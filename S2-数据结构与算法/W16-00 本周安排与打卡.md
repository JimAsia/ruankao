## 三、自测六题

**1. 顺序表的遍历循环条件应该写 `i < length` 还是 `i < MAXSIZE`？为什么？**

**2. 在顺序表中插入元素，元素移动的方向是？删除呢？**

**3. 长度为 n 的顺序表，插入一个元素平均移动多少次？删除呢？**

**4. 按位置访问 `L.data[500]` 的时间复杂度是多少？为什么？**

**5. 删除顺序表中所有值为 x 的元素，最优写法的时间复杂度是多少？为什么不是 O(n²)？**

**6. 循环左移 m 位，三次逆置法的三步分别是什么？**

## 四、答案与解析

**1. `i < length`。**

`MAXSIZE` 是**容量**，`length` 是**实际元素个数**。用 MAXSIZE 会把数组后面没初始化的内存也当成数据，输出一堆随机值。

**2. 插入从后往前，删除从前往后。**

理由：想清楚「谁是源、谁是目标」。

```text
插入：要把 pos 之后的元素往后搬。
      源在前（i-1），目标在后（i）。从后往前搬，源还没被覆盖。

删除：要把 pos 之后的元素往前搬。
      源在后（i+1），目标在前（i）。从前往后搬，源还没被覆盖。
```

**3. 插入平均 n/2 次，删除平均 (n-1)/2 次。**

推导：

```text
插入：位置 0..n 共 n+1 种，移动次数 n, n-1, ..., 1, 0
      平均 = [n(n+1)/2] / (n+1) = n/2

删除：位置 0..n-1 共 n 种，移动次数 n-1, n-2, ..., 1, 0
      平均 = [(n-1)n/2] / n = (n-1)/2
```

> ⚠️ 插入分母 n+1、删除分母 n，这是最容易混的点。

**4. O(1)。**

地址可以直接算出来：

```text
地址 = 首地址 + 下标 × sizeof(int)
```

这叫**随机访问**。链表做不到，因为节点地址不连续，必须从头走。

**5. O(n)，用覆盖法。**

```c
int k = 0;
for (int i = 0; i < n; i++)
    if (a[i] != x) a[k++] = a[i];
n = k;
```

因为 `k <= i` 恒成立，所以 `a[k] = a[i]` 永远写在已经读过的位置，不会覆盖未读数据。一趟扫完就是 O(n)。

对比 O(n²) 的写法：找到一个就整体前移，有 m 个目标就要挪 m 次，最坏 m=n 时是 O(n²)。

**6. 逆置前 m 个 → 逆置后 n-m 个 → 整体逆置。**

```
原表：  [1 2 3 | 4 5 6 7]
逆置前半：[3 2 1 | 4 5 6 7]
逆置后半：[3 2 1 | 7 6 5 4]
整体逆置：[4 5 6 7 1 2 3]     ← 左移 3 位
```

设 `A` = 前 m 个，`B` = 后 n-m 个：`AB → AᴿB → AᴿBᴿ → BA`。
