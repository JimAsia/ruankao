# W19-01 树的概念与二叉树的性质

> 前面学的都是**线性**结构（一个接一个），树是第一个**非线性**结构。
> 二叉树是「每个节点最多两个孩子」的特殊树，是软考考查的重心。
> 这一节先吃透**性质和概念**，它们是选择题的送分项。

---

## 一、树的基本术语

```text
        A        ← 根节点（唯一，没有父节点）
       / \
      B   C      ← B、C 是 A 的孩子
     / \   \
    D   E   F    ← D、E、F 是叶子（没有孩子）
```

| 术语 | 含义 | 例子 |
|---|---|---|
| 根节点 | 没有父节点的那个 | A |
| 叶子 | 没有孩子的节点 | D、E、F |
| 度 | 一个节点的孩子个数 | A 的度是 2，C 的度是 1 |
| 深度 | 从根到这个节点的层数 | A 深度 1，D 深度 3 |
| 高度 | 从下往上数 | 叶子高度 1 |
| 子树 | 一个节点及其后代 | B 的子树是 B、D、E |

> ⚠️ **「深度」和「高度」容易混：**
> 深度是「从上往下数」（根算第 1 层），高度是「从下往上数」（叶子算 1）。
> 软考常问「树的深度」= 最深的叶子在第几层。

## 二、二叉树的三条核心性质（必背 + 会推）

### 性质 1：第 i 层最多 2^(i-1) 个节点

```text
第 1 层：1 个（根）
第 2 层：2 个
第 3 层：4 个
第 4 层：8 个
...
第 i 层：2^(i-1) 个
```

> 为什么？每个节点最多 2 个孩子，每往下一层最多翻一倍。

### 性质 2：深度 k 的二叉树最多 2^k - 1 个节点

```text
1 + 2 + 4 + ... + 2^(k-1) = 2^k - 1
```

等比数列求和。实测（`191_tree_basic.c`）：

```text
深度 1 → 1 个
深度 2 → 3 个
深度 3 → 7 个
深度 4 → 15 个
深度 5 → 31 个
深度 6 → 63 个
```

> ⚠️ **是 2^k - 1，不是 2^k。** 满二叉树深度 5 是 31 个节点，不是 32。

### 性质 3：叶子数 n0 = 度为 2 的节点数 n2 + 1

这条最重要，软考选择题几乎每年都考，要会推导：

```text
设总节点 n，度 2 节点 n2，度 1 节点 n1，叶子 n0。

（1）节点总数：n = n0 + n1 + n2
（2）边数 = n - 1（n 个节点的树有 n-1 条边）
（3）边数也 = n1 + 2·n2（度 1 贡献 1 条边，度 2 贡献 2 条边）

联立 (2)(3)：n0 + n1 + n2 - 1 = n1 + 2·n2
              n0 = n2 + 1
```

实测验证（一棵 8 节点的树）：

```text
度为 2 的节点 = 3 个（A、B、F）
叶子节点     = 4 个（D、E、G、H）
验证：4 = 3 + 1 ✓
```

> ⭐ 变体问法：已知 n2 求 n0，或已知 n0 求 n2。记住「叶子比度 2 多 1 个」。

## 三、满二叉树 vs 完全二叉树

| 类型 | 定义 | 关键 |
|---|---|---|
| 满二叉树 | 每一层都填满 | 深度 k 有 2^k-1 个节点 |
| 完全二叉树 | 只有最后一层可以不满，且从左到右连续 | 前面层全满 |

```text
满二叉树：    完全二叉树：    不是完全二叉树：
    A             A               A
   / \           / \             / \
  B   C         B   C           B   C
 / \ / \       / \ /           / \   \
D  E F  G     D  E F          D  E   G
                              ↑ 有空洞（F空但G有）
```

> ⭐ **包含关系：满二叉树一定是完全二叉树，完全二叉树不一定是满二叉树。**

判断口诀：把节点按层序排开（空位也占位置），**空位只能出现在最后且不能中断**。

## 四、完全二叉树的两个性质（重点）

### 性质 A：深度 = ⌊log2(n)⌋ + 1

实测（`191_tree_basic.c`）：

```text
n = 1  → 深度 1
n = 2  → 深度 2
n = 3  → 深度 2
n = 4  → 深度 3
n = 7  → 深度 3
n = 8  → 深度 4
n = 15 → 深度 4
n = 16 → 深度 5
```

> ⚠️ 注意边界：n 是 2 的幂时会「跳层」。
> 8 个节点深度是 4，但 7 个节点深度是 3。

### 性质 B：下标规律（编号从 1 开始）

```text
节点 i 的左孩子 = 2i
节点 i 的右孩子 = 2i + 1
节点 i 的父节点 = ⌊i/2⌋
```

实测：

```text
节点 1 → 左 2，右 3，父 0
节点 2 → 左 4，右 5，父 1
节点 3 → 左 6，右 7，父 1
```

> ⭐ **这个下标规律是「堆」和「顺序存储」的基础。**
> W20 讲堆排序时要用它。也解释了为什么完全二叉树能用数组高效存。

## 五、二叉树的存储

### 链式存储（最常用）

```c
typedef struct TNode {
    int          data;
    struct TNode *left;
    struct TNode *right;
} TNode;
```

### 顺序存储（只适合完全二叉树）

完全二叉树用数组存，下标规律 `2i` / `2i+1`，一个位置都不浪费。

但一般的树会严重浪费：

```text
斜树：A → B → C（3 个节点）
数组：[A, 空, 空, C]   ← 3 个节点占了 7 个位置！
```

> ⭐ 最坏情况（斜树），n 个节点要 `2^n - 1` 个位置。
> 所以**顺序存储只适合完全二叉树**。
> 📌 这就是「堆必须是完全二叉树」的原因 —— 为了能用数组存。

## 六、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 性质 1 | 第 i 层最多几个 | `2^(i-1)` |
| 性质 2 | 深度 k 最多几个 | `2^k - 1` |
| 性质 3 | n0 和 n2 关系 | `n0 = n2 + 1` |
| 完全二叉树 | 深度公式 | `⌊log2(n)⌋ + 1` |
| 完全二叉树 | 孩子下标 | `2i` / `2i+1` |
| 满 vs 完全 | 包含关系 | 满 ⊂ 完全 |
| 顺序存储 | 为什么只适合完全二叉树 | 一般树会浪费空间 |
| 术语 | 深度 vs 高度 | 从上数 vs 从下数 |
