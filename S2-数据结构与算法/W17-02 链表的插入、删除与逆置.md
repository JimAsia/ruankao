# W17-02 链表的插入、删除与逆置

> 链表的所有操作都围绕一句话：**先接后断**。
> 顺序错了，后面的节点就永久丢失 —— 而且不报错，只是数据少了。

---

## 一、插入：四步，先接后断

```c
Node *prev = getPrev(L, pos);       /* 找到前驱，O(n) */
Node *n = malloc(sizeof(Node));

n->data = value;
n->next = prev->next;               /* ① 新节点接上后半段 */
prev->next = n;                     /* ② 前驱改指新节点 */
```

```text
插入前：  prev → [30] → [40] → ...
插入中：  n(99) 的 next 先指向 [30]（原 prev->next）
插入后：  prev → [99] → [30] → [40] → ...
```

实测：

```text
原链表  10 -> 20 -> 30 -> 40 -> 50
插下标 2 → 10 -> 20 -> 99 -> 30 -> 40 -> 50
```

### 顺序反了会怎样

```c
/* ❌ 错误写法 */
prev->next = n;              /* 前半段先断了 */
n->next = prev->next;        /* 此时 prev->next 已经是 n 自己！ */
```

结果：`n->next` 指向 `n`，形成**自环**，原来的 `[30] → [40] → ...` 全部丢失（内存泄漏）。

> ⭐ **口诀：新节点先抱紧后面，前驱再回头拉它。**
>
> 形象点说：先把新人的手牵上后面那个人，再让前面的人放开旧手改牵新人。
> 反过来做，后面那串人就再也找不到了。

---

## 二、找前驱：为什么链表插入是 O(n)

```c
static Node *getPrev(const LinkedList *L, int pos)
{
    Node *p = L->head;              /* 头结点是第 0 个节点的前驱 */
    for (int i = 0; i < pos && p != NULL; i++) p = p->next;
    return p;
}
```

| 操作 | 改指针 | 找前驱 | 整体 |
|---|---|---|---|
| 在**已知节点**后插入 | O(1) | — | **O(1)** |
| 按**位置**插入 | O(1) | O(n) | O(n) |
| 在**表头**插入 | O(1) | O(1)（前驱是头结点） | **O(1)** |
| 在**表尾**插入 | O(1) | O(n)（要走到底） | O(n) |

> ⭐ **「链表插入 O(1)」这句话，永远带着一个前提：已经拿到前驱指针。**
> 软考选择题经常在这上面挖坑。

### 链表与顺序表正好相反

| | 表头插入 | 表尾插入 |
|---|---|---|
| 顺序表 | O(n)（全部后移） | **O(1)** |
| 链表 | **O(1)** | O(n)（要找尾） |

## 三、删除：一句话，别忘了 free

```c
Node *prev = getPrev(L, pos);
Node *victim = prev->next;

prev->next = victim->next;      /* 前驱跳过被删节点 */
free(victim);                   /* ⚠️ 必须 free */
L->length--;
```

实测：

```text
删除下标 3 → 被删的是 99
10 -> 20 -> 30 -> 40 -> 50
```

> ⚠️ **不 free 就是内存泄漏。** 一个节点 16 字节，删一万次泄漏 160 KB。
> 量小看不出问题，量大就是灾难。

> 📌 双链表删除已知节点是 O(1)（有 prev 指针），单链表要 O(n) 找前驱。
> 这是 W17-03 要讲的内容。

## 四、逆置：三指针法（背下来）

```c
Node *prev = NULL;
Node *cur  = L->head->next;
Node *next = NULL;

while (cur != NULL) {
    next = cur->next;           /* ① 先存后继 */
    cur->next = prev;           /* ② 反转指向 */
    prev = cur;                 /* ③ prev 前进 */
    cur  = next;                /* ④ cur 前进 */
}
L->head->next = prev;           /* 头结点指向新表头（原尾节点） */
```

### 图解（1→2→3 逆置）

```text
初始：  prev=NULL   cur=1   next=?

第1轮：  next=2;  1.next=NULL;  prev=1;  cur=2
        NULL ← 1   2 → 3

第2轮：  next=3;  2.next=1;     prev=2;  cur=3
        NULL ← 1 ← 2   3

第3轮：  next=NULL; 3.next=2;   prev=3;  cur=NULL
        NULL ← 1 ← 2 ← 3

结束：  head->next = prev = 3
        3 → 2 → 1 → NULL ✓
```

实测：

```text
原表   1 -> 2 -> 3 -> 4 -> 5 -> NULL
逆置后 5 -> 4 -> 3 -> 2 -> 1 -> NULL
```

### 第 ① 步为什么不能颠倒

```c
/* ❌ 错误顺序 */
cur->next = prev;       /* 一改，cur 原来的后继就找不到了 */
next = cur->next;       /* 此时 cur->next 已经是 prev，next 拿到的是错的 */
```

后果：链表只剩前半截，后半截全部泄漏。

> ⭐ **这是链表题第一大 bug，改错题常考。**
> 记住：**只要要改 `p->next`，前面必须先存 `next`。**

### 三指针法不需要特判空表和单节点

```text
空表：cur = NULL，while 不进入，head->next = NULL → 还是空表 ✓
单节点：cur 走一轮，prev = 该节点，cur = NULL → head->next 指向它自己 ✓
```

实测两组边界都不崩。

## 五、逆置的第二种写法：头插法

思路：把整条链摘下来，再逐个**头插**回原表头。

```c
Node *cur = L->head->next;
L->head->next = NULL;           /* 先摘空 */

while (cur != NULL) {
    Node *next = cur->next;     /* 存后继 */
    cur->next = L->head->next;  /* 头插 */
    L->head->next = cur;
    cur = next;
}
```

实测：再逆置一次，链表**回到原顺序**（逆置两次 = 复原）。

> ⭐ 两种方法都是 **O(n) 时间、O(1) 空间**。
> 头插法更容易理解，三指针法更常见于教材 —— 考试写哪个都行。

## 六、插入删除的四个边界

| 位置 | 插入 pos 范围 | 删除 pos 范围 | 注意 |
|---|---|---|---|
| 表头 | `pos == 0` | `pos == 0` | 前驱是头结点 |
| 表中 | `0 < pos < length` | `0 < pos < length` | 正常找前驱 |
| 表尾 | `pos == length`（可以插） | `pos == length-1`（可以删） | 插入时前驱是原尾节点 |
| 越界 | `pos > length` 或 `pos < 0` | `pos >= length` | 必须判，否则崩 |

> ⚠️ **插入 `pos` 最大是 `length`（插到末尾），删除最大是 `length-1`。**
> 和顺序表完全一致。

## 七、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 插入顺序 | 两句谁先谁后 | 先 `n->next = prev->next` |
| 插入复杂度 | 在 p 之后插入 | O(1)（前提是已知 p） |
| 删除 | 漏了 free 会怎样 | 内存泄漏 |
| 逆置 | 补全三指针的四步 | 顺序不能错 |
| 逆置复杂度 | 时间空间 | O(n) / O(1) |
| 表头/表尾 | 哪个 O(1) | 表头插入 O(1) |
| 空表/单节点 | 逆置函数要不要特判 | 三指针法不需要 |
