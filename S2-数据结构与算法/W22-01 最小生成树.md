# W22-01 最小生成树

> 生成树是「连通图的最小连通子图」，最小生成树是所有生成树里权值和最小的。
> 两个算法：Prim 加点、Kruskal 加边。软考选择题的核心是**「哪个适合什么图」**。

---

## 一、生成树的定义与三个条件

**生成树**：包含图中全部 n 个顶点的极小连通子图。

判断是不是生成树，看三条：

```text
1. 包含全部 n 个顶点
2. 恰好 n-1 条边
3. 连通
```

> ⭐ **n 个顶点的生成树一定有 n-1 条边。**
> 少一条 → 不连通；多一条 → 必有环。

**最小生成树（MST）**：所有生成树里边权之和最小的那棵。

> 📌 重要性质：**MST 的权值之和唯一，但形态可能不唯一**（有等权边时可以互换）。

---

## 二、Prim：加点法（滚雪球）

### 思路

```text
从一个顶点开始，维护一个「已选集合」
每轮：找「离已选集合最近的」未选顶点，把它加进来
重复 n-1 次
```

### 代码骨架

```c
int prim(int cost[MAXV][MAXV], int n) {
    int lowcost[MAXV];          /* lowcost[i] = i 到已选集合的最小边权 */
    int visited[MAXV];
    int total = 0;

    for (int i = 0; i < n; i++) {
        lowcost[i] = cost[0][i];        /* 从 0 出发 */
        visited[i] = 0;
    }
    visited[0] = 1;

    for (int round = 1; round < n; round++) {
        /* ① 找 lowcost 最小的未访问点 */
        int minIdx = -1, minVal = INF;
        for (int i = 0; i < n; i++)
            if (!visited[i] && lowcost[i] < minVal) {
                minVal = lowcost[i]; minIdx = i;
            }

        /* ② 加入 */
        visited[minIdx] = 1;
        total += minVal;

        /* ③ 用新点更新 lowcost */
        for (int i = 0; i < n; i++)
            if (!visited[i] && cost[minIdx][i] < lowcost[i])
                lowcost[i] = cost[minIdx][i];
    }
    return total;
}
```

### 实测

```text
图：0-1(2) 0-3(6) 1-2(3) 1-3(8) 1-4(5) 2-4(7) 3-4(9)

从顶点 0 开始
  第 1 步：加入顶点 1，边权 2
  第 2 步：加入顶点 2，边权 3
  第 3 步：加入顶点 4，边权 5
  第 4 步：加入顶点 3，边权 6

最小生成树总权值 = 16
```

共 5-1 = 4 条边，总权 2+3+5+6 = 16 ✓

> ⭐ **Prim 天然不会成环**，因为每次只连一个新点。

## 三、Kruskal：加边法（拼图）

### 思路

```text
1. 所有边按权值升序排序
2. 依次取边，用并查集判断「加入后会不会成环」
   不成环就选，成环就跳过
3. 选够 n-1 条就停
```

### 并查集判环

```c
int ufFind(int x) {                     /* 找根 */
    while (parent[x] != x) {
        parent[x] = parent[parent[x]];  /* 路径压缩 */
        x = parent[x];
    }
    return x;
}

int ufUnion(int a, int b) {
    int ra = ufFind(a), rb = ufFind(b);
    if (ra == rb) return 0;             /* 已连通 → 会成环 */
    parent[ra] = rb;
    return 1;
}
```

> ⭐ **并查集是 Kruskal 的灵魂。** 它能在近似 O(1) 的时间里回答「两个点是否已连通」。

### 实测

```text
排序后：0-1(2) 1-2(3) 1-4(5) 0-3(6) 2-4(7) 1-3(8) 3-4(9)

选 0-1(2)
选 1-2(3)
选 1-4(5)
选 0-3(6)
跳过 2-4(7) —— 会成环（1-2-4-1）
跳过 1-3(8) —— 会成环
跳过 3-4(9) —— 已经够 4 条边

总权值 = 16
```

> ⭐ 和 Prim 结果相同 —— **MST 的权值和唯一**。

## 四、Prim vs Kruskal（必背）

| 对比项 | Prim | Kruskal |
|---|---|---|
| 思路 | 加点（滚雪球） | 加边（拼图） |
| 复杂度 | **O(n²)** | **O(e log e)** |
| 适合 | **稠密图** | **稀疏图** |
| 需要的数据 | 邻接矩阵 + lowcost 数组 | 边集 + 并查集 |
| 判环方式 | 天然不会成环 | 并查集 |

### 为什么这样选

```text
Prim     O(n²)      —— 只和顶点数有关，和边数无关
                    稠密图 e ≈ n²，O(n²) 和 O(e log e) = O(n² log n) 比，Prim 更快

Kruskal  O(e log e) —— 边越少越快
                    稀疏图 e ≈ n，O(n log n) 远好于 Prim 的 O(n²)
```

> 📌 软考原题：「求稀疏图的最小生成树，用哪个算法？」→ **Kruskal**。

## 五、手算 MST 的技巧

软考常给一个带权图，让你求 MST 的总权值。手算建议用 **Kruskal**（更机械）：

```text
1. 把所有边按权值从小到大排成一列
2. 从小到大取边，画在图上
3. 如果这条边会让某些点形成环，划掉
4. 取够 n-1 条就停，把权值加起来
```

### 判断成环的土办法

看这条边的两个端点，**是不是已经通过已选的边连通了**。
如果已经能走通，再加这条就是环。

> ⭐ 例：已选 1-2、1-4 后，2 和 4 已连通，此时再选 2-4 就是环。

## 六、一个容易忽略的点

**MST 唯一吗？**

```text
权值之和 → 唯一
边的集合 → 可能不唯一（当存在等权边时）
```

例：三角形三条边都是 1，任选两条都是 MST，权值和都是 2。

> 📌 软考如果问「最小生成树是否唯一」，答案取决于有没有等权边。
> 问「最小生成树的权值是否唯一」，答案是**唯一**。

## 七、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 生成树边数 | n 个顶点几条边 | n-1 |
| MST 权值 | 给图求最小权值和 | 手算，用 Kruskal |
| 算法选择 | 稀疏图用哪个 | Kruskal |
| 算法选择 | 稠密图用哪个 | Prim |
| 复杂度 | Prim / Kruskal | O(n²) / O(e log e) |
| 唯一性 | MST 唯一吗 | 权值唯一，形态可能不唯一 |
| 判环 | Kruskal 怎么判环 | 并查集 |
