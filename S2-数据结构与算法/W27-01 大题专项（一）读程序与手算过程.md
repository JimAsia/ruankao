## 题 1（15 分，建议 12 分钟）

### 题目

有如下二叉树：

```text
           8
         /   \
        3     10
       / \      \
      1   6      14
         / \    /
        4   7  13
```

```c
typedef struct Node { int key; struct Node *left, *right; } Node;

int f(Node *t) {
    if (t == NULL) return 0;
    int l = f(t->left);
    int r = f(t->right);
    printf("%d ", t->key);
    return l + r + 1;
}
```

设 `t` 指向根节点 8，回答：

1. `f(t)` 的输出序列是什么？（6 分）
2. `f(t)` 的返回值是多少？说明这个返回值的含义。（4 分）
3. 如果把 `printf` 移到函数第一行（`if` 判断之后），输出序列变成什么？（5 分）

### 参考答案

**1.** `1 4 7 6 3 13 14 10 8`

**2.** 返回 **9**，含义是**这棵二叉树的节点个数**。

**3.** `8 3 1 6 4 7 10 14 13`

### 解析

**第 1 问**：`printf` 在两次递归之后，这就是**后序遍历**（左 → 右 → 根）。

按树走一遍：

```text
8 的左子树 3：
  3 的左 1 → 输出 1
  3 的右 6：
     6 的左 4 → 输出 4
     6 的右 7 → 输出 7
     输出 6
  输出 3
8 的右子树 10：
  10 的左为空
  10 的右 14：
     14 的左 13 → 输出 13
     输出 14
  输出 10
输出 8
```

连起来：`1 4 7 6 3 13 14 10 8`。

> ⚠️ 注意 14 只有**左**孩子 13，没有右孩子。画图时容易看错成右孩子。

**第 2 问**：`l + r + 1`，`l` 和 `r` 分别是左右子树的节点数，加 1 是自己。
所以返回整棵树的节点数 = 9。

同时验证：`1+1+1+1+1+1+1+1+1 = 9`，与遍历输出 9 个数字一致。

**第 3 问**：`printf` 移到最前面就是**先序遍历**（根 → 左 → 右）。
但要注意位置：必须在 `if (t == NULL) return 0;` **之后**，
否则会先打印空指针（崩溃）。

结果：`8 3 1 6 4 7 10 14 13`。

### 考点映射

| 考点 | 出处 |
|---|---|
| 二叉树三种遍历 | W19-02 |
| 递归的执行顺序 | W08 |
| 后序/先序只差 printf 的位置 | W19-02 |

### 易错点

1. **把后序当先序**：只看到"递归"就默认先序。判断依据是 `printf` 的位置。
2. **数错节点**：树画得不对称时容易漏。输出了 9 个数字就说明有 9 个节点，
   两种方法可以互相验证。
3. **第 3 问忽略 NULL 判断**：如果 `printf` 写在 `if` 之前，遇到空指针就崩了。

## 题 2（20 分，建议 20 分钟）

### 题目

对数组 `{49, 38, 65, 97, 76, 13, 27, 52}` 回答：

**（1）** 以第一个元素 49 为基准，写出**快速排序第一趟**分区后的结果，
并指出基准 49 的最终下标。（10 分）

**（2）** 用**筛选法（下沉调整）**把该数组建成**大根堆**，
写出建堆后的结果，并说明是从哪个下标开始调整的。（10 分）

### 参考答案

**（1）** `27 38 13 49 76 97 65 52`，基准 49 的最终下标是 **3**。

**（2）** `97 76 65 52 49 13 27 38`，从下标 **3**（`n/2 - 1 = 8/2 - 1 = 3`）开始往前调整。

### 解析（1）：挖坑法

```text
初始：49 38 65 97 76 13 27 52     pivot = 49，a[0] 是坑

j 从右往左找 < 49 的：a[6]=27
  27 填到 a[0]，i 右移          → 27 38 65 97 76 13 [27] 52

i 从左往右找 > 49 的：a[2]=65
  65 填到 a[6]，j 左移          → 27 38 [65] 97 76 13 65 52

j 继续往左找 < 49 的：a[5]=13
  13 填到 a[2]，i 右移          → 27 38 13 97 76 [13] 65 52

i 继续往右找 > 49 的：a[3]=97
  97 填到 a[5]，j 左移          → 27 38 13 [97] 76 97 65 52

i 继续往右：a[4]=76 > 49，停
j 继续往左：i == j，停

i == j == 3，把 pivot 填进去   → 27 38 13 49 76 97 65 52
```

**验证**：49 左边 `27 38 13` 全部 < 49，右边 `76 97 65 52` 全部 > 49 ✓

> ⭐ 快排一趟的结果**不唯一**（取决于分区写法），但**基准的最终位置是唯一的**。
> 判卷时看的是"基准左边是否都小、右边是否都大"，而不是逐位比对。

### 解析（2）：建堆

`n = 8`，最后一个非叶子节点是 `n/2 - 1 = 3`，所以从下标 3 往前到 0，逐个下沉。

```text
初始：49 38 65 97 76 13 27 52

i=3（值 97）：孩子是 a[7]=52 → 97 > 52，不用动
               49 38 65 97 76 13 27 52

i=2（值 65）：孩子是 a[5]=13, a[6]=27 → 65 最大，不用动
               49 38 65 97 76 13 27 52

i=1（值 38）：孩子是 a[3]=97, a[4]=76 → 97 最大，交换
               49 97 65 38 76 13 27 52
              38 落到下标 3，孩子是 a[7]=52 → 52 > 38，再交换
               49 97 65 52 76 13 27 38

i=0（值 49）：孩子是 a[1]=97, a[2]=65 → 97 最大，交换
               97 49 65 52 76 13 27 38
              49 落到下标 1，孩子是 a[3]=52, a[4]=76 → 76 最大，交换
               97 76 65 52 49 13 27 38
              49 落到下标 4，没有孩子，停
```

**结果**：`97 76 65 52 49 13 27 38`

验证大根堆性质：每个父节点都不小于孩子

```text
a[0]=97 ≥ a[1]=76, a[2]=65   ✓
a[1]=76 ≥ a[3]=52, a[4]=49   ✓
a[2]=65 ≥ a[5]=13, a[6]=27   ✓
a[3]=52 ≥ a[7]=38            ✓
```

### 追问：取出堆顶 97 之后呢？

这是考试常接的第二问。做法：把末尾元素 38 放到堆顶，长度减 1，然后下沉。

```text
97 76 65 52 49 13 27 38   → 取走 97，38 放到堆顶
38 76 65 52 49 13 27      → 孩子 76 > 65，交换
76 38 65 52 49 13 27      → 38 的孩子 52 > 49，交换
76 52 65 38 49 13 27      → 38 没有孩子，停
```

结果：`76 52 65 38 49 13 27`，新堆顶 76。

### 考点映射

| 考点 | 出处 |
|---|---|
| 快排分区（挖坑法） | W24-01 |
| 建堆的起点 `n/2-1` | W20-02 |
| 下沉调整 | W20-02 |
| 堆排序的"取顶—换尾—下沉" | W23/W20 |

### 易错点

1. **建堆从 0 开始**：应该从**最后一个非叶子节点** `n/2-1` 开始，
   因为叶子本身已经是堆，不用调整。
2. **下沉时选错孩子**：大根堆要选**较大**的孩子交换，选小的会破坏性质。
3. **快排时 i/j 移动顺序**：挖坑法是"右找小、左找大"，左右弄反会导致结果错乱。
4. **忘记最后填回 pivot**：循环结束时 `i == j`，这个位置就是基准的最终位置。

## 题 3（25 分，建议 25 分钟）

### 题目

补全下面三处算法（每空 5 分，共 15 分；后两问各 5 分）。

**（1）** 单链表就地逆置（要求空间 O(1)）：

```c
LNode *reverseList(LNode *head) {
    LNode *prev = NULL, *cur = head, *next;
    while (cur != NULL) {
        next = ______①______;
        cur->next = ______②______;
        prev = ______③______;
        cur  = ______④______;
    }
    return ______⑤______;
}
```

**（2）** 循环队列（数组长度 `MAX`，少用一个元素区分空/满），补全判空、判满、入队：

```c
int empty(Q *q) { return ______⑥______; }
int full (Q *q) { return ______⑦______; }
int push(Q *q, int x) {
    if (full(q)) return 0;
    q->data[q->rear] = x;
    q->rear = ______⑧______;
    return 1;
}
```

**（3）** 折半查找的递归版，补全两个递归调用：

```c
int binRec(int *a, int lo, int hi, int key) {
    if (lo > hi) return -1;
    int mid = lo + (hi - lo) / 2;
    if (a[mid] == key) return mid;
    if (a[mid] < key) return ______⑨______;
    return ______⑩______;
}
```

### 参考答案

| 空 | 答案 |
|---|---|
| ① | `cur->next` |
| ② | `prev` |
| ③ | `cur` |
| ④ | `next` |
| ⑤ | `prev` |
| ⑥ | `q->front == q->rear` |
| ⑦ | `(q->rear + 1) % MAX == q->front` |
| ⑧ | `(q->rear + 1) % MAX` |
| ⑨ | `binRec(a, mid + 1, hi, key)` |
| ⑩ | `binRec(a, lo, mid - 1, key)` |

### 解析（1）：为什么是这个顺序

```text
next = cur->next;    ← 必须先存，否则改完 next 就找不到后面了
cur->next = prev;    ← 掉头
prev = cur;          ← prev 前进
cur = next;          ← cur 前进
```

**如果把 ① 和 ② 对调**：

```c
cur->next = prev;      // 先把 next 改掉了
next = cur->next;      // 此时 next 取到的是 prev，不是原来的下一个
```

后面整条链就断了，而且不会报错 —— 这类错误最难查。

**返回值为什么是 prev**：循环结束时 `cur == NULL`，`prev` 停在原来的尾节点，
也就是新的头节点。

**实测**：`1 2 3 4 5` → `5 4 3 2 1`。

> ⭐ 三指针法的漂亮之处：**空表和单节点都不用特判**。
> 空表时 while 一次不进，返回 NULL；单节点时走一轮返回该节点。

### 解析（2）：少用一个元素

队列长度 `MAX`，但最多只能存 `MAX-1` 个元素，故意空一格：

```text
队空：front == rear
队满：(rear + 1) % MAX == front
```

为什么要空一格：如果不空，队满和队空都是 `front == rear`，无法区分。

**实测**（`MAX = 6`）：

```text
入队 1 → 成功（front=0, rear=1）
入队 2 → 成功（front=0, rear=2）
入队 3 → 成功（front=0, rear=3）
入队 4 → 成功（front=0, rear=4）
入队 5 → 成功（front=0, rear=5）
第 6 次入队 6 → 队满失败（front=0, rear=5）
出队 → 1（front=1）
出队 → 2（front=2）
再入队 7 → 成功（front=2, rear=0）   ← rear 绕回 0
```

注意最后一次 `rear` 从 5 变成 `(5+1)%6 = 0`，这就是"循环"的体现。

### 解析（3）：两个边界

```c
if (a[mid] < key) return binRec(a, mid + 1, hi, key);   // 往右，lo = mid+1
return binRec(a, lo, mid - 1, key);                     // 往左，hi = mid-1
```

**必须 ±1**。写成 `mid` 会导致区间不缩小，无限递归。

**实测**（表 `8 15 22 27 33 41 55 60 73 84 96`）：

```text
查 33  → 下标 4
查 8   → 下标 0
查 96  → 下标 10
查 50  → -1
```

### 考点映射

| 考点 | 出处 |
|---|---|
| 链表逆置三指针 | W17-02 |
| 循环队列判空/判满 | W18-03 |
| 折半查找递归版 | W25-01 |
| 递归边界 ±1 | W25-01 |

### 易错点

1. **链表逆置写成两指针**：只留 `prev` 和 `cur`，改完 `cur->next` 就丢了后面。
2. **循环队列判满用 `rear == front`**：那是判空条件，两者会混淆。
3. **入队不取模**：写成 `q->rear++` 会越界。
4. **折半递归写 `mid`**：死循环。
