# W18-02 栈的应用

> 栈的四个经典应用：**括号匹配、进制转换、表达式求值、递归**。
> 前三个是软考真题原型，第四个解释了「栈为什么无处不在」。

---

## 一、括号匹配：嵌套结构都能查

```c
for (int i = 0; s[i] != '\0'; i++) {
    char c = s[i];
    if (c == '(' || c == '[' || c == '{') {
        push(&S, c);                    /* 左括号入栈 */
    } else if (c == ')' || c == ']' || c == '}') {
        char left;
        if (!pop(&S, &left)) return 0;  /* 情况 1：右括号多了 */
        if (!match(left, c))  return 0; /* 情况 2：类型不配 */
    }
}
if (!empty(&S)) return 0;               /* 情况 3：左括号多了 */
return 1;
```

### 实测七组

```text
{[()()]}         → 匹配 ✓
(a+b)*[c-d]      → 匹配 ✓
((()))           → 匹配 ✓
{[(])}           → 不匹配 ✗  第 4 个字符 ']' 与栈顶 '(' 不配对
(()              → 不匹配 ✗  扫描完还有 1 个左括号没闭合
())              → 不匹配 ✗  第 3 个字符 ')' 多余（栈已空）
(空串)           → 匹配 ✓
```

### 三种失败情况必须分清

| 情况 | 表现 | 例子 |
|---|---|---|
| 右括号多余 | 出栈时栈已空 | `())` |
| 类型不配对 | 栈顶和当前右括号不是一对 | `{[(])}` |
| 左括号多余 | 扫完栈非空 | `(()` |

> ⭐ **为什么用栈**：括号匹配的本质是「**最近打开的最先关闭**」，正是后进先出。
>
> 所以所有**嵌套结构**都能用栈检查：HTML 标签、JSON 的 `{}`、函数调用嵌套。

> 📌 **复杂度**：时间 O(n)，空间 O(n)（最坏情况全是左括号）。

## 二、进制转换：除基取余

```c
while (n > 0) {
    push(&S, digits[n % base]);     /* 余数依次入栈 */
    n /= base;
}
while (pop(&S, &c)) out[k++] = c;   /* 弹出就是倒序 */
```

实测：

```text
10     → 2进制 1010        8进制 12       16进制 A
255    → 2进制 11111111    8进制 377      16进制 FF
100    → 2进制 1100100     8进制 144      16进制 64
12345  → 2进制 11000000111001  8进制 30071  16进制 3039
```

### 为什么用栈

```text
10 转 2 进制：
  10 % 2 = 0   ← 最低位
   5 % 2 = 1
   2 % 2 = 0
   1 % 2 = 1   ← 最高位

除基取余得到的是【低位 → 高位】，
而输出需要【高位 → 低位】—— 正好倒过来，栈就是干这个的。
```

> ⭐ **凡是「先得到的不该先输出」的场景，都想到栈。**
> 这是识别「该用栈」最快的一个信号。

## 三、后缀表达式求值

### 三步

```text
1. 遇到数字     → 入栈
2. 遇到运算符   → 弹出两个数，计算，结果再入栈
3. 扫完         → 栈里只剩一个数，就是答案
```

实测：

```text
3 4 +                = 7
5 1 2 + 4 * + 3 -    = 14      ← 软考经典题
2 3 *                = 6
8 2 /                = 4
1 2 + 3 *            = 9
6 2 - 3 +            = 7
3 4 -                = -1
```

### 顺序陷阱：先弹的是右操作数

```c
int b, a;
pop(&S, &b);        /* 先弹出的是【右】操作数 */
pop(&S, &a);        /* 后弹出的是【左】操作数 */
result = a - b;     /* ⚠️ 是 a-b，不是 b-a */
```

> ⚠️ **减法和除法写反了结果就错。**
> `3 4 -` 是 `3 - 4 = -1`，不是 `1`。
> 实测已验证输出 `-1`。

### 为什么计算机用后缀不用中缀

| 形式 | 例子 | 需要括号吗 | 需要优先级吗 |
|---|---|---|---|
| 中缀 | `(1+2)*3` | 要 | 要 |
| 后缀 | `1 2 + 3 *` | **不要** | **不要** |

> ⭐ **后缀表达式把「优先级」和「括号」都编进了顺序里**，
> 所以求值只需一个栈、一趟扫描，不需要任何判断。

## 四、中缀转后缀：调度场算法

```
遇到数字   → 直接输出
遇到 '('   → 入栈
遇到 ')'   → 弹栈并输出，直到弹出 '('（'(' 本身不输出）
遇到运算符 → 弹出所有【优先级 >= 自己】的运算符并输出，然后自己入栈
扫描结束   → 把栈里剩下的全部弹出输出
```

### 实测五组

```text
1+2*3          → 1 2 3 * +
(1+2)*3        → 1 2 + 3 *
1+2+3          → 1 2 + 3 +
2*(3+4)-5      → 2 3 4 + * 5 -
((1+2)*(3+4))  → 1 2 + 3 4 + *
```

串起来验证：

```text
2*(3+4)-5  →  2 3 4 + * 5 -  →  9    （14-5=9 ✓）
```

### 为什么是「>=」不是「>」

```text
用 >= ：1+2+3 → 1 2 + 3 +      ← 左结合，正确
用 >  ：1+2+3 → 1 2 3 + +      ← 右结合，减法除法会算错
```

> ⭐ **减法和除法必须左结合**（`a-b-c` 是 `(a-b)-c`），
> 所以遇到同优先级必须弹出，用 `>=`。

### 优先级表

| 运算符 | 优先级 |
|---|---|
| `*` `/` | 2 |
| `+` `-` | 1 |
| `(` | 0（入栈后不参与比较） |

## 五、栈与递归：同一件事

```c
递归函数调用时，系统用「函数调用栈」保存：
   返回地址、参数、局部变量

每次递归 = 入栈
每次返回 = 出栈
```

### 这就是「栈溢出」的由来

S1-W8 讲过 `fib(30)` 要调用 166 万次。每次调用压一个栈帧，
递归深度太大时，栈空间耗尽 → **Stack Overflow**。

> ⭐ **任何递归都能用「显式栈 + 循环」改写**，这就是为什么「栈」是理解递归的钥匙。

### 一个对照

```c
/* 递归版 */
int fact(int n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}

/* 用栈的迭代版：把「待乘的数」压栈，再倒着乘回来 */
int factStack(int n) {
    Stack S;
    while (n > 1) { push(&S, n); n--; }
    int r = 1;
    int v;
    while (pop(&S, &v)) r *= v;
    return r;
}
```

两版结果相同，第二版没有递归深度限制。

## 六、还有哪些地方用栈（了解即可）

| 场景 | 为什么用栈 |
|---|---|
| 浏览器前进后退 | 后退时按相反顺序恢复 |
| 编辑器的撤销（Ctrl+Z） | 操作按逆序撤销 |
| 函数调用 | 系统调用栈 |
| 深度优先搜索 DFS | 回溯时要回到上一层 |
| 表达式求值、编译器的语法分析 | 嵌套结构 |
| 进制转换、逆序输出 | 倒序需求 |

> ⭐ **一句话识别法：凡是「要倒着来」「要回到上一步」「要处理嵌套」，就该想到栈。**
