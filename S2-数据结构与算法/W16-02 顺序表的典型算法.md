# W16-02 顺序表的典型算法

> 这一节的六个算法，是软考「线性表」大题的全部原型。
> 它们的共同套路是**双指针或覆盖法**，做完这六道，换个题型也能套出来。

---

## 一、逆置：首尾交换

```c
int i = 0, j = L->length - 1;
while (i < j) {                     /* ⚠️ i < j，不是 i < length */
    int t = L->data[i];
    L->data[i] = L->data[j];
    L->data[j] = t;
    i++;
    j--;
}
```

实测：

```text
原表(奇数个) [1 2 3 4 5 6 7]
逆置后       [7 6 5 4 3 2 1]
原表(偶数个) [1 2 3 4]
逆置后       [4 3 2 1]
原表(单个)   [42]
逆置后       [42]
```

### 为什么是 `i < j`

```text
[1 2 3 4]：i=0,j=3 换 → i=1,j=2 换 → i=2,j=1 停
```

如果写 `i < length`：

```text
i=0 换 3、i=1 换 2、i=2 换 1、i=3 换 0   → 每个元素被换两次，等于白做
```

> ⭐ 时间 O(n)，空间 O(1)。

---

## 二、删除所有指定值：覆盖法

```c
int k = 0;                          /* k = 下一个写入位置 */
for (int i = 0; i < L->length; i++) {
    if (L->data[i] != value) {
        L->data[k++] = L->data[i];
    }
}
L->length = k;
```

实测：

```text
原表   [3 5 3 7 3 9 1 3]
删除后 [5 7 9 1]
删掉 4 个
```

### 为什么覆盖法是对的

```text
k 是写入位置，i 是读取位置。
因为 k <= i 恒成立（k 只在保留时 +1，i 每轮都 +1），
所以 data[k] = data[i] 永远写在「已经读过」的位置上，
绝不会覆盖还没读的数据。
```

### 两种写法的复杂度差一个量级

| 写法 | 做法 | 复杂度 |
|---|---|---|
| ❌ 边扫边挪 | 找到一个就整体前移 | O(n·m)，最坏 **O(n²)** |
| ✅ 覆盖法 | k 记录写入位置，一趟扫完 | **O(n)** |

> ⭐ 覆盖法是「原地删除」的标准做法，W16 后面几个算法都用它。
> 记住这个名字：**用 k 记录写入位置**。

## 三、归并两个有序表

```c
while (i < A->length && j < B->length) {
    if (A->data[i] <= B->data[j]) {
        C->data[k++] = A->data[i++];
    } else {
        C->data[k++] = B->data[j++];
    }
}
while (i < A->length) C->data[k++] = A->data[i++];
while (j < B->length) C->data[k++] = B->data[j++];
```

实测：

```text
表 A      [1 4 7 10]
表 B      [2 3 8 11 15]
归并结果  [1 2 3 4 7 8 10 11 15]
```

> ⭐ 时间 O(n+m)，空间 O(n+m)。
> **前提：两个表必须已经有序**，否则结果不对。
>
> 📌 这是归并排序（S2 后面讲）的核心步骤。

## 四、集合运算：并、交、差

三个算法的骨架**完全一样**，差别只在「什么时候收元素」。

```c
while (i < A->length && j < B->length) {
    if (A->data[i] < B->data[j]) {
        /* 并集：收 A[i]；交集：跳过；差集：收 A[i] */
    } else if (A->data[i] > B->data[j]) {
        /* 并集：收 B[j]；交集：跳过；差集：让 j 前进 */
    } else {
        /* 并集：收一个；交集：收一个；差集：跳过 */
    }
}
```

实测（A = `{1,3,5,7,9,11}`，B = `{2,3,5,8,11,13}`）：

```text
并集 A ∪ B   {1, 2, 3, 5, 7, 8, 9, 11, 13}   12 → 9 个
交集 A ∩ B   {3, 5, 11}
差集 A - B   {1, 7, 9}
```

### 一张表记住三个算法

| 运算 | `A[i] < B[j]` 时 | `A[i] == B[j]` 时 | 剩余部分 |
|---|---|---|---|
| 并集 | 收 `A[i]` | 收一个 | 两边都要接 |
| 交集 | 跳过 `A[i]` | 收 `A[i]` | 都不要 |
| 差集 | 收 `A[i]` | 跳过 | 只接 A 的 |

> ⭐ 记住这张表，三个算法就都记住了。
>
> ⚠️ **并集「相等时只收一个」和交集「相等时收一个」，是去重的关键。**
> 如果并集相等时收了两个，结果就有重复元素。

### 并集去重的另一处细节

`163_seqlist_merge.c` 里那个「合并去重」的版本，相等时是 **i++ 且 j++**：

```c
} else {
    C->data[k++] = A->data[i];
    i++;
    j++;                    /* ⭐ 两个都前进，才不重复 */
}
```

> ⚠️ 如果相等时只 `i++`，那 B 的这个元素下次还会被收，就重复了。
> **代码只差一行，结果完全不同** —— 这是软考改错题的高频点。

## 五、按值分割：双指针

把「小于 x」的放前面，「大于等于 x」的放后面，要求 O(n) 时间 O(1) 空间。

```c
int i = 0, j = L->length - 1;
while (i < j) {
    while (i < j && L->data[i] < x) i++;        /* i 找第一个 >= x 的 */
    while (i < j && L->data[j] >= x) j--;       /* j 找第一个 < x 的 */
    if (i < j) { 交换; i++; j--; }
}
```

实测（`8 3 9 1 5 7 2 6`，x=5）：

```text
原表   [8 3 9 1 5 7 2 6]
分割后 [2 3 1 9 5 7 8 6]
前 3 个都 < 5（2 3 1），后面 5 个都 >= 5（9 5 7 8 6）
```

> ⚠️ **内层循环也必须写 `i < j`。**
> 否则「全是小值」时 i 会一路冲出数组，越界崩溃。

### 稳定性代价

本题的分割**不稳定**：相等元素的相对顺序会变。

| 要求 | 能否同时满足 |
|---|---|
| 原地（O(1) 空间） | ✅ |
| 稳定 | ❌ |
| O(n) 时间 | ✅ |

> ⭐ **三者不可兼得。** 要稳定必须用 O(n) 辅助空间。
> 📌 这就是**快速排序不稳定**的根本原因 —— 它用的就是这个分割。

## 六、循环左移：三次逆置

把前 m 个元素移到后面：

```text
[1 2 3 4 5 6 7]，m=3  →  [4 5 6 7 1 2 3]
```

### 三次逆置法

```c
m = m % L->length;                  /* ⚠️ m 可能大于 n */
if (m == 0) return;

reverseRange(L, 0, m - 1);          /* ① 逆置前 m 个 */
reverseRange(L, m, L->length - 1);  /* ② 逆置后 n-m 个 */
reverseRange(L, 0, L->length - 1);  /* ③ 整体逆置 */
```

实测四组：

```text
m = 3 → [4 5 6 7 1 2 3]
m = 0 → [1 2 3 4 5 6 7]（不变）
m = 7 → [1 2 3 4 5 6 7]（不变，7%7=0）
m = 9 → [3 4 5 6 7 1 2]（9%7=2，等价于左移 2 位）
```

### 为什么三次逆置是对的

设 A = 前 m 个，B = 后 n-m 个，原表是 `AB`。

```text
逆置 A  →  AᴿB
逆置 B  →  AᴿBᴿ
整体逆置 → (AᴿBᴿ)ᴿ = BA      ← 正好是左移 m 位
```

> ⭐ 每一步都是 O(n)，做三次还是 O(n)。

### 三种解法对比

| 方法 | 时间 | 空间 | 说明 |
|---|---|---|---|
| 三次逆置 | O(n) | **O(1)** | 推荐 |
| 辅助数组 | O(n) | O(n) | 最简单 |
| 逐次左移一位 | O(n·m) | O(1) | 最慢 |

> ⚠️ **`m % length` 必须有。** 不取模的话子区间会算出 `[0, 8]`，直接越界。

## 七、去重：有序 vs 无序

### 有序表去重 O(n)

```c
int k = 1;                          /* 第一个一定保留 */
for (int i = 1; i < L->length; i++) {
    if (L->data[i] != L->data[k - 1]) {     /* 和「已保留的最后一个」比 */
        L->data[k++] = L->data[i];
    }
}
L->length = k;
```

实测：

```text
原表   [1 1 2 2 2 3 5 5 8]
去重后 [1 2 3 5 8]
删掉 4 个
```

> ⭐ 比较对象是 `data[k-1]`（已保留的最后一个），**不是 `data[i-1]`**。
> 因为被删元素的位置会被后面的覆盖，`data[i-1]` 可能是已经被丢弃的值。

### 无序表去重 O(n²)

```c
for (int i = 1; i < L->length; i++) {
    int dup = 0;
    for (int t = 0; t < k; t++) {           /* 和「已保留的所有」比 */
        if (L->data[t] == L->data[i]) { dup = 1; break; }
    }
    if (!dup) L->data[k++] = L->data[i];
}
```

实测：

```text
原表   [5 3 5 1 3 5 8 1]
去重后 [5 3 1 8]
删掉 4 个（保留首次出现）
```

### 三种方案对比

| 方法 | 时间 | 空间 | 前提 |
|---|---|---|---|
| 有序去重 | O(n) | O(1) | 表必须有序 |
| 无序去重 | O(n²) | O(1) | 无 |
| **先排序再去重** | **O(n log n)** | O(1) | 无 |

> ⭐ **无序表去重的最优解不是双重循环**，而是「先排序 O(n log n)，再用 O(n) 的有序去重」。
> 总复杂度 O(n log n)，比 O(n²) 好一个量级。

## 八、六个算法的共同套路

| 算法 | 核心技巧 | 复杂度 |
|---|---|---|
| 逆置 | 首尾双指针 | O(n) / O(1) |
| 删除指定值 | **覆盖法（k 记录写入位置）** | O(n) / O(1) |
| 归并有序表 | 双指针取小 | O(n+m) / O(n+m) |
| 集合运算 | 双指针 + 三种收法 | O(n+m) / O(n+m) |
| 按值分割 | 首尾双指针交换 | O(n) / O(1) |
| 循环左移 | 三次逆置 | O(n) / O(1) |
| 去重 | 覆盖法（有序）/ 双重循环（无序） | O(n) 或 O(n²) |

> ⭐ **「双指针」和「覆盖法」两个套路，覆盖了本节全部算法。**
> 后面学链表、排序、图，这两个套路还会反复出现。

## 九、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 逆置 | 补全循环条件 | `i < j`，不是 `i < length` |
| 删除 | 为什么用 k 而不是边删边挪 | 复杂度 O(n) vs O(n²) |
| 归并 | 前提条件 | 两个表必须有序 |
| 集合运算 | 并集/交集的区别 | 相等时收不收、指针怎么走 |
| 去重 | 有序去重的比较对象 | `data[k-1]`，不是 `data[i-1]` |
| 左移 | 三种解法 | 三次逆置最优 |
| 稳定性 | 原地分割稳定吗 | 不稳定，这就是快排不稳定的原因 |
