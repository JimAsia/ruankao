# W15-02 循环与递归的复杂度

> 判断复杂度只有两条路：**循环数层数**、**递归看递推式**。
> 这两条走通，S2 后面所有算法的复杂度你都能自己推，不用背。

---

## 一、十二种循环形态，一次数清

这是本节的骨架。所有考试代码都能拆成这十二种之一或它们的组合。

实测（`153_loop_count.c`）：

| 编号 | 写法 | n=8 | n=32 | 复杂度 |
|---|---|---|---|---|
| ① | `for (i=0; i<n; i++)` | 8 | 32 | **O(n)** |
| ② | `for (i=0; i<n; i+=2)` | 4 | 16 | **O(n)** |
| ③ | `for (i=1; i<n; i*=2)` | 3 | 5 | **O(log n)** |
| ④ | 双层，内层 `j<n` | 64 | 1024 | **O(n²)** |
| ⑤ | 双层，内层 `j<i` | 28 | 496 | **O(n²)** |
| ⑥ | 双层，内层 `j=i` | 36 | 528 | **O(n²)** |
| ⑦ | 双层，内外变量不同 | 64 | 1024 | **O(n·m)** |
| ⑧ | 内层 `j < n*n` | 512 | 32768 | **O(n³)** |
| ⑨ | `for (i=0; i*i<n; i++)` | 3 | 6 | **O(√n)** |
| ⑩ | 三层嵌套 | 512 | 32768 | **O(n³)** |
| ⑪ | 两个并列单层 | 16 | 64 | **O(n)** |
| ⑫ | 外层 n，内层 log | 21 | 135 | **O(n log n)** |

### 逐个数

**① 标准单层 → O(n)**
i 取 0 到 n-1，共 n 个值。

**② 步长 2 → 仍是 O(n)**
i 取 0,2,4,... 约 n/2 次。**除以 2 是常数因子**，不影响量级。同理 `i += 100` 也是 O(n)。

**③ 倍增 → O(log n)**
i 取 1,2,4,8,...,n 共 log₂n 次。实测：

```text
n=8   时 3 次，log2(8)=3
n=16  时 4 次，log2(16)=4
n=32  时 5 次，log2(32)=5
```

> ⭐ 看到 `i *= 2` 或 `i /= 2`，条件反射想 log。

**④ vs ⑤：这是最容易搞混的一对**

```c
/* ④ 内层每次都跑满 n 次 */
for (i = 0; i < n; i++) for (j = 0; j < n; j++) ...   /* n × n = n² */

/* ⑤ 内层跑 i 次 */
for (i = 0; i < n; i++) for (j = 0; j < i; j++) ...   /* 0+1+...+(n-1) = n(n-1)/2 */
```

实测 n=32：④ 是 **1024** 次，⑤ 是 **496** 次，比值 **2.06**。

少了一半，但仍是 **O(n²)** —— 常数因子被忽略。

**⑥ 含对角线 → 也是 O(n²)**
`j` 从 i 到 n-1，共 `n(n+1)/2` 次。n=32 时 528 次。

**⑧ 内层 n×n → O(n³)**
外层 n 次，内层 n² 次，`n × n² = n³`。

**⑨ `i*i < n` → O(√n)**
i 从 0 到 √n-1。实测 n=16 → 4 次，n=32 → 6 次。

> ⭐ 判素数时写 `for (i = 2; i*i <= n; i++)`，就是把 O(n) 降到 O(√n)。
> 这个优化在 S1-W4 的 `ex33` 里用过，现在知道它的复杂度名字了。

**⑪ 并列 vs 嵌套：最容易记错的一条**

```c
/* 并列：相加 */
for (i = 0; i < n; i++) ...;
for (i = 0; i < n; i++) ...;      /* n + n = 2n → O(n) */

/* 嵌套：相乘 */
for (i = 0; i < n; i++)
    for (j = 0; j < n; j++) ...;  /* n × n = n² */
```

> ⭐ **并列相加取最大，嵌套相乘。** 背这一条就够了。

## 二、递归：看「分几支 × 规模怎么变 × 几层停」

递归复杂度写成递推式：

```text
T(n) = a·T(n/b) + f(n)
       ↑     ↑      ↑
     分几支  每支规模  拆分/合并开销
```

### 四种典型，四个结论

| 递推式 | 复杂度 | 典型算法 |
|---|---|---|
| `T(n) = T(n-1) + O(1)` | **O(n)** | 阶乘、递归求和 |
| `T(n) = T(n/2) + O(1)` | **O(log n)** | 二分查找 |
| `T(n) = 2T(n/2) + O(n)` | **O(n log n)** | 归并排序 |
| `T(n) = 2T(n-1) + O(1)` | **O(2ⁿ)** | 汉诺塔 |
| `T(n) = T(n-1) + T(n-2)` | **O(2ⁿ)** | 朴素斐波那契 |

### 实测验证

**阶乘 O(n)**：

```text
n=5   → 5 次
n=10  → 10 次
n=20  → 20 次
```

次数正好等于 n —— 每层只分 1 支，规模减 1。

**朴素斐波那契 O(2ⁿ)**：

```text
n=10  → 177 次
n=15  → 1973 次      增 11.15 倍
n=20  → 21891 次     增 11.10 倍
n=25  → 242785 次    增 11.09 倍
n=30  → 2692537 次   增 11.09 倍
```

每加 5，次数涨约 **11 倍**。

> 为什么不是 2⁵ = 32 倍？因为 `T(n)=T(n-1)+T(n-2)` 的增长因子是**黄金比 1.618**，1.618⁵ ≈ 11.1。
> 软考按 **O(2ⁿ)** 回答即可，指数级就够了。

**二分查找 O(log n)**：

```text
数组长度  比较次数  log2(n)
16        5         4
64        7         6
256       9         8
1024      11        10
```

1024 个元素最多比 11 次，顺序查找最坏要 1024 次。

**归并排序 O(n log n)**：

```text
n     比较次数   n log2 n
32    80         160
64    192        384
128   448        896
256   1024       2048
512   2304       4608
```

比较次数稳定是 `n·log₂n` 的**一半**左右 —— 同阶，常数因子。

> ⭐ 归并排序的价值：**稳定在 O(n log n)**，不像快排会退化到 O(n²)。

**汉诺塔 O(2ⁿ)**：

```text
盘子数  调用次数  2^(n+1)-1   移动步数 2^n-1
4       31        31          15
8       511       511         255
16      131071    131071      65535
```

> ⚠️ 这里调用次数是 `2^(n+1)-1`，不是 `2^n-1`，**差一倍**。
> 因为本函数把「盘数为 0 的空调用」也数进去了。
> 两者差一个常数因子 2 —— 按大 O 规则，都是 **O(2ⁿ)**。
>
> 这又是一个「常数不影响量级」的实例。

## 三、三种递推式的速判口诀

不用背公式，看形式就能判：

```text
规模减 1 + 1 支  → O(n)
规模减半 + 1 支  → O(log n)
规模减半 + 2 支  → 看合并开销
                    合并 O(1) → O(n)
                    合并 O(n) → O(n log n)
规模减 1 + 2 支  → O(2ⁿ)   ← 才会爆炸
```

### 最容易错的一个：`规模减半 + 2 支` 不等于指数级

`T(n) = 2T(n/2) + 1`，答案是多少？

实测（`ex155` 的 r2）：

```text
n=8   → 15 次
n=16  → 31 次
n=32  → 63 次
n=64  → 127 次
```

正好是 `2n - 1`，**线性**，不是指数级。

> ⭐ 为什么？因为「分支多」和「规模减半」同时发生：
> 树的叶子数 = `2^(层数)` = `2^(log₂n)` = **n**，总节点数约 2n。
>
> 而指数级是「分 2 支但规模只减 1」，叶子数才是 `2ⁿ`。
>
> **一句话：看叶子数，不是看分支数。**

## 四、软考怎么考

| 考点 | 典型问法 | 应对 |
|---|---|---|
| 单层循环 | 给代码问复杂度 | 看步长：`++` → n，`*=2` → log |
| 双层嵌套 | 内层边界依赖外层 | 求和公式，结果通常仍是 n² |
| 并列循环 | 两段独立的循环 | 相加取最大 |
| 递归复杂度 | 给递推式或代码 | 套四种典型 |
| 快排最坏 | 什么时候退化 | 已有序 + 取首元素为基准 → O(n²) |
| 二分前提 | 能不能用 | 必须有序 + 随机访问 |

> 📌 **判断题小技巧**：如果代码里出现了 `while (n > 0) n /= 2` 这类，直接找 log。
> 如果出现了两层 `for` 且内层上限是 n，直接 n²。90% 的题目这两条就够了。
