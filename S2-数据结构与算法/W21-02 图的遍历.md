# W21-02 图的遍历

> 图的遍历和树很像，但多了一个必须做的事：**标记已访问**。
> 因为图有环，不标记就死循环。

---

## 一、DFS：一条路走到底

```c
void dfs(Graph *G, int v) {
    visited[v] = 1;
    printf("%d ", v);
    for (int w = 0; w < G->n; w++) {
        if (G->matrix[v][w] && !visited[w]) dfs(G, w);
    }
}
```

### 实测（6 顶点）

```text
图：0-1, 0-2, 1-3, 2-3, 3-4, 4-5

从 0 出发：0 1 3 2 4 5
走法：0 → 1 → 3 → 2（走不通了回退）→ 3 → 4 → 5
检查邻接关系 36 次 = n² = 6²
```

### DFS 也可以用显式栈

```c
stack[++top] = start;
while (top >= 0) {
    v = stack[top--];
    if (visited[v]) continue;
    visited[v] = 1;
    printf("%d ", v);
    for (w = n-1; w >= 0; w--)      /* 逆序压栈，保证出栈顺序递增 */
        if (G->matrix[v][w] && !visited[w]) stack[++top] = w;
}
```

实测结果与递归版**完全一致**。

> ⭐ **递归就是用系统栈实现的 DFS。**
> 系统栈 = 你写递归；显式栈 = 自己用数组模拟。
> S1-W8 讲过「递归和栈是同一件事」，这里是它的第二个例子。

## 二、BFS：一层一层扩

```c
void bfs(Graph *G, int start) {
    int q[MAXV], front = 0, rear = 0;
    visited[start] = 1;
    dist[start] = 0;
    q[rear++] = start;

    while (front < rear) {
        int v = q[front++];
        printf("%d(%d) ", v, dist[v]);
        for (int w = 0; w < G->n; w++) {
            if (G->matrix[v][w] && !visited[w]) {
                visited[w] = 1;             /* ⚠️ 入队时就标记 */
                dist[w] = dist[v] + 1;
                q[rear++] = w;
            }
        }
    }
}
```

### 实测

```text
从 0 出发：0(0) 1(1) 2(1) 3(2) 4(3) 5(4)

第 0 层：0
第 1 层：1 2
第 2 层：3
第 3 层：4
第 4 层：5
```

> ⭐ **括号里的层数就是「从 0 到该点的最少边数」。**
> 这是 BFS 最重要的用途：**无权图的最短路径**。

---

## 三、两个必须注意的点

### ① 必须标记已访问

图可以有环，不标记会无限循环。

> 树的遍历**不需要**标记，因为树无环、且每个节点只有一个父亲。
> 这是图和树遍历最大的区别。

### ② BFS 的标记时机：入队时，不是出队时

```text
✅ 入队时标记：每个点只入队一次
❌ 出队时标记：同一点可能被多个邻居重复入队
```

后果：队列膨胀，层数可能被后入队的（更大的值）覆盖。

## 四、DFS vs BFS

| 对比项 | DFS | BFS |
|---|---|---|
| 走法 | 一条路走到底 | 一层一层扩 |
| 用的结构 | **栈（或递归）** | **队列** |
| 最短路径 | 不适合 | **适合（无权图）** |
| 典型用途 | 判连通、拓扑排序、判环 | 最短跳数、层序 |
| 内存 | 少（只看一条路） | 多（存整层） |

> ⭐ 记法：
> **DFS = 深度优先 = 栈 = 一条道走到黑**
> **BFS = 广度优先 = 队列 = 涟漪式扩散**

---

## 五、复杂度

| 存储方式 | 复杂度 | 原因 |
|---|---|---|
| 邻接矩阵 | **O(n²)** | 每个顶点都要扫一整行 |
| 邻接表 | **O(n+e)** | 只扫实际存在的边 |

实测：本例用矩阵存储，检查邻接关系 36 次 = n² = 6²。

> ⭐ 稠密图两者差不多，稀疏图邻接表明显快。
> 这和 W21-01 的存储选择是同一个道理。

## 六、非连通图：要循环所有顶点

```c
for (int v = 0; v < n; v++) {
    if (!visited[v]) {
        comp++;                     /* 分量数 +1 */
        dfs(G, v);                  /* 把一个分量全标记掉 */
    }
}
```

实测（图：0-1，2-3，4，5）：

```text
[分量1: 0 1] [分量2: 2 3] [分量3: 4] [分量4: 5]
连通分量数 = 4
```

> ⭐ **启动次数 = 连通分量数。**
> 这也是判断「图是否连通」的方法：分量数 == 1 则连通。
>
> 📌 软考常考：
> - 「有几个连通分量」
> - 「n 个顶点 c 个分量，生成森林有几条边」→ **n - c**

## 七、遍历能解决哪些问题

| 问题 | 用哪个 | 怎么做 |
|---|---|---|
| 图是否连通 | DFS/BFS | 从任一点出发，能访问完就连通 |
| 有几个连通分量 | DFS | 循环所有点，每次启动计数 |
| 无权图最短路径 | **BFS** | 记录层数 |
| 判断有环 | DFS | 遇到「正在访问」的点即有环 |
| 拓扑排序 | DFS/BFS | 见 W22 |
| 二分图判定 | BFS | 染色，相邻点必须异色 |

## 八、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 遍历序列 | 给图求 DFS/BFS 序列 | 手算，注意顺序可能不唯一 |
| 用的结构 | DFS/BFS 各用什么 | 栈 / 队列 |
| 复杂度 | 邻接矩阵的 DFS | O(n²) |
| 复杂度 | 邻接表的 DFS | O(n+e) |
| 连通分量 | 有几个 | 启动 DFS 次数 |
| 最短跳数 | 用什么算法 | BFS |
| 为什么标记 | 不标记会怎样 | 有环时死循环 |

> ⚠️ **遍历序列通常不唯一**（邻居访问顺序取决于存储顺序）。
> 软考给的选项里可能有多个合法的，但只有一个错得离谱。
