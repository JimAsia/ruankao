## 三、自测六题

**1. `3n² + 5n + 100` 的复杂度是多少？化简的规则是什么？**

**2. 把下面几个按增长快慢排序：`O(n log n)`、`O(2ⁿ)`、`O(1)`、`O(n²)`、`O(log n)`、`O(n)`**

**3. 下面两段代码的复杂度各是多少？**

```c
/* A */
for (int i = 0; i < n; i++)
    for (int j = 0; j < i; j++) sum++;

/* B */
for (int i = 1; i < n; i *= 2) sum++;
```

**4. 递归方程 `T(n) = 2T(n/2) + O(1)` 的复杂度是多少？为什么不是 O(2ⁿ)？**

**5. 一个递归函数递归深度为 n，它的空间复杂度是多少？为什么？**

**6. n = 10⁶ 时，O(n²) 的算法大约要跑多久（假设每秒 1 亿次操作）？**

## 四、答案与解析

**1. O(n²)。**

三条规则：
1. 去掉常数系数：`3n²` → `n²`
2. 去掉低阶项：`n² + n` → `n²`（n 比 n² 小一个量级）
3. 去掉常数：`n + 100` → `n`（100 不随 n 增长）

> ⭐ 判断依据：n 很大时，`n²` 项占绝对主导。n=1000 时 `3n²=300万`，`5n+100=5100`，差 588 倍。

**2. `O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(2ⁿ)`**

两头最容易记：`O(1)` 最慢增长（不变），`O(2ⁿ)` 最快（爆炸）。

**3. A 是 O(n²)，B 是 O(log n)。**

A：内层次数 `0+1+2+...+(n-1) = n(n-1)/2`，平方级。
> ⚠️ 这里**必须求和**，不能因为「内层次数在变」就以为更简单。

B：i 取 1,2,4,... 共 `log₂n` 次。

**4. O(n)，不是 O(2ⁿ)。**

`T(n) = 2T(n/2) + 1`，解出来是 `T(n) = 2n - 1`。

实测 n=8/16/32/64 分别是 15/31/63/127，正好 `2n-1`。

> ⭐ 关键：**看叶子数，不是看分支数。**
> 叶子数 = `2^(层数)` = `2^(log₂n)` = **n**。
> 指数级是「分 2 支但规模只减 1」，那才是指数。

**5. O(n)。**

每递归一层，栈上就压一个帧（返回地址 + 参数 + 局部变量）。深度 n 就有 n 个帧同时存在。

> ⚠️ 这是新手最常漏的。看到「时间 O(n)」就以为空间是 O(1)，其实递归的栈空间也是 O(n)。
> n = 10 万层时会栈溢出。

**6. 约 2.8 小时。**

`(10⁶)² = 10¹²` 次操作，除以 `10⁸` 次/秒 = `10⁴` 秒 ≈ 2.8 小时。

> 实测程序 `ex156` 的输出正是 `2.8小时`。
