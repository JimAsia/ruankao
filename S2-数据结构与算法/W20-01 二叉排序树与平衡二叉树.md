# W20-01 二叉排序树与平衡二叉树

> 二叉排序树（BST）让「查找」有了树形结构的高效实现。
> 它的核心结论只有一句：**复杂度取决于树的高度，不是节点数**。
> 由此引出「平衡」这个贯穿后半程的主题。

---

## 一、二叉排序树（BST）的定义

对每个节点，满足：

```text
左子树所有值 < 根的值 < 右子树所有值
```

```text
        50
       /  \
     30    70
    /  \  /  \
   20  40 60  80
```

### 核心性质：中序遍历 = 升序

实测（`201_bst.c`）：

```text
插入 50 30 70 20 40 60 80
中序遍历：20 30 40 50 60 70 80    ← 升序！
```

> ⭐ **中序遍历 BST 得到升序序列，这是验证 BST 正确性的标志。**
> 反过来，「中序升序」也是判断一棵树是不是 BST 的常用方法。

---

## 二、查找：比大小往下走

```c
BSTNode *bstSearch(BSTNode *root, int v) {
    while (root != NULL && root->data != v) {
        if (v < root->data) root = root->left;
        else                root = root->right;
    }
    return root;
}
```

实测：

```text
找 60：50 → 70 → 60（比根大走右，比 70 小走左）
找 99：没找到
```

> ⭐ 每比较一次，搜索范围减半 → O(深度)。
> 平衡时深度 ≈ log2(n)，所以是 O(log n)。

---

## 三、插入：插在叶子位置

```c
BSTNode *bstInsert(BSTNode *root, int v) {
    if (root == NULL) return make(v);       /* 空位插入 */
    if (v < root->data) root->left = bstInsert(root->left, v);
    else if (v > root->data) root->right = bstInsert(root->right, v);
    return root;                            /* 相等则忽略 */
}
```

> ⭐ 新节点永远插在「叶子」位置，一路比大小走到空位，那里本来就满足大小关系。
> 所以插入**不需要调整整棵树**，O(log n)。

---

## 四、删除：三种情况

| 情况 | 描述 | 处理 |
|---|---|---|
| 1 | 叶子节点 | 直接删 |
| 2 | 只有一个孩子 | 孩子顶上来 |
| 3 | 有两个孩子 | 用右子树最小值替代 |

```c
BSTNode *bstDelete(BSTNode *root, int v) {
    if (root == NULL) return NULL;
    if (v < root->data)      root->left  = bstDelete(root->left, v);
    else if (v > root->data) root->right = bstDelete(root->right, v);
    else {
        if (root->left == NULL)  return root->right;     /* 情况1/2a */
        if (root->right == NULL) return root->left;      /* 情况2b */
        /* 情况3：右子树最小值替代 */
        BSTNode *min = findMin(root->right);
        root->data = min->data;
        root->right = bstDelete(root->right, min->data);
    }
    return root;
}
```

实测：

```text
删叶子 20 → 中序仍升序 ✓
删两孩子的 70 → 用 80 替代，仍升序 ✓
删根 50 → 仍升序 ✓
```

> ⭐ 情况 3 选「右子树最小值」（也就是中序的后继），
> 是为了保证中序仍升序。

## 五、BST 的致命缺陷：可能退化成斜树

如果按**升序**插入 `10 20 30 40 50`：

```text
10
  \
   20
     \
      30
        \
         40
           \
            50
```

实测高度 = 5 = 节点数，退化成**斜树**。

### 复杂度和高度的关系

| 状态 | 高度 | 查找/插入/删除 |
|---|---|---|
| 平衡 | ≈ log2(n) | **O(log n)** |
| 退化成斜树 | = n | **O(n)** |

> ⭐ **BST 的复杂度 = O(高度)，不是 O(节点数)。**
>
> 这就是为什么要「平衡二叉树」—— 保证高度始终是 O(log n)。

---

## 六、平衡二叉树（AVL）

### 定义

```text
任意节点的左右子树高度差 <= 1
```

实测：

```text
平衡树（3 层满）：高度差 <= 1，是 ✓
斜树：高度差 = 3，否 ✗
```

### 四种失衡与旋转

| 失衡类型 | 怎么插出来的 | 处理 |
|---|---|---|
| LL | 左孩子的左子树插入 | **右旋**一次 |
| RR | 右孩子的右子树插入 | **左旋**一次 |
| LR | 左孩子的右子树插入 | 先左旋后右旋 |
| RL | 右孩子的左子树插入 | 先右旋后左旋 |

> 📌 判断方法：从「失衡节点」往「插入方向」走两步，两个 L 就是 LL，先 L 后 R 就是 LR。

### 为什么 AVL 能保证 O(log n)

AVL 树的高度始终是 O(log n)（约 1.44 log n），
所以查找、插入、删除都稳定在 O(log n)，**不会退化**。

| 类型 | 查找 | 插入删除 | 是否会退化 |
|---|---|---|---|
| 普通 BST | O(log n)~O(n) | 同左 | 会 |
| AVL 平衡树 | **稳定 O(log n)** | **稳定 O(log n)** | 不会 |

> 📌 软考主要考「判断是否平衡」「四种旋转」，不要求写旋转代码。

## 七、二叉树家族总结

| 类型 | 特点 | 查找复杂度 |
|---|---|---|
| 普通二叉树 | 无约束 | O(n) 最坏 |
| 二叉排序树 BST | 左<根<右 | O(log n) ~ O(n) |
| 平衡二叉树 AVL | 高度差 ≤ 1 | **O(log n) 稳定** |
| 哈夫曼树 | WPL 最小 | —（用于编码） |
| 堆 | 完全二叉树 + 堆序 | 取最大/最小 O(1) |
