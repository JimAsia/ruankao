# W20-02 哈夫曼树与堆

> 两个「最值问题」的数据结构：
> **哈夫曼树**求 WPL（带权路径长度）最小，用于压缩；
> **堆**求「随时取最大/最小」，用于优先级队列和堆排序。
> 两者都是软考选择题的高频考点。

---

## 一、哈夫曼树：WPL 最小的二叉树

### 核心概念

```text
WPL（带权路径长度）= 所有叶子节点的「权值 × 到根的路径长度」之和
```

权值通常是「出现频率」。频率高的字符编码短，平均编码就短。

### 构造算法（贪心）

```text
1. 把所有权值做成单节点
2. 每次取两个【权值最小】的节点，合并成一个新节点（权 = 两者之和）
3. 重复，直到只剩一个根
```

### 实测（`202_huffman.c`）

权值 `{5, 32, 18, 7, 25}`：

```text
构造出的 WPL = 184

哈夫曼编码（左 0 右 1）：
    权值 32 → 0          （最短，出现最多）
    权值 25 → 10
    权值 18 → 111
    权值 5  → 1100       （最长，出现少）
    权值 7  → 1101
```

> ⭐ 观察：权值越大，编码越短。这正是压缩的原理。

### WPL 的计算

```text
权值 32 → 深度 1
权值 25 → 深度 2
权值 18 → 深度 3
权值 5  → 深度 4
权值 7  → 深度 4

WPL = 32×1 + 25×2 + 18×3 + 5×4 + 7×4
    = 32 + 50 + 54 + 20 + 28 = 184
```

另一个经典例子（教材常用）：权值 `{2, 4, 5, 7}` 的 WPL = **35**。

### 哈夫曼树的两条性质（必记）

**① 没有度为 1 的节点**

因为每次都是「取两个合并成一个」，只产生度为 2 的内部节点。

**② n 个叶子节点的哈夫曼树，总节点数 = 2n - 1**

```text
n 个叶子 + (n-1) 个内部节点 = 2n - 1
```

> 📌 这两条是选择题原题，尤其是「2n-1」。

### 哈夫曼编码是前缀码

```text
前缀码：任何一个编码都不是另一个编码的前缀。
例如 0 / 10 / 110 / 111 是前缀码，0 / 01 不是。
```

> ⭐ 为什么必须是前缀码：否则解码时无法判断边界。
> 收到 `01`，不知道是一个 `01`，还是 `0` 后面跟 `1`。
> 📌 哈夫曼编码天然是前缀码，因为字符都在叶子上。

## 二、堆：完全二叉树 + 堆序

### 定义

```text
大顶堆：每个节点 >= 它的孩子（根是最大值）
小顶堆：每个节点 <= 它的孩子（根是最小值）
```

堆是**完全二叉树**，用数组存储（下标从 1 开始）：

```text
节点 i 的左孩子 = 2i
节点 i 的右孩子 = 2i + 1
节点 i 的父节点 = ⌊i/2⌋
```

### 为什么堆必须是完全二叉树

因为只有完全二叉树才能用数组高效存储（下标规律不浪费空间）。
一般树用数组存会浪费（W19 讲过）。

### 建堆（大顶堆）

从最后一个非叶子节点 `n/2` 开始，往前逐个「向下调整」。

```c
void buildHeap(int a[], int n) {
    for (int i = n / 2; i >= 1; i--) {
        siftDown(a, i, n);
    }
}
```

实测：

```text
原始数组 [49 38 65 97 76 13 27 49]
建堆后   [97 76 65 49 49 13 27 38]
堆顶 = 97（最大值）
```

### 建堆复杂度为什么是 O(n) 而不是 O(n log n)

```text
直觉：n/2 个节点，每个向下调整 O(log n) → 看着像 O(n log n)

实际：
  最底层（约 n/2 个）根本不用调整
  倒数第二层（约 n/4 个）最多下沉 1 层
  倒数第三层（约 n/8 个）最多下沉 2 层
  ...

总下沉次数 = 0×(n/2) + 1×(n/4) + 2×(n/8) + ... < n
```

> ⭐ 这个级数收敛到 O(n)。**软考选择题考过，答案是 O(n)。**

## 三、堆排序

```c
buildHeap(a, n);            // ① 建堆 O(n)

for (int i = n; i > 1; i--) {
    swap(a[1], a[i]);       // ② 堆顶（最大）换到末尾
    siftDown(a, 1, i-1);    // ③ 恢复堆
}
```

实测：

```text
排序后(升序)：13 27 38 49 49 65 76 97
```

### 为什么升序

每次把堆顶（当前最大值）换到末尾，换过去就不再参与调整，
相当于从后往前「固定」了最大、次大、……、最小。

### 堆排序 vs 其他 O(n log n) 排序

| 排序 | 时间 | 空间 | 稳定 |
|---|---|---|---|
| 堆排序 | O(n log n) | **O(1)** | 不稳定 |
| 归并排序 | O(n log n) | O(n) | 稳定 |
| 快速排序 | O(n log n) 平均 | O(log n) | 不稳定 |

> ⭐ 堆排序的两大优势：
> 1. **空间 O(1)**（原地，不需要额外数组）
> 2. **最坏也是 O(n log n)**（不会像快排退化到 O(n²)）
>
> 代价：不稳定，常数比快排大。

## 四、堆的用途：优先级队列

堆最常见的用途不是排序，而是**优先级队列**（随时插入，随时取最大/最小）。

| 操作 | 普通数组 | 有序数组 | 堆 |
|---|---|---|---|
| 取最大 | O(n) | O(1) | **O(1)** |
| 插入 | O(1) | O(n) | **O(log n)** |
| 删除最大 | O(n) | O(1) | **O(log n)** |

> ⭐ 堆的插入 + 删除都是 O(log n)，综合最优。
> 这也是为什么操作系统调度、Dijkstra 算法都用堆。

## 五、线索二叉树（补充考点）

二叉树的 n 个节点有 2n 个指针域，其中 **n+1 个是空的**。

```text
推导：n 个节点 2n 个指针，n-1 条边用了 n-1 个，剩 2n-(n-1) = n+1 个空指针
```

线索二叉树：利用这些空指针，指向中序的「前驱/后继」，加快遍历。

> 📌 「空指针数 = n+1」是软考必记的数字。

## 六、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| WPL | 给权值求 WPL | 手算，权×深度求和 |
| 哈夫曼树性质 | 有没有度为 1 的节点 | 没有 |
| 哈夫曼树性质 | n 叶子总节点数 | 2n-1 |
| 前缀码 | 哈夫曼编码是什么 | 前缀码 |
| 堆 | 大顶堆堆顶是什么 | 最大值 |
| 建堆复杂度 | O(n) 还是 O(n log n) | **O(n)** |
| 堆排序 | 空间复杂度 | O(1) |
| 堆排序 | 稳定性 | 不稳定 |
| 线索二叉树 | 空指针数 | n+1 |
