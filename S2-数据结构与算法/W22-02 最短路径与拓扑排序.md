## 一、Dijkstra：单源最短路径

### 思路（贪心）

```text
维护 dist[]：dist[i] = 源点到 i 的当前最短距离

每轮：
  ① 在未确定的点里，选 dist 最小的，把它「确定」下来
  ② 用它去「松弛」邻居：如果绕道更近，就更新
重复 n-1 轮
```

### 松弛：所有最短路径算法的核心一行

```c
if (dist[u] + cost[u][v] < dist[v])
    dist[v] = dist[u] + cost[u][v];
```

> ⭐ 全部最短路径算法（Dijkstra / Bellman-Ford / Floyd）都有这一句。
> 记住「松弛」这个词，就是「绕道试试会不会更近」。

### 实测

```text
有向图：0→1(10) 0→3(30) 0→4(100) 1→2(50) 2→3(20) 2→4(10) 3→4(60)

初始化 dist：0 INF 10 INF 30 100（源点 0 已确定）
  第 1 步：确定顶点 2（dist=10）
      松弛 3：INF → 60（经 2）
  第 2 步：确定顶点 4（dist=30）
      松弛 3：60 → 50（经 4）
      松弛 5：100 → 90（经 4）
  第 3 步：确定顶点 3（dist=50）
      松弛 5：90 → 60（经 3）
  第 4 步：确定顶点 5（dist=60）
```

最终结果：

| 目标 | 最短距离 | 路径 |
|---|---|---|
| 0 | 0 | 0 |
| 3 | **50** | 0 → 4 → 3 |
| 4 | 30 | 0 → 4 |
| 5 | **60** | 0 → 4 → 3 → 5 |

> ⭐ 注意 0→3：没有直达边，0→2→3 = 10+50 = 60，但 0→4→3 = 30+20 = **50** 更短。
> 这就是「松弛」的意义。

### 为什么不能有负权边

```text
假设 0→1 权 10，0→2 权 1，2→1 权 -100

Dijkstra 第一步会确定 2（dist=1），
然后松弛 1：dist[1] = 1 + (-100) = -99 ✓

但如果先确定 1（dist=10），后面发现走 2 更近就来不及了 ——
已经「确定」的点不会再改。
```

> ⭐ **负权让「绕远路反而更近」，贪心失效。**
> 有负权要用 Bellman-Ford（O(ne)）或 SPFA。

## 二、三种最短路径算法（必背对比）

| 算法 | 复杂度 | 解决什么 | 支持负权 |
|---|---|---|---|
| **BFS** | O(n+e) | 无权图单源最短 | — |
| **Dijkstra** | O(n²) | 单源最短路径 | **不支持** |
| **Bellman-Ford** | O(ne) | 单源 + 判负环 | 支持 |
| **Floyd** | O(n³) | **所有点对**最短路径 | 支持 |

> 📌 软考选择题的经典区分：
> - 「一个源点到所有点」→ **Dijkstra**
> - 「所有顶点对之间」→ **Floyd**
> - 「无权图」→ **BFS** 就够

## 三、拓扑排序：AOV 网

### 什么是 AOV 网

**AOV（Activity On Vertex）**：顶点表示活动，边表示优先关系。

```text
学 A 才能学 B  →  边 A→B
```

拓扑排序：求一个合法的执行顺序，使得每个活动都在它的所有前驱之后。

### 算法（Kahn）

```text
① 统计所有顶点的入度
② 入度为 0 的顶点入队
③ 出队一个，输出；把它所有后继的入度减 1
④ 减到 0 的就入队
⑤ 重复直到队列空
```

### 实测

```text
图：0→1 0→2 1→3 1→4 2→4 3→5 4→5

初始入度：0:0  1:1  2:1  3:1  4:2  5:2
入度为 0 的入队：0

  输出 0  →  入度归零入队：1 2
  输出 1  →  入度归零入队：3
  输出 2  →  入度归零入队：4
  输出 3
  输出 4  →  入度归零入队：5
  输出 5

拓扑序列：0 → 1 → 2 → 3 → 4 → 5
```

> ⭐ **拓扑序列不唯一。** 入度为 0 的点谁先谁后都行。
> 上面 `0 2 1 4 3 5` 也合法。

### 第二个用途：判断有环

```c
return (cnt == n) ? 1 : 0;      /* 输出数 == n → 无环 */
```

实测（有环图 0→1→2→0）：

```text
初始入度：0:1 1:1 2:1
入度为 0 的入队：（没有）
结果：失败 → 有环 ✓
```

> ⭐ **有环的图里，环上每个点入度都 ≥ 1，永远进不了队列。**
> 所以「输出顶点数 < 总顶点数」就是有环。

### 怎么判断一个序列是否合法

软考常给四个序列问「哪个不是合法拓扑序列」。

判断方法：**按序列顺序一个个看，每个点出现时，它的所有前驱必须已经出现过。**

```text
图：0→1 0→2 1→3 2→3

✅ 0 1 2 3    （3 出现时 1、2 都在了）
✅ 0 2 1 3
❌ 0 1 3 2    （3 出现时 2 还没出现）
❌ 1 0 2 3    （1 出现时 0 还没出现）
```

## 四、关键路径：AOE 网

### AOV vs AOE

| 对比 | AOV 网 | AOE 网 |
|---|---|---|
| 顶点表示 | 活动（任务） | 事件（状态） |
| 边表示 | 优先关系 | 活动（带持续时间） |
| 用于 | 拓扑排序 | 关键路径 |
| 有无权值 | 无权 | 边有权（时间） |

### 关键路径的定义

```text
关键路径 = 从源点到汇点的【最长】路径
```

> ⭐ **为什么是最长？** 因为最长的活干完了才能收工。
> 关键路径的长度 = 整个工程的最短完成时间。

### 四个术语

| 术语 | 含义 | 怎么算 |
|---|---|---|
| `ve(i)` | 事件 i 的最早发生时间 | 从前往后推，取 **max** |
| `vl(i)` | 事件 i 的最晚发生时间 | 从后往前推，取 **min** |
| `e(a)` | 活动 a 的最早开始时间 | = 起点的 `ve` |
| `l(a)` | 活动 a 的最晚开始时间 | = 终点的 `vl` − 活动时长 |

### 关键活动

```text
关键活动 = e(a) == l(a) 的活动（没有时间余量）
关键路径上的活动全是关键活动
```

> ⭐ **缩短工期只能缩短关键活动。** 缩短非关键活动没用（它有富余时间）。
> 📌 这是软考选择题的经典问法。

## 五、一张图理清所有图算法

| 问题 | 算法 | 复杂度 | 关键点 |
|---|---|---|---|
| 遍历 | DFS | O(n²) / O(n+e) | 栈 / 递归 |
| 遍历 | BFS | O(n²) / O(n+e) | 队列 |
| 最小生成树 | Prim | O(n²) | 加点，稠密图 |
| 最小生成树 | Kruskal | O(e log e) | 加边 + 并查集，稀疏图 |
| 单源最短路 | Dijkstra | O(n²) | 贪心 + 松弛，无负权 |
| 所有点对最短路 | Floyd | O(n³) | 三重循环 |
| 拓扑排序 | Kahn | O(n+e) | 入度为 0 入队 |
| 判环（有向） | DFS 三色 / 拓扑 | O(n+e) | 灰色回边 / 输出数 < n |
| 判环（无向） | 并查集 | O(e α(n)) | 两端已连通即成环 |
| 关键路径 | 拓扑 + 逆拓扑 | O(n+e) | ve 取 max，vl 取 min |
