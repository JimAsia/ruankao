# W21-01 图的概念与存储

> 树是「一对多」，图是「多对多」—— 最一般的结构。
> 图这一章概念多、算法多，但**选择题考的其实是那几个固定结论**，先把它们记住。

---

## 一、图的基本术语

```text
   0 ----- 1
   |    /  |
   |  /    |
   2 ----- 3
```

| 术语 | 含义 |
|---|---|
| 顶点（V） | 图中的点 |
| 边（E） | 连接两点的线 |
| 无向图 | 边没有方向，`(u,v)` |
| 有向图 | 边有方向（弧），`<u,v>` |
| 度 | 与该点相连的边数 |
| 入度/出度 | 有向图里，指向该点的边数 / 从该点出发的边数 |
| 路径 | 从一个点到另一个点经过的顶点序列 |
| 连通 | 两点之间有路径 |
| 连通图 | 任意两点都连通 |
| 连通分量 | 无向图的极大连通子图 |
| 强连通 | 有向图里 u 能到 v，v 也能到 u |

---

## 二、完全图：两个必背公式

### 无向完全图：`n(n-1)/2` 条边

n 个顶点，每两个之间一条边。相当于从 n 个点里选 2 个，组合数 `C(n,2) = n(n-1)/2`。

### 有向完全图：`n(n-1)` 条边

每两个顶点之间**两条边**（双向），是上面的 2 倍。

实测：

```text
顶点数 n   无向完全图      有向完全图
3          n(n-1)/2 = 3    n(n-1) = 6
4          6                12
5          10               20
6          15               30
8          28               56
```

> ⭐ 这两个公式软考几乎每年都考，必须张口就来。

## 三、度的两个等式（必考）

### 无向图：所有顶点的度之和 = 2e

因为每条边被两个端点各数了一次。

实测（6 顶点 6 边）：

```text
各顶点的度：0:2  1:2  2:2  3:3  4:2  5:1
度之和 = 12 = 2×6 ✓
```

### 有向图：入度之和 = 出度之和 = e

每条边贡献 1 个出度 + 1 个入度。

实测（6 边）：

```text
入度之和 = 6，出度之和 = 6，边数 = 6 ✓
```

> 📌 这两个等式常用来「已知度求边数」或「验证答案」。

## 四、邻接矩阵：二维数组

```c
typedef struct {
    int matrix[MAXV][MAXV];     /* 1 表示相邻 */
    int n, e;
} MatrixGraph;

/* 无向图加边：对称位置都置 1 */
G->matrix[u][v] = 1;
G->matrix[v][u] = 1;
```

实测（6 顶点 6 边）：

```text
     0 1 2 3 4 5
  0  0 1 1 0 0 0
  1  1 0 0 1 0 0
  2  1 0 0 1 0 0
  3  0 1 1 0 1 0
  4  0 0 0 1 0 1
  5  0 0 0 0 1 0
  占用 36 个 int（144 字节）
```

### 特点

| 项 | 值 | 说明 |
|---|---|---|
| 空间 | **O(n²)** | 和边数无关 |
| 判断 i,j 相邻 | **O(1)** | 直接查 `matrix[i][j]` |
| 找 i 的所有邻居 | O(n) | 扫一整行 |
| 无向图 | 沿对角线对称 | 可以只存一半 |

> ⚠️ 稀疏图（边很少）用矩阵极度浪费：
> 1000 个顶点、1000 条边，矩阵要 100 万个格子，其中 99.8% 是 0。

## 五、邻接表：每个顶点挂一条链表

```c
typedef struct EdgeNode {
    int adjvex;                 /* 邻接点 */
    int weight;
    struct EdgeNode *next;
} EdgeNode;

typedef struct {
    EdgeNode *head[MAXV];       /* 每个顶点一个链表头 */
    int n, e;
} ListGraph;
```

实测：

```text
   0 → 2 → 1
   1 → 3 → 0
   2 → 3 → 0
   3 → 4 → 2 → 1
   4 → 5 → 3
   5 → 4
   边节点 12 个（无向图 = 2e）
```

> ⭐ 注意顺序是**倒的**（头插法）。想让顺序和输入一致就改尾插，但要维护尾指针。
> 遍历时顺序不影响正确性，软考不纠结这点。

### 特点

| 项 | 值 | 说明 |
|---|---|---|
| 空间 | **O(n+e)** | 只存实际存在的边 |
| 判断 i,j 相邻 | O(度) | 要遍历链表 |
| 找 i 的所有邻居 | **O(度)** | 直接顺着链表走 |
| 无向图 | 边节点 = 2e | 每条边存两次 |

---

## 六、两种存储怎么选（软考原题）

| 对比项 | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | O(n²) | **O(n+e)** |
| 判断 i,j 相邻 | **O(1)** | O(度) |
| 找 i 的所有邻居 | O(n) | **O(度)** |
| 适合 | **稠密图** | **稀疏图** |
| 实现难度 | 简单 | 要指针 |
| 删除边 | O(1) | O(度) |

> ⭐ **判断标准：看 e 和 n² 的关系。**
> e 接近 n² → 稠密图 → 矩阵；e 接近 n → 稀疏图 → 邻接表。

## 七、图的分类（了解）

| 类型 | 特点 |
|---|---|
| 无向图 | 边无方向 |
| 有向图 | 边有方向（弧） |
| 带权图（网） | 边上有权值 |
| 完全图 | 任意两点都有边 |
| 连通图 | 任意两点可达 |
| 稀疏图 / 稠密图 | e 远小于 n² / e 接近 n² |

---

## 八、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 完全图边数 | n 个顶点几条边 | `n(n-1)/2` 或 `n(n-1)` |
| 度之和 | 所有度加起来等于几 | 无向 2e，有向入/出各 e |
| 存储选择 | 稀疏图用什么 | 邻接表 |
| 存储空间 | 矩阵占多少 | O(n²) |
| 判断相邻 | 哪种快 | 矩阵 O(1) |
| 连通分量 | 有几个 | 启动 DFS 的次数 |
| 生成树边数 | n 个顶点几条 | n-1 |

> 📌 图这一章公式不多，但每个都要准确。
> 最容易错的是「无向 n(n-1)/2」和「有向 n(n-1)」记混。
