## 一、复杂度总表（从快到慢）


| O(2ⁿ) | 天文数字 | 汉诺塔、子集枚举 |

## 三、树与二叉树

### 3.1 五个公式

| 结论 | 公式 |
|---|---|
| 第 i 层最多节点 | `2^(i-1)` |
| 深度 k 最多节点 | `2^k - 1` |
| 叶子与度 2 的关系 | `n0 = n2 + 1` |
| n 个节点的完全二叉树深度 | `⌊log2 n⌋ + 1` |
| 完全二叉树中节点 i 的孩子 | `2i` 和 `2i+1`（从 1 编号） |

### 3.2 遍历

```text
先序：根 → 左 → 右      第一个是根
中序：左 → 根 → 右      BST 的中序 = 升序
后序：左 → 右 → 根      最后一个是根
层次：用队列，一层一层
```

**重建**：中序 + 先序（或后序）能唯一确定；先序 + 后序**不能**。

### 3.3 四种特殊树

| 树 | 关键性质 | 考点 |
|---|---|---|
| **二叉排序树 BST** | 中序升序 | 升序插入会退化成链，O(n) |
| **平衡二叉树 AVL** | 平衡因子 ∈ {−1,0,1} | 四种旋转（LL/RR/LR/RL） |
| **哈夫曼树** | WPL 最小、无前缀码 | 每次合并最小的两个 |
| **堆** | 大根堆：父 ≥ 子 | 建堆 O(n)，插入/删除 O(log n) |

> ⭐ 建堆是 **O(n)** 不是 O(n log n) —— 因为大部分节点下沉层数很少。

## 四、图

### 4.1 基本公式

| 结论 | 公式 |
|---|---|
| 无向完全图边数 | `n(n-1)/2` |
| 有向完全图边数 | `n(n-1)` |
| 度之和 | 无向：`2e`；有向：入度=出度=`e` |
| 生成树边数 | `n-1` |

### 4.2 存储对比

| | 邻接矩阵 | 邻接表 |
|---|---|---|
| 空间 | O(n²) | O(n+e) |
| 判断 i,j 相邻 | **O(1)** | O(度) |
| 找全部邻居 | O(n) | **O(度)** |
| 适合 | 稠密图 | 稀疏图 |

### 4.3 算法表

| 算法 | 用途 | 时间 | 关键点 |
|---|---|---|---|
| DFS | 遍历 | O(n²)/O(n+e) | 递归或栈 |
| BFS | 遍历、最短路（无权） | O(n²)/O(n+e) | 队列；**入队时标记** |
| Prim | MST | O(n²) | 选"集合到外"的最小边 |
| Kruskal | MST | O(e log e) | 边排序 + 并查集判环 |
| Dijkstra | 单源最短路 | O(n²) | 不能有负权 |
| Floyd | 多源最短路 | O(n³) | 三重循环，动规 |
| 拓扑排序 | AOV 网 | O(n+e) | 入度减到 0 入队 |

## 五、排序总表（最重要的一张）

| 排序 | 平均 | 最好 | 最坏 | 空间 | 稳定 |
|---|---|---|---|---|---|
| 直接插入 | O(n²) | **O(n)** | O(n²) | O(1) | ✅ |
| 冒泡 | O(n²) | **O(n)** | O(n²) | O(1) | ✅ |
| 直接选择 | O(n²) | **O(n²)** | O(n²) | O(1) | ❌ |
| 希尔 | O(n^1.3) | O(n) | O(n²) | O(1) | ❌ |
| 快速 | O(n log n) | O(n log n) | **O(n²)** | O(log n) | ❌ |
| 归并 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | ✅ |
| 堆 | O(n log n) | O(n log n) | O(n log n) | **O(1)** | ❌ |
| 基数 | O(d(n+r)) | 同 | 同 | O(n+r) | ✅ |

**四个"唯一"（高频考点）**：

```text
唯一最好也是 O(n²) 的：直接选择排序
唯一空间 O(1) 的 O(n log n) 排序：堆排序
唯一最坏会退化到 O(n²) 的 O(n log n) 排序：快速排序
稳定的四个：插入、冒泡、归并、基数
```

**实测印证**（n=8，`W23`）：

```text
数据已有序时：插入比较 7 次、冒泡 7 次、选择仍 28 次（= n(n-1)/2）
```

## 六、查找总表

| 方法 | 前提 | ASL(成功) | 时间复杂度 |
|---|---|---|---|
| 顺序查找 | 无 | `(n+1)/2` | O(n) |
| 折半查找 | **有序 + 顺序存储** | `≈ log2(n+1) − 1` | O(log n) |
| 分块查找 | 块间有序 | `(b+1)/2 + (s+1)/2` | O(√n) |
| 哈希 | 无 | 与 α 有关 | O(1) 期望 |

**四个必背数字**：

```text
顺序失败：(n+1)，不带哨兵是 n
折半失败：≈ log2(n+1)，判定树高度 ⌈log2(n+1)⌉
分块最优：b = s = √n 时 ASL = √n + 1
链地址失败：ASL = α = n/m
```

## 七、三大算法策略

| | 分治 | 贪心 | 动规 |
|---|---|---|---|
| 子问题 | 独立 | 每步一个 | **重叠** |
| 是否回退 | 不需要 | 绝不 | 隐式全枚举 |
| 正确性 | 结构保证 | **需要证明** | 转移方程保证 |
| 典型 | 归并、快排、快速幂 | 活动安排、Huffman、Prim | 背包、LCS、Floyd |

**递推式速查**：

| 递推式 | 结果 |
|---|---|
| T(n) = 2T(n/2) + O(n) | O(n log n) |
| T(n) = 2T(n/2) + O(1) | O(n) |
| T(n) = T(n/2) + O(1) | O(log n) |
| T(n) = 2T(n−1) + O(1) | O(2ⁿ) |

**动规四步**：

```text
① 定义状态  ② 转移方程  ③ 边界  ④ 填表方向
```

## 八、易错点清单（考前过一遍）

### 线性表

1. 顺序表插入分母是 **n+1**，删除分母是 **n**。
2. 顺序表插入要**从后往前**移动，删除要**从前往后**。
3. 链表插入「先接后断」，顺序反了会丢链。
4. 「链表插入 O(1)」的前提是**已知前驱**；给下标就是 O(n)。

### 栈与队列

5. 循环队列判空 `front == rear`，判满 `(rear+1)%MAX == front`。
6. 循环队列最多存 **MAX−1** 个（少用一个）。
7. 栈的应用：括号匹配、表达式求值、递归、进制转换。

### 树

8. `n0 = n2 + 1`，推导靠「节点数=度之和」。
9. 先序 + 后序**不能**唯一确定二叉树。
10. BST 按升序插入会退化成链，查找变 O(n)。
11. 建堆 O(n)，不是 O(n log n)。
12. 哈夫曼树的 WPL 要按叶子深度算，别把内部节点算进去。

### 图

13. DFS 用栈，BFS 用队列；BFS **入队时**标记，不是出队时。
14. Prim 适合稠密图 O(n²)，Kruskal 适合稀疏图 O(e log e)。
15. Dijkstra **不能有负权**；多源最短路用 Floyd。
16. 拓扑排序输出数 < n 说明**有环**。

### 排序

17. 选择排序比较次数与数据无关，恒为 `n(n-1)/2`。
18. 快排**已有序时最慢**（取首元素为基准）。
19. 堆排序空间 O(1)，归并空间 O(n)。
20. 稳定性：插入/冒泡/归并/基数稳定，其余不稳定。

### 查找

21. 折半要求**有序 + 顺序存储**，链表不行。
22. 哈希 ASL **只与装填因子有关**，与表长无关。
23. 成功 ASL 除以 n，失败 ASL 除以 m。
24. 开放定址法删除必须用**墓碑**，不能直接置空。
25. 二次探测的装填因子**不能超过 0.5**。

### 算法

26. 快速幂只递归一次，写两次就退化回 O(n)。
27. 0-1 背包一维数组必须**逆序**，正序会变成完全背包。
28. 分数背包贪心对，0-1 背包贪心错。
29. 活动安排按**结束时间**排序，不是开始时间。
30. LCS 与最长公共子串是两个问题，转移方程不同。
