## 一、复杂度分析（W15）

### 1.1 常见量级排序

```text
O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)
```

| 量级 | 典型算法 |
|---|---|
| O(1) | 数组随机访问、哈希查找（平均） |
| O(log n) | 二分查找、平衡树操作 |
| O(n) | 顺序遍历、顺序查找 |
| O(n log n) | 快排/归并/堆排序、建堆 |
| O(n²) | 冒泡/选择/插入排序、双重循环 |
| O(2ⁿ) | 朴素递归斐波那契、子集枚举 |

### 1.2 怎么数循环

```c
for (i = 1; i <= n; i++)            /* n 次 */
    for (j = 1; j <= n; j++)        /* 每轮 n 次 */
        x++;                        /* 总共 n² 次 → O(n²) */
```

```c
for (i = 1; i <= n; i++)            /* 1+2+...+n = n(n+1)/2 → O(n²) */
    for (j = 1; j <= i; j++)
        x++;
```

```c
for (i = 1; i < n; i *= 2)          /* i: 1,2,4,8... → 共 log₂n 次 → O(log n) */
    x++;
```

```c
for (i = 1; i <= n; i++)            /* 外层 n 次 × 内层 log n 次 → O(n log n) */
    for (j = 1; j < n; j *= 2)
        x++;
```

> 📌 **只保留最高阶项，忽略系数**。`3n² + 5n + 100` → `O(n²)`。

### 1.3 空间复杂度

| 情况 | 空间 |
|---|---|
| 只用几个临时变量 | O(1) |
| 递归深度 n | O(n)（每层一个栈帧） |
| 需要辅助数组 | O(n) |

⚠️ 递归算法的空间复杂度看**最大递归深度**，不是调用总次数。

## 二、线性表（W16 – W17）

### 2.1 顺序表 vs 链表

| 维度 | 顺序表（数组） | 链表 |
|---|---|---|
| 存储 | 连续空间 | 离散，靠指针连接 |
| 随机访问 | ⭐ O(1) | O(n) |
| 插入/删除 | O(n)（要移动元素） | ⭐ O(1)（已知位置） |
| 空间 | 需预先分配，可能浪费 | 按需分配，有指针开销 |
| 缓存友好 | 好 | 差 |

**⭐ 顺序表插入的平均移动次数**

在第 i 个位置插入，要移动 `n - i + 1` 个元素。等概率插入时平均移动 `n/2` 次。
删除第 i 个位置，平均移动 `(n-1)/2` 次。

### 2.2 单链表核心操作

```c
typedef struct Node {
    int          data;
    struct Node *next;
} Node;
```

**头插法（结果与输入逆序）**

```c
s->next = head->next;
head->next = s;
```

**尾插法（保持顺序）**

```c
tail->next = s;
tail = s;
```

**删除结点 p 的后继**

```c
Node *q = p->next;
p->next = q->next;
free(q);
```

**⭐ 单链表逆置（必考）**

```c
Node *prev = NULL, *cur = head, *next;
while (cur != NULL) {
    next = cur->next;      /* 先存后继 */
    cur->next = prev;      /* 反转指针 */
    prev = cur;            /* 前移 */
    cur = next;
}
head = prev;
```

> ⚠️ 顺序不能错：必须**先保存 next**，否则断链后找不到后面的结点。

**带头结点 vs 不带头结点**

| 形式 | 优点 | 缺点 |
|---|---|---|
| 带头结点 | 插入删除不用特判第一个位置，代码统一 | 多占一个结点空间 |
| 不带头结点 | 省空间 | 首结点操作要单独判断 |

### 2.3 双向链表

```c
p->prior->next = p->next;
p->next->prior = p->prior;
```

插入时要改 4 个指针，⚠️ 顺序很重要（先连新结点的两头，再断旧的）。

## 三、栈与队列（W18）

### 3.1 特性对比

| 结构 | 规则 | 典型应用 |
|---|---|---|
| 栈 Stack | 后进先出 LIFO | 函数调用、括号匹配、表达式求值、递归、撤销 |
| 队列 Queue | 先进先出 FIFO | 层次遍历、任务调度、缓冲区 |

### 3.2 循环队列（⭐ 必考）

用数组实现队列，为了复用空间做成循环：

```c
#define MAXSIZE 100
int queue[MAXSIZE];
int front = 0, rear = 0;
```

| 判断 | 条件 |
|---|---|
| 队空 | `front == rear` |
| 队满 | `(rear + 1) % MAXSIZE == front`（牺牲一个单元） |
| 元素个数 | `(rear - front + MAXSIZE) % MAXSIZE` |
| 入队 | `queue[rear] = x; rear = (rear + 1) % MAXSIZE;` |
| 出队 | `x = queue[front]; front = (front + 1) % MAXSIZE;` |

> ⚠️ 队满条件为什么是 `(rear+1)%MAXSIZE == front`？因为 `front == rear` 已经用来表示空队了，必须牺牲一个单元来区分「空」和「满」。

### 3.3 栈的应用（软考常考）

**括号匹配**：遇左括号入栈，遇右括号弹栈比对，最后栈空才算匹配。

**表达式求值**：
- 中缀 → 后缀（调度场算法，用栈）
- 后缀求值（遇数字入栈，遇运算符弹两个算完压回）

**⭐ 出栈序列判断**（高频）：给入栈顺序，问某个出栈序列是否可能。
判断法：模拟一遍，如果某个元素出栈时，它前面的元素必须都已经入过栈。

## 四、树与二叉树（W19 – W20）⭐ 重点

### 4.1 二叉树五条性质（必背）

| 编号 | 性质 |
|---|---|
| 1 | 第 i 层最多有 `2^(i-1)` 个结点 |
| 2 | 深度为 k 的二叉树最多有 `2^k - 1` 个结点 |
| 3 | 叶子数 `n0 = n2 + 1`（`n2` 是度为 2 的结点数） |
| 4 | n 个结点的完全二叉树深度 = `⌊log₂n⌋ + 1` |
| 5 | 完全二叉树按层编号，结点 i 的左孩子 `2i`，右孩子 `2i+1`，父结点 `⌊i/2⌋` |

> 💡 性质 3 的推导：结点总数 `n = n0 + n1 + n2`；分支数 `= n - 1 = n1 + 2n2`。两式相减得 `n0 = n2 + 1`。

### 4.2 四种遍历

| 遍历 | 顺序 | 记忆 |
|---|---|---|
| 前序 Preorder | 根 → 左 → 右 | 根最先 |
| 中序 Inorder | 左 → 根 → 右 | 根在中间 |
| 后序 Postorder | 左 → 右 → 根 | 根最后 |
| 层序 Level | 逐层从左到右 | 用队列实现 |

```c
void inorder(TreeNode *t) {
    if (t == NULL) return;
    inorder(t->left);
    printf("%d ", t->data);
    inorder(t->right);
}
```

### 4.3 ⭐ 由遍历序列还原二叉树（高频）

| 已知 | 能否唯一确定 |
|---|---|
| 前序 + 中序 | ✅ 能 |
| 后序 + 中序 | ✅ 能 |
| 层序 + 中序 | ✅ 能 |
| 前序 + 后序 | ❌ **不能**（无法区分只有一个孩子时的左右） |

**还原方法**：前序的第一个（或后序的最后一个）是根；在中序里找到根的位置，左边是左子树，右边是右子树；递归处理。

### 4.4 特殊二叉树

| 类型 | 定义 | 要点 |
|---|---|---|
| 满二叉树 | 每层都满 | n 个结点，深度 `log₂(n+1)` |
| 完全二叉树 | 只有最后一层可能不满，且靠左 | 适合用数组存 |
| 二叉排序树 BST | 左 < 根 < 右 | 中序遍历得**升序序列** |
| 平衡二叉树 AVL | 左右子树高度差 ≤ 1 | 查找 O(log n) |
| 哈夫曼树 | 带权路径长度 WPL 最小 | 每次合并最小的两个 |

### 4.5 哈夫曼树与编码

**构造**：每次取权值最小的两个结点合并，新结点权值为二者之和，放回集合，重复直到只剩一个。

**WPL** = Σ(叶子权值 × 叶子深度)

**哈夫曼编码**：左分支记 0、右分支记 1，从根到叶子的路径就是编码。特点是**前缀码**（没有任何编码是另一个的前缀），且出现频率高的字符编码短。

## 五、图（W21 – W22）

### 5.1 基本术语与数量关系（⭐ 必考）

| 概念 | 公式 |
|---|---|
| 无向完全图边数 | `n(n-1) / 2` |
| 有向完全图弧数 | `n(n-1)` |
| 无向图度数之和 | `= 2 × 边数` |
| 有向图入度之和 = 出度之和 | `= 弧数` |
| n 个顶点的生成树边数 | `n - 1` |
| 连通图最少边数 | `n - 1` |

### 5.2 两种存储结构

| 结构 | 空间 | 适用 | 特点 |
|---|---|---|---|
| 邻接矩阵 | O(n²) | 稠密图 | 判断两点是否相邻 O(1) |
| 邻接表 | O(n + e) | 稀疏图 | 找某点的邻居快 |

无向图的邻接矩阵是**对称**的；第 i 行的非零元素个数 = 顶点 i 的度。

### 5.3 遍历

| 遍历 | 数据结构 | 特点 |
|---|---|---|
| DFS 深度优先 | **栈**（递归） | 一条路走到黑，再回溯 |
| BFS 广度优先 | **队列** | 层层扩展，可求无权图最短路径 |

### 5.4 图的应用（⭐ 高频）

| 算法 | 解决什么 | 复杂度 | 注意 |
|---|---|---|---|
| Prim | 最小生成树 | O(n²) | 适合稠密图，从点出发 |
| Kruskal | 最小生成树 | O(e log e) | 适合稀疏图，从边出发，用并查集 |
| Dijkstra | 单源最短路径 | O(n²) | ⚠️ **不能有负权边** |
| Floyd | 所有顶点对最短路径 | O(n³) | 可处理负权（不能有负环） |
| 拓扑排序 | AOV 网，判断有无环 | O(n+e) | 反复输出入度为 0 的顶点 |
| 关键路径 | AOE 网，最短工期 | — | 最早开始时间 = 最晚开始时间 的活动 |

**最小生成树不唯一**：当有权值相同的边时，可能有多棵不同的最小生成树，但**总权值相同**。

**拓扑排序**：能完成 → 图无环；无法完成（还有顶点入度不为 0）→ 图有环。拓扑序列可能不唯一。

## 六、排序（W23 – W24）⭐ 必考

### 6.1 ⭐ 复杂度与稳定性总表（必背）

| 排序 | 平均 | 最坏 | 最好 | 空间 | 稳定性 |
|---|---|---|---|---|---|
| 直接插入 | O(n²) | O(n²) | **O(n)** | O(1) | ✅ 稳定 |
| 希尔 | O(n^1.3) | O(n²) | O(n) | O(1) | ❌ 不稳定 |
| 冒泡 | O(n²) | O(n²) | **O(n)** | O(1) | ✅ 稳定 |
| 快速 | **O(n log n)** | **O(n²)** | O(n log n) | O(log n) | ❌ 不稳定 |
| 直接选择 | O(n²) | O(n²) | O(n²) | O(1) | ❌ 不稳定 |
| 堆排序 | O(n log n) | O(n log n) | O(n log n) | O(1) | ❌ 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n log n) | **O(n)** | ✅ 稳定 |
| 基数 | O(d(n+r)) | 同 | 同 | O(n+r) | ✅ 稳定 |

**记忆要点**
- 稳定的 4 个：**插入、冒泡、归并、基数**（口诀：插冒归基）
- 空间 O(1) 的：插入、冒泡、选择、希尔、堆
- 空间 O(n) 的：归并
- 最好是 O(n) 的：插入、冒泡（原始有序时）
- **快排最坏 O(n²)**：数组已有序（或逆序）时退化成这样，这是最高频的坑

### 6.2 三种 O(n²) 排序的过程

**冒泡**：相邻两两比较，大的往后冒。每轮把当前最大值送到末尾。优化：某轮无交换则提前结束。

**插入**：把第 i 个元素插入到前面已经有序的部分里。像整理扑克牌。

**选择**：每轮从未排序部分选出最小（大）的，与该轮首位交换。

### 6.3 快排与堆排

**快排**：选基准 pivot，把小于它的放左边、大于的放右边，再对两侧递归。

```text
一轮划分后：[小于 pivot] pivot [大于 pivot]
```

**堆排序**：先建大顶堆（从最后一个非叶结点 `n/2` 开始向下调整），然后反复把堆顶与末尾交换、缩小堆、再调整。

> ⚠️ 建堆是 O(n)，不是 O(n log n)。每次调整为 O(log n)，共 n 次，所以总的是 O(n log n)。

### 6.4 排序的稳定性判定

**稳定** = 相等元素的相对次序在排序后不变。

判断技巧：**如果算法会做「跨越式的交换」（远距离交换），多半不稳定**（快排、堆排、选择、希尔）。相邻交换的通常稳定（插入、冒泡）。

## 七、查找（W25）

### 7.1 三种查找对比

| 方法 | 前提 | 平均 ASL | 特点 |
|---|---|---|---|
| 顺序查找 | 无 | `(n+1)/2` | 简单，O(n) |
| 二分查找 | ⭐ **必须有序 + 顺序存储** | `log₂(n+1) - 1` | O(log n) |
| 哈希查找 | 无 | O(1) 理想情况 | 空间换时间 |

**⚠️ 二分查找不能用于链表**，因为取中间元素需要随机访问。

### 7.2 二分查找

```c
int binSearch(int a[], int n, int key) {
    int low = 0, high = n - 1, mid;
    while (low <= high) {
        mid = (low + high) / 2;
        if (a[mid] == key)      return mid;
        else if (a[mid] < key)  low = mid + 1;
        else                    high = mid - 1;
    }
    return -1;
}
```

⚠️ 三个易错点：`low <= high` 的等号、`mid ± 1`、high 初值 `n-1`。

**最大比较次数** = `⌊log₂n⌋ + 1`。

### 7.3 哈希表

**构造方法**：除留余数法最常用 —— `H(key) = key % p`，p 取小于表长的最大质数。

**冲突处理**

| 方法 | 做法 | 特点 |
|---|---|---|
| 线性探测 | 冲突就往后找下一个空位 | 简单，但会**堆积** |
| 二次探测 | 按 ±1², ±2², ±3² 找 | 减少堆积 |
| 链地址法 | 同一位置挂一条链表 | 删除方便，不堆积 |

**装填因子** `α = 元素个数 / 表长`。α 越大冲突越多，ASL 越大。

## 八、算法设计方法（W26）

### 8.1 三种思想

| 方法 | 核心 | 典型题 | 软考要求 |
|---|---|---|---|
| 分治 | 分解 → 递归求解 → 合并 | 归并排序、快排、二分查找 | 理解 |
| 贪心 | 每步选当前最优，不回头 | 找零钱、活动安排、哈夫曼 | 理解 + 判断能否用 |
| 动态规划 | 记录子问题结果，避免重复 | 背包、最长公共子序列、斐波那契 | **能看懂递推式** |

### 8.2 分治 vs 动态规划

| 区别 | 分治 | 动规 |
|---|---|---|
| 子问题 | 相互独立，不重叠 | **有重叠**，所以需要记忆化 |
| 求解方向 | 自顶向下递归 | 通常自底向上填表 |

### 8.3 01 背包的递推式（看懂即可）

```text
f[i][j] = max( f[i-1][j],                         不选第 i 件
               f[i-1][j-w[i]] + v[i] )            选第 i 件（j >= w[i]）
```

`f[i][j]` 表示「前 i 件物品、容量 j 时的最大价值」。

### 9.1 五类题型

| 题型 | 打法 |
|---|---|
| 读程序写结果 | 列变量表，逐行追踪，绝不跳步 |

| 算法实现 | 数组/字符串/排序/查找四类练熟，不求最优解 |
| 流程补全 | 跟判断走，确保每个分支都有覆盖 |

### 9.2 高频代码模板（背下来）

```c
/* 冒泡排序 */
for (int i = 0; i < n - 1; i++)
    for (int j = 0; j < n - 1 - i; j++)
        if (a[j] > a[j + 1]) { int t = a[j]; a[j] = a[j+1]; a[j+1] = t; }

/* 二分查找 */
while (low <= high) {
    mid = (low + high) / 2;
    if (a[mid] == key) break;
    else if (a[mid] < key) low = mid + 1;
    else high = mid - 1;
}

/* 求最大公约数 */
int gcd(int a, int b) { return b == 0 ? a : gcd(b, a % b); }

/* 判断素数 */
int isPrime(int n) {
    if (n < 2) return 0;
    for (int i = 2; i * i <= n; i++)
        if (n % i == 0) return 0;
    return 1;
}

/* 单链表逆置 */
while (cur) { next = cur->next; cur->next = prev; prev = cur; cur = next; }
```
