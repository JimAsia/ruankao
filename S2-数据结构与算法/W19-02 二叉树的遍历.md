# W19-02 二叉树的遍历

> 遍历是树的核心操作，软考选择题和应用题都考。
> 三种深度遍历（先/中/后序）+ 一种广度遍历（层序），都要求能**手算**和**写代码**。

---

## 一、三种深度遍历：只差根的位置

```c
/* 先序：根 → 左 → 右 */
void preorder(TNode *root) {
    if (!root) return;
    printf("%c ", root->data);      /* ← 根最先 */
    preorder(root->left);
    preorder(root->right);
}

/* 中序：左 → 根 → 右 */
void inorder(TNode *root) {
    if (!root) return;
    inorder(root->left);
    printf("%c ", root->data);      /* ← 根居中 */
    inorder(root->right);
}

/* 后序：左 → 右 → 根 */
void postorder(TNode *root) {
    if (!root) return;
    postorder(root->left);
    postorder(root->right);
    printf("%c ", root->data);      /* ← 根最后 */
}
```

> ⭐ **三份代码只有 `printf` 的位置不同。**
> 左孩子永远在右孩子之前，区别只在「根什么时候访问」。

### 实测（`192_tree_traversal.c`）

对同一棵树：

```text
        A
       / \
      B   C
     / \   \
    D   E   F
       / \
      G   H

先序：A B D E G H C F     （根最先）
中序：D B G E H A C F     （根在中间）
后序：D G H E B F C A     （根最后）
```

### 记忆法：看英文名

| 遍历 | 英文 | 根的位置 |
|---|---|---|
| 先序 | Pre-order | 根「先」 |
| 中序 | In-order | 根在「中间」 |
| 后序 | Post-order | 根「后」 |

> 📌 软考有时用「前序/中序/后序」和「先序/中序/后序」混称，是一回事。

## 二、层序遍历：必须用队列

```c
void levelOrder(TNode *root) {
    if (!root) return;
    TNode *q[64]; int front = 0, rear = 0;

    q[rear++] = root;               /* 根入队 */
    while (front < rear) {
        TNode *cur = q[front++];    /* 出队 */
        printf("%d ", cur->data);
        if (cur->left)  q[rear++] = cur->left;
        if (cur->right) q[rear++] = cur->right;
    }
}
```

实测：

```text
层序：1 2 3 4 5 6
```

### 为什么层序必须用队列

| 遍历 | 本质 | 用的结构 |
|---|---|---|
| 先/中/后序 | **DFS**（深度优先） | 栈 / 递归 |
| 层序 | **BFS**（广度优先） | **队列** |

> ⭐ 层序要求「先遇到先访问」—— 这正是先进先出，队列。
> 递归（栈）做的是「先遇到后访问」，做不了层序。
> 📌 DFS 和 BFS 是图遍历的两大算法，W21 会正式讲。

## 三、由遍历序列重建树（软考重点）

### 结论（必记）

```text
中序 + 先序 → 能唯一确定一棵树
中序 + 后序 → 能唯一确定一棵树
先序 + 后序 → 【不能】唯一确定
```

### 为什么「先序 + 后序」不够

```text
先序 A B C，后序 C B A：

    A            A
   / \   还是    /      ← 两种都可能！
  B   C        B
                \
                 C
```

> 因为先序后序都只能确定「根是谁」，**不能确定左右子树的分界**。
> 而中序能告诉我们「根左边是左子树，右边是右子树」。
> 📌 这是软考选择题的经典考点。

### 重建算法（前序 + 中序）

```c
TNode *buildTree(char pre[], char in[], int n) {
    if (n <= 0) return NULL;

    char rootData = pre[0];         /* 前序第一个是根 */
    TNode *root = make(rootData);

    int rootIdx = 0;
    while (rootIdx < n && in[rootIdx] != rootData) rootIdx++;

    root->left  = buildTree(pre + 1, in, rootIdx);
    root->right = buildTree(pre + 1 + rootIdx, in + rootIdx + 1, n - 1 - rootIdx);
    return root;
}
```

实测（`193_tree_build.c`）：

```text
前序：ABDECFG
中序：DBEAFCG
重建后后序：DEBFGCA ✓
```

### 手算步骤

```text
前序 A B D E C F G，中序 D B E A F C G

1. 前序第一个 A 是根
2. 中序里 A 左边 DBE 是左子树，右边 FCG 是右子树
3. 左子树：前序 BDE，中序 DBE → B 是根，D 左，E 右
4. 右子树：前序 CFG，中序 FCG → C 是根，F 左，G 右
```

> ⭐ 软考常考「给前序和中序，求后序」，就是先重建再遍历。

## 四、递归统计三件套（模板）

```c
int countNodes(TNode *root) {
    if (!root) return 0;
    return countNodes(root->left) + countNodes(root->right) + 1;
}

int countLeaves(TNode *root) {
    if (!root) return 0;
    if (!root->left && !root->right) return 1;      /* 叶子 */
    return countLeaves(root->left) + countLeaves(root->right);
}

int treeDepth(TNode *root) {
    if (!root) return 0;
    int dl = treeDepth(root->left);
    int dr = treeDepth(root->right);
    return (dl > dr ? dl : dr) + 1;
}
```

> ⭐ **共同套路：先递归问左右子树，再汇总自己。**
> 这是「树的递归」最核心的模式，后面所有树的题都是这个骨架。

### 实测

```text
节点总数 = 6
叶子数   = 3
深度     = 4
```

## 五、其他两个高频操作

### ① 判断完全二叉树（层序 + 空位标记）

```c
int isComplete(TNode *root) {
    TNode *q[64]; int front = 0, rear = 0;
    int seenNull = 0;

    q[rear++] = root;
    while (front < rear) {
        TNode *cur = q[front++];
        if (cur == NULL) { seenNull = 1; continue; }
        if (seenNull) return 0;         /* 空位后又有非空 → 不是完全 */
        q[rear++] = cur->left;
        q[rear++] = cur->right;
    }
    return 1;
}
```

> ⭐ 完全二叉树的层序序列里，**空位只能出现在最后且不能中断**。

### ② 求镜像（翻转二叉树）

```c
void mirror(TNode *root) {
    if (!root) return;
    TNode *t = root->left;
    root->left = root->right;
    root->right = t;
    mirror(root->left);
    mirror(root->right);
}
```

> ⭐ 每个节点左右孩子互换，整棵树就像照了镜子。
> 实测：翻转后中序正好是原来的倒序（左中右 → 右中左）。

## 六、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 遍历结果 | 给树求先/中/后序 | 手算，注意根的位置 |
| 重建 | 给两序求第三序 | 先重建再遍历 |
| 重建可行性 | 哪两序能唯一确定 | 中序 + 前/后序 |
| 层序 | 用什么结构 | 队列 |
| 递归统计 | 节点数/叶子/深度 | 分治模板 |
| DFS/BFS | 前中后序 vs 层序 | 栈 vs 队列 |
