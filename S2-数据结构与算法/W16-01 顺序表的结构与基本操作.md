# W16-01 顺序表的结构与基本操作

> 线性表是最基础的逻辑结构：一串「一个接一个」的元素。
> 它有两种存储方式：**顺序表（数组）** 和 **链表（指针）**。
> 这一周讲顺序表，下周讲链表。

---

## 一、逻辑结构与存储结构

这是软考最爱考的一个概念区分：

| 概念 | 含义 | 例子 |
|---|---|---|
| **逻辑结构** | 元素之间的关系，与存储无关 | 线性表、树、图 |
| **存储结构** | 在内存里怎么放 | 顺序存储、链式存储 |

> ⭐ **同一个逻辑结构可以有多种存储结构。**
> 线性表既可以用数组实现（顺序表），也可以用指针实现（链表）。
> 这是「逻辑」和「存储」不是一回事的最好例子。

---

## 二、顺序表的定义

```c
#define MAXSIZE 20

typedef struct {
    int data[MAXSIZE];      /* 存数据的数组 */
    int length;             /* 当前实际元素个数 */
} SqList;
```

### `data` 和 `length` 缺一不可

| 变量 | 含义 | 易混点 |
|---|---|---|
| `data[MAXSIZE]` | 容量是 **MAXSIZE** | 容量是固定的 |
| `length` | 实际有 **length** 个 | 不是数组长度！ |

> ⚠️ **遍历必须用 `i < L->length`，不能用 `i < MAXSIZE`。**
> 用 MAXSIZE 会把后面没意义的内存也当成数据 —— 这是顺序表第一大 bug。

---

## 三、随机访问：顺序表最大的优势

```c
int v = L.data[500];        /* 直接取，O(1) */
```

为什么是 O(1)？因为地址可以直接算：

```text
data[500] 的地址 = 首地址 + 500 × sizeof(int)
```

> ⭐ **这叫「随机访问」（random access）。**
> 不管下标是 0 还是 500，都是一次乘法加一次加法。
> **链表做不到** —— 它必须从头一个个走，这就是 W17 要讲的核心差别。

---

## 四、插入：从后往前挪

```c
/* 在下标 pos 处插入 value */
for (int i = L->length; i > pos; i--) {
    L.data[i] = L.data[i - 1];      /* 后移一格 */
}
L.data[pos] = value;
L.length++;
```

### 为什么必须从后往前

假设在下标 2 插入，表是 `[10 20 30 40 50]`：

```text
✅ 从后往前（i 从 5 递减到 3）：
   data[5] = data[4]   50 挪到 5 号位
   data[4] = data[3]   40 挪到 4 号位
   data[3] = data[2]   30 挪到 3 号位
   data[2] = 99        插入
   结果 [10 20 99 30 40 50] ✓

❌ 从前往后（i 从 2 递增到 4）：
   data[3] = data[2]   30 挪到 3 号位，但 data[3] 原来的 40 被覆盖了
   data[4] = data[3]   现在 data[3] 是 30，把 30 又挪到 4
   → 40 和 50 全丢了
```

> ⭐ **口诀：插入从后往前，删除从前往后。**
> 想清楚「谁是源、谁是目标」就不会错：插入时源在前、目标在后，所以从后往前搬才不覆盖源。

### 实测移动次数

`161_seqlist_basic.c` 的真实输出：

```text
① 末尾插 5 个元素：移动 0 次（末尾插入不用挪）
② 在表头插入 5  ：移动 5 次（原来的 5 个全部后移）
③ 在下标 3 插入 77：移动 3 次
```

**插入表头挪 n 次，插入表尾挪 0 次。**

## 五、删除：从前往后挪

```c
for (int i = pos; i < L->length - 1; i++) {
    L.data[i] = L.data[i + 1];      /* 前移一格，覆盖被删元素 */
}
L.length--;
```

实测：

```text
删表头：移动 5 次（后面全部前移）
删表尾：移动 0 次（没有元素需要前移）
```

> ⚠️ **循环边界必须是 `length - 1`。**
> 写成 `length` 时，最后一次执行 `data[length-1] = data[length]`，
> 把数组里**没意义的旧数据**搬进了有效区 —— 不崩溃、不报错，但结果错得很隐蔽。

## 六、平均移动次数：软考必考的两个数字

软考原题：

> 「在长度为 n 的顺序表中插入一个元素，平均需要移动多少个元素？」

**答案：n/2。**

> 「删除一个元素，平均需要移动多少个元素？」

**答案：(n-1)/2。**

### 插入的推导

在位置 i（`0 <= i <= n`）插入，要移动 `n - i` 个元素。i 有 `n+1` 种取值：

```text
平均值 = [n + (n-1) + ... + 1 + 0] / (n+1)
       = [n(n+1)/2] / (n+1)
       = n/2
```

### 删除的推导

删位置 i（`0 <= i <= n-1`），要移动 `n-1-i` 个。i 有 `n` 种取值：

```text
平均值 = [(n-1) + (n-2) + ... + 1 + 0] / n
       = [(n-1)n/2] / n
       = (n-1)/2
```

> ⚠️ **插入的分母是 n+1，删除的分母是 n。** 这是最容易混的一点。
> 因为插入有 n+1 个位置（含末尾），删除只有 n 个位置。

### 实测验证

`163_seqlist_cost.c` 的真实输出（n=10）：

```text
插入：位置 0..10，移动次数 10,9,8,...,1,0
      总移动 55，平均 55/11 = 5.00，公式 n/2 = 5.00 ✓

删除：位置 0..9，移动次数 9,8,...,1,0
      总移动 45，平均 45/10 = 4.50，公式 (n-1)/2 = 4.50 ✓
```

换几个 n 验证：

| n | 插入平均 | n/2 | 删除平均 | (n-1)/2 |
|---|---|---|---|---|
| 10 | 5.00 | 5.00 | 4.50 | 4.50 |
| 100 | 50.00 | 50.00 | 49.50 | 49.50 |
| 10000 | 5000.00 | 5000.00 | 4999.50 | 4999.50 |

> ⭐ **完全相等，不是「接近」。** 因为 n/2 就是精确平均值。

## 七、顺序表操作复杂度总表

| 操作 | 复杂度 | 原因 |
|---|---|---|
| 按位置取值 `L[i]` | **O(1)** | 地址可算，随机访问 |
| 按值查找 | O(n) | 要逐个比较 |
| 表尾插入 | O(1) | 不用挪元素 |
| 表头/中间插入 | **O(n)** | 平均挪 n/2 个 |
| 表尾删除 | O(1) | 不用挪元素 |
| 表头/中间删除 | **O(n)** | 平均挪 (n-1)/2 个 |
| 求长度 | **O(1)** | 直接读 length |

> 📌 这张表要和 W17 的链表表对照背。
> 记住规律：**顺序表「查快改慢」，链表「查慢改快」。**

## 八、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 定义 | 顺序表需要哪些成员 | 数组 + length |
| 遍历 | 循环条件 | `i < length`，不是 MAXSIZE |
| 插入方向 | 从前往后还是从后往前 | **从后往前** |
| 删除方向 | 从前往后还是从后往前 | **从前往后** |
| 平均移动 | 插入/删除平均移动几个 | **n/2** 和 **(n-1)/2** |
| 复杂度 | 按位置访问 | O(1)（随机访问） |
| 边界 | 插入的合法位置范围 | `0..length`（含末尾） |
