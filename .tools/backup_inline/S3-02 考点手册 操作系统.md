# S3-02 考点手册 操作系统

> 操作系统的题分两类：**概念对比**（进程 vs 线程、分页 vs 分段）和**过程计算**（调度、页面置换）。
> 前者靠背表格，后者靠模板。这一份两类都覆盖。

## 二、必背考点

### 2.1 进程、程序、线程

| | 程序 | 进程 | 线程 |
|---|---|---|---|
| 性质 | **静态**的指令集合 | **动态**的执行过程 | 进程内的执行单元 |
| 资源 | 不占 | **资源分配**的基本单位 | **CPU 调度**的基本单位 |
| 地址空间 | 无 | 独立 | **共享所属进程的** |
| 开销 | — | 大（切换要换页表） | 小（只换栈和寄存器） |

**一句话记**：

```text
进程 = 资源分配的基本单位
线程 = CPU 调度的基本单位
```

**线程共享什么、独有什么**：

| 共享（同进程内） | 私有 |
|---|---|
| 代码段、数据段、堆 | **栈** |
| 打开的文件 | **寄存器、PC** |
| 信号处理函数 | 线程 ID |

> ⭐ 高频题：同一进程的多个线程**共享全局变量**，但**各自的栈是独立的**。

### 2.2 进程状态

```text
三态：就绪 →（调度）→ 运行 →（时间片到）→ 就绪
                     ↓（等待 I/O）
                   阻塞 →（I/O 完成）→ 就绪
```

**四条铁律**（常考判断）：

```text
① 阻塞 → 运行：不可能（必须先去就绪）
② 就绪 → 阻塞：不可能（没运行怎么阻塞）
③ 运行 → 阻塞：可能（主动申请资源）
④ 阻塞 → 就绪：可能（等待的事件发生了）
```

**PCB（进程控制块）**：进程存在的**唯一标志**。
里面存：进程标识、状态、程序计数器、寄存器现场、资源清单、优先级。

> ⭐ 题目问「进程存在的唯一标志是什么」→ **PCB**，不是程序代码。

### 2.3 调度算法

| 算法 | 特点 | 缺点 |
|---|---|---|
| **FCFS** 先来先服务 | 简单、公平 | 短作业等长作业（护航效应） |
| **SJF** 短作业优先 | **平均周转时间最短** | 长作业可能饿死 |
| **优先级** | 照顾重要进程 | 低优先级饿死 |
| **RR** 时间片轮转 | 响应快、公平 | 时间片太小切换开销大 |
| **多级反馈队列** | 兼顾响应与吞吐 | 实现复杂 |

**四个时间概念**：

```text
到达时间：进程进入就绪队列的时刻
服务时间（运行时间）：需要 CPU 多久
完成时间：真正做完的时刻
周转时间 = 完成时间 − 到达时间
带权周转时间 = 周转时间 / 服务时间
```

**实测**（4 个进程：A(0,8) B(1,4) C(2,9) D(3,5)）：

| 算法 | 平均周转时间 | 平均带权周转时间 |
|---|---|---|
| FCFS | 15.25 | 2.62 |
| SJF | **14.25** | **2.30** |
| RR（q=2） | 19.25 | 3.04 |

> ⭐ SJF 的平均周转时间最短（可证明），但 RR 的**响应时间**更好 ——
> 两个指标不同，题目问哪个就答哪个。

### 2.4 同步与互斥

| 概念 | 含义 |
|---|---|
| **临界资源** | 一次只允许一个进程使用的资源（打印机） |
| **临界区** | 访问临界资源的那段代码 |
| **互斥** | 两个进程不能同时进临界区 |
| **同步** | 进程之间有先后顺序的约束 |

**信号量 PV 操作**：

```text
P(S)：S = S − 1；若 S < 0，则本进程阻塞，进入等待队列
V(S)：S = S + 1；若 S ≤ 0，则唤醒等待队列中的一个进程
```

**S 值的含义**：

```text
S > 0：还有 S 个资源可用
S = 0：资源刚好用完，没有进程在等
S < 0：|S| 就是等待队列里的进程数
```

> ⭐ 这是最常考的一点：**S < 0 时，|S| 等于等待的进程数**。

**生产者—消费者**（缓冲区大小 n）：

```c
semaphore mutex = 1;    // 互斥访问缓冲区
semaphore empty = n;    // 空位数量
semaphore full  = 0;    // 产品数量

生产者：               消费者：
  P(empty);              P(full);
  P(mutex);              P(mutex);
  放产品                  取产品
  V(mutex);              V(mutex);
  V(full);               V(empty);
```

> ⚠️ **两个 P 的顺序不能反**：必须先 P(empty) 再 P(mutex)。
> 反了会死锁 —— 生产者占着锁等空位，消费者拿不到锁。

### 2.5 死锁

**四个必要条件（缺一不可）**：

```text
① 互斥：资源一次只能被一个进程用
② 请求并保持：占着资源还申请新资源
③ 不可剥夺：不能强行抢走
④ 环路等待：存在进程资源的环形等待链
```

**四种处理策略**：

| 策略 | 做法 | 代价 |
|---|---|---|
| **预防** | 破坏四个条件之一 | 资源利用率低 |
| **避免** | 银行家算法（分配前判断是否安全） | 计算开销大 |
| **检测** | 定期检查是否有环 | 需要回滚 |
| **解除** | 撤销进程 / 剥夺资源 | 丢失工作 |

> ⭐ 「银行家算法」属于**避免**死锁，不是预防，也不是检测。

### 2.6 存储管理

| | 分页 | 分段 |
|---|---|---|
| 划分依据 | **物理**大小固定 | **逻辑**意义 |
| 大小 | 固定（如 4KB） | 不等长 |
| 地址 | 一维（页号+页内偏移） | 二维（段号+段内偏移） |
| 碎片 | 内部碎片 | 外部碎片 |
| 对用户 | 不可见 | 可见 |

**段页式**：先分段（逻辑），段内再分页（物理）。地址 = 段号 + 页号 + 页内偏移。

**地址转换（分页）**：

```text
逻辑地址 = 页号 P + 页内偏移 W
物理地址 = 页表[P] × 页大小 + W
```

**页面置换算法实测**（引用串 20 个，3 个页框）：

```text
引用串：7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1

FIFO：缺页 15 次（缺页率 75.0%）
LRU ：缺页 12 次（缺页率 60.0%）
OPT ：缺页  9 次（缺页率 45.0%）
```

**Belady 异常（FIFO 特有）**（引用串 12 个）：

| 页框数 | FIFO 缺页 | LRU 缺页 |
|---|---|---|
| 3 | **9** | 10 |
| 4 | **10** | 8 |

> ⭐ 3 个页框缺页 9 次，加到 4 个反而 10 次 —— 这就是 Belady 异常。
> **只有 FIFO 会出这种现象**，LRU 和 OPT 不会（它们满足栈式性质）。

### 2.7 文件管理

**文件的物理结构**：

| 方式 | 优点 | 缺点 |
|---|---|---|
| **连续** | 顺序访问快 | 有外部碎片、难扩展 |
| **链接** | 易扩展、无碎片 | 只能顺序访问 |
| **索引** | 支持随机访问 | 索引表占空间 |

**空闲空间管理**：位示图（1 位表示一个块）、空闲链表、成组链接。

**索引节点（inode）**：存文件的**属性**（大小、权限、时间、物理地址），
**不存文件名**。文件名在目录项里。

> ⭐ 常考：一个文件可以有多个文件名（硬链接），但只有一个 inode。

### 2.8 设备管理

| 技术 | 作用 |
|---|---|
| **缓冲** | 缓解 CPU 与外设速度差 |
| **SPOOLing** | 把独占设备改造成共享设备（打印机的排队） |
| **DMA** | 整块数据直接进内存，不占 CPU |
| **通道** | 专用 I/O 处理器 |

> ⭐ SPOOLing 的核心是**用磁盘当缓冲区**，让多个进程"同时"用一台打印机。

## 三、计算题模板

### 模板 1：调度算法求周转时间

```text
① 画时间轴：从 0 时刻开始，按算法决定谁上 CPU
② 每个进程的完成时间 = 它运行结束的时刻
③ 周转时间 = 完成 − 到达
④ 带权周转 = 周转 / 服务
⑤ 平均值 = 总和 / 进程数
```

**FCFS 例子**（A(0,8) B(1,4) C(2,9) D(3,5)）：

```text
A: 0→8 完成   周转 8−0=8    带权 8/8=1.00
B: 8→12 完成  周转 12−1=11  带权 11/4=2.75
C: 12→21 完成 周转 21−2=19  带权 19/9=2.11
D: 21→26 完成 周转 26−3=23  带权 23/5=4.60
平均周转 15.25，平均带权 2.62
```

### 模板 2：页面置换数缺页

```text
① 画表格，列是页框，行是引用串的每一项
② 每次先查是否命中
③ 缺页时按算法选一个页框替换
④ 数「缺页」出现的行数
```

**FIFO 要点**：替换**最早进入**的（不看是否用过）。
**LRU 要点**：替换**最久没被访问**的（命中也要更新它的时间）。
**OPT 要点**：替换**将来最晚才用到**的（需要看未来，不可实现）。

### 模板 3：银行家算法

```text
① 算 Need = Max − Allocation
② Work = Available
③ 找一个 Need ≤ Work 的进程，假设它运行完，Work += Allocation
④ 重复 ③，若所有进程都能完成 → 安全，记录顺序
⑤ 找不到可满足的进程 → 不安全，拒绝分配
```

**例**：Available = (3,3,2)

| 进程 | Allocation | Max | Need |
|---|---|---|---|
| P0 | 0 1 0 | 7 5 3 | 7 4 3 |
| P1 | 2 0 0 | 3 2 2 | 1 2 2 |
| P2 | 3 0 2 | 9 0 2 | 6 0 0 |
| P3 | 2 1 1 | 2 2 2 | 0 1 1 |
| P4 | 0 0 2 | 4 3 3 | 4 3 1 |

```text
Work = 3 3 2
P1 Need(1,2,2) ≤ Work → 完成，Work = 3+2, 3+0, 2+0 = 5 3 2
P3 Need(0,1,1) ≤ Work → 完成，Work = 7 4 3
P4 Need(4,3,1) ≤ Work → 完成，Work = 7 4 5
P0 Need(7,4,3) ≤ Work → 完成，Work = 7 5 5
P2 Need(6,0,0) ≤ Work → 完成，Work = 10 5 7
安全序列：P1 → P3 → P4 → P0 → P2
```

> ⭐ 安全序列**不唯一**。P4 之后 P0 和 P2 都能跑，换个顺序也算对。

## 四、自测 15 题

**1.** 进程和线程，哪个是资源分配的基本单位？哪个是调度的基本单位？

**2.** 同一进程的多个线程，哪些资源是共享的？哪些是私有的？

**3.** 进程从「阻塞」能否直接转为「运行」？

**4.** 进程存在的唯一标志是什么？

**5.** 哪种调度算法的平均周转时间最短？

**6.** 信号量 S = −3 表示什么？

**7.** 生产者—消费者问题中，`P(empty)` 和 `P(mutex)` 的顺序能反吗？

**8.** 死锁的四个必要条件是什么？

**9.** 银行家算法属于死锁的哪种处理策略？

**10.** 分页和分段，哪个对用户可见？

**11.** 引用串 `7 0 1 2 0 3 0 4 2 3 0 3 2 1 2 0 1 7 0 1`，3 个页框，FIFO 缺页几次？

**12.** 同上，LRU 缺页几次？

**13.** 什么是 Belady 异常？哪种算法会出现？

**14.** 链接分配的缺点是什么？

**15.** SPOOLing 技术解决了什么问题？

---

### 答案与解析

**1.** 进程是**资源分配**的基本单位；线程是 **CPU 调度**的基本单位。

**2.** 共享：代码段、数据段、堆、打开的文件。私有：**栈**、寄存器、PC、线程 ID。

**3.** **不能**。阻塞必须先转成就绪，再由调度器选中才能运行。

**4.** **PCB（进程控制块）**。

**5.** **SJF（短作业优先）**。实测 FCFS 15.25、SJF 14.25、RR 19.25。

**6.** 有 **3 个进程**在等待该信号量（|S| = 等待进程数）。

**7.** **不能**。必须先 `P(empty)` 再 `P(mutex)`。
反过来会出现「生产者占着锁等空位，消费者拿不到锁取产品」的死锁。

**8.** 互斥、请求并保持、不可剥夺、**环路等待**。

**9.** **避免**（不是预防，也不是检测）。

**10.** **分段**对用户可见（按逻辑划分）；分页对用户不可见（纯物理划分）。

**11.** **15 次**（缺页率 75%）。

**12.** **12 次**（缺页率 60%）。

**13.** 增加页框数，缺页次数反而**增加**。只有 **FIFO** 会出现（实测 3 框 9 次、4 框 10 次）。

**14.** 只能**顺序访问**，不支持随机访问（要找第 k 块必须从头走）。

**15.** 把**独占设备**（打印机）改造成**共享设备**：多个进程的输出先写到磁盘缓冲区排队，
再由 SPOOLing 程序依次真正打印。

## 五、易错清单

1. 进程是资源分配单位，线程是调度单位 —— **别对调**。
2. 线程共享全局变量，但**栈是私有的**。
3. 阻塞不能直接到运行，必须先到就绪。
4. 进程存在的唯一标志是 **PCB**，不是程序。
5. 信号量 S < 0 时，**|S| 才是等待进程数**。
6. 生产者消费者里两个 P 的顺序不能反（先 P(empty) 再 P(mutex)）。
7. 死锁四条件缺一不可；银行家算法属于**避免**。
8. 分页有内部碎片，分段有外部碎片；分页对用户不可见。
9. FIFO 有 Belady 异常，**LRU / OPT 没有**。
10. 周转时间 = 完成 − 到达，**不是**完成 − 开始。
