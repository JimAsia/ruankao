# S3-01 考点手册 计算机组成与体系结构

> 这一块的核心是「**会算**」：补码、浮点、Cache、总线、可靠性。

## 二、必背考点

### 2.1 四种机器数编码（8 位）

| 真值 | 原码 | 反码 | 补码 | 移码 |
|---|---|---|---|---|
| 127 | 0111 1111 | 0111 1111 | 0111 1111 | 1111 1111 |
| 1 | 0000 0001 | 0000 0001 | 0000 0001 | 1000 0001 |
| 0 | 0000 0000 | 0000 0000 | 0000 0000 | **1000 0000** |
| −1 | 1000 0001 | 1111 1110 | **1111 1111** | 0111 1111 |
| −127 | 1111 1111 | 1000 0000 | 1000 0001 | 0000 0001 |
| −128 | **无** | **无** | **1000 0000** | 0000 0000 |

**三条必背结论**：

```text
① 原码 / 反码：−(2^(n−1)−1) ~ +(2^(n−1)−1)     8 位时是 −127 ~ +127
② 补码 / 移码：−2^(n−1) ~ +(2^(n−1)−1)          8 位时是 −128 ~ +127
③ 补码的 0 只有一种编码；原码有 +0 和 −0 两种
```

**转换规则**：

```text
正数：原码 = 反码 = 补码
负数：反码 = 原码符号位不变、其余取反
      补码 = 反码 + 1
移码 = 补码的符号位取反（只改最高位）
```

**为什么用补码**：把减法变成加法，硬件只需一套加法器。

```text
7 − 5 = 7 + (−5)
  7  的补码 = 0000 0111
  −5 的补码 = 1111 1011
  相加      = 1 0000 0010 → 丢掉最高位进位 = 0000 0010 = 2 ✓
```

**溢出判断（双符号位法）**：

```text
00 → 结果为正，正常
11 → 结果为负，正常
01 → 正溢出（两个正数相加超上限）
10 → 负溢出
```

### 2.2 IEEE 754 浮点数

| | 符号位 | 阶码 | 尾数 | 偏移量 |
|---|---|---|---|---|
| 单精度（32 位） | 1 | 8 | 23 | **127** |
| 双精度（64 位） | 1 | 11 | 52 | **1023** |

**阶码用移码，尾数用原码**，且尾数隐含最高位的 1（规格化）。

**完整推导 12.5**：

```text
12.5 = 1100.1(B) = 1.1001 × 2^3
符号 0
阶码 = 3 + 127 = 130 = 1000 0010
尾数 = 1001 0000 ... 0（23 位，去掉隐含的 1.）

拼起来：0 10000010 10010000000000000000000
即 0x41480000
```

> ⭐ 注意：尾数存的是小数点后的部分，**整数部分的 1 被省略**（规格化数的隐含位）。

**几个常见值的编码**（已用程序验证）：

| 十进制 | 十六进制 |
|---|---|
| 12.5 | 0x41480000 |
| 0.5 | 0x3F000000 |
| −6.0 | 0xC0C00000 |

### 2.3 汉字编码

```text
区位码：94 个区 × 94 个位，区号和位号各加 32（0x20）得国标码
国标码 = 区位码 + 2020H
机内码 = 国标码 + 8080H = 区位码 + A0A0H
字形码：点阵，16×16 点阵需要 16×16/8 = 32 字节
```

> ⭐ 高频题：给区位码求机内码，直接用 `区位码 + A0A0H` 一次算完。

### 2.4 CPU 的组成

| 部件 | 包含 | 作用 |
|---|---|---|
| **运算器** | ALU、累加器 ACC、通用寄存器、状态寄存器 PSW | 算术与逻辑运算 |
| **控制器** | PC、IR、指令译码器、时序发生器 | 取指、译码、发控制信号 |

**两个必须记准的寄存器**：

```text
PC（程序计数器）：存【下一条】要执行的指令地址，自动加 1
IR（指令寄存器）：存【当前】正在执行的指令
```

> ⭐ 常考：PC 里放的是「下一条指令的地址」而不是「当前指令」。

### 2.5 寻址方式

| 寻址方式 | 操作数在哪 | 例子 |
|---|---|---|
| **立即寻址** | 就在指令里 | `MOV R1, #5` |
| **直接寻址** | 指令给出内存地址 | `MOV R1, [1000]` |
| **间接寻址** | 指令给出地址，该地址存着真正的地址 | `MOV R1, [[1000]]` |
| **寄存器寻址** | 在寄存器里 | `MOV R1, R2` |
| **寄存器间接** | 寄存器里存的是地址 | `MOV R1, [R2]` |
| **相对寻址** | PC + 偏移量 | 跳转指令 |
| **变址寻址** | 变址寄存器 + 偏移 | 数组遍历 |
| **基址寻址** | 基址寄存器 + 偏移 | 程序重定位 |

### 2.6 CISC 与 RISC

| | CISC | RISC |
|---|---|---|
| 指令数量 | 多 | **少** |
| 指令长度 | 不等长 | **等长** |
| 寻址方式 | 多 | **少** |
| 执行时间 | 差异大 | **大多一个周期** |
| 控制器实现 | 微程序控制为主 | **硬布线为主** |
| 流水线 | 难 | **容易** |
| 典型 | x86 | ARM、MIPS |

### 2.7 存储系统

**层次结构（从快到慢、从贵到便宜、容量从小到大）**：

```text
寄存器 → Cache → 主存 → 辅存（磁盘/SSD）
```

**Cache 平均访问时间**：

```text
t = h × t_cache + (1 − h) × t_main
```

实测（`t_cache = 1ns`，`t_main = 10ns`）：

| 命中率 h | 平均访问时间 |
|---|---|
| 0.90 | 1.900 ns |
| 0.95 | 1.450 ns |
| 0.98 | 1.180 ns |
| 0.99 | 1.090 ns |

> ⭐ 命中率从 90% 到 99%，平均时间降了近一半。
> **Cache 的关键指标是命中率，不是容量。**

**两个局部性原理**：

```text
时间局部性：刚被访问的数据，很快还会被访问（循环变量）
空间局部性：刚被访问的数据，它旁边的也会被访问（数组）
```

**替换算法**：FIFO、LRU（最近最少使用）、LFU（最不经常使用）、随机。
**写策略**：写直达（write through，同步写主存，慢但一致）、
写回（write back，只写 Cache，脏块换出时才写主存，快但需标记）。

**容量计算**：

```text
按字节编址，地址线 n 根 → 可寻址 2^n 个字节
地址线 20 根 → 2^20 B = 1 MB
```

### 2.8 总线

| 总线 | 传什么 | 决定什么 |
|---|---|---|
| 数据总线 | 数据 | 一次能传多少位（位宽） |
| 地址总线 | 地址 | 能寻址多大空间（2^n） |
| 控制总线 | 控制信号 | 读写、中断、时钟等 |

**带宽计算**：

```text
带宽 = 每次传输字节数 × 传输频率
```

实测：

| 规格 | 计算 | 带宽 |
|---|---|---|
| 32 位 / 66 MHz | 4 B × 66 M | 264 MB/s |
| 64 位 / 100 MHz | 8 B × 100 M | 800 MB/s |
| 32 位 / 133 MHz | 4 B × 133 M | 532 MB/s |

> ⚠️ 最常见的错：忘了「位 ÷ 8 = 字节」，直接把 32 当字节算成 2112 MB/s。

### 2.9 I/O 方式

| 方式 | CPU 参与度 | 特点 |
|---|---|---|
| 程序查询（轮询） | 全程占用 | 最简单，效率最低 |
| **中断** | 传输时不管 | 外设主动通知 CPU |
| **DMA** | 只在开始/结束时参与 | 数据块直接进内存，效率高 |
| 通道 | 几乎不参与 | 专用处理器，大型机 |

### 2.10 可靠性与性能

```text
MTBF：平均无故障时间
MTTR：平均修复时间
可用性 = MTBF / (MTBF + MTTR)

串联可靠性：R = R1 × R2 × ...
并联可靠性：R = 1 − (1−R1)(1−R2)×...
```

实测（三个 0.9 的部件）：

```text
串联 R = 0.7290
并联 R = 0.9990
```

**性能公式**：

```text
MIPS = 主频 / (CPI × 10^6)
```

实测：

| 主频 | CPI | MIPS |
|---|---|---|
| 1000 MHz | 2 | 500 |
| 2000 MHz | 2 | 1000 |
| 2000 MHz | 4 | **500** |

> ⭐ 主频翻倍但 CPI 也翻倍，性能一样 —— 这就是「主频不等于性能」。

## 三、计算题模板

### 模板 1：求补码

```text
步骤：① 写出绝对值的二进制
      ② 从右往左，遇到第一个 1 及其右边不变，左边全部取反
      （这是「取反加一」的快速做法）
```

例：求 −100 的 8 位补码。

```text
100 = 0110 0100
最右边的 1 在第 3 位（从 0 数），它和右边不变 → ...100
左边 0110 全部取反 → 1001
结果：1001 1100 = 0x9C
验证：−100 = −128 + 28，补码 = 1000 0000 + 0001 1100 = 1001 1100 ✓
```

### 模板 2：求 IEEE 754 编码

```text
步骤：① 转二进制
      ② 规格化成 1.xxxx × 2^e
      ③ 阶码 = e + 127，转 8 位二进制
      ④ 尾数 = 小数点后的部分，补足 23 位
      ⑤ 拼接：符号 + 阶码 + 尾数
```

### 模板 3：Cache 平均访问时间

```text
直接代 t = h×tc + (1−h)×tm
注意单位统一（都是 ns 或都是 μs）
```

### 模板 4：总线带宽

```text
带宽 = (位宽 / 8) × 频率
结果单位是 MB/s（频率按 MHz 算）
```

## 四、自测 15 题

**1.** 8 位补码 `1000 0000` 表示的真值是多少？

**2.** −1 的 8 位补码是什么？

**3.** 8 位原码能表示的整数范围是多少？

**4.** 12.5 的 IEEE 754 单精度编码（十六进制）是多少？

**5.** 单精度浮点数的阶码偏移量是多少？

**6.** Cache 访问 1ns、主存 10ns、命中率 0.95，平均访问时间是多少？

**7.** 32 位数据总线、66MHz 频率，带宽是多少？

**8.** 三个可靠度都是 0.9 的部件串联、并联，整体可靠度分别是？

**9.** 主频 2GHz、CPI = 4，MIPS 是多少？

**10.** 操作数直接写在指令中的寻址方式叫什么？

**11.** 指令寄存器 IR 和程序计数器 PC 分别存什么？

**12.** RISC 相比 CISC 的三个主要特点？

**13.** 汉字「啊」的区位码是 1601（即 16 区 01 位，十进制），求它的国标码和机内码。

**14.** DMA 方式和中断方式的核心区别？

**15.** 存储层次从快到慢的顺序？

---

### 答案与解析

**1.** **−128**。补码 `1000 0000` 是 −128 的专用编码，没有对应的原码。

**2.** `1111 1111`。−1 的补码是全 1，这是最好记的一个。

**3.** **−127 ~ +127**。原码的尾数只有 7 位，最大 127；且 +0/−0 占两个编码。

**4.** `0x41480000`。12.5 = 1.1001×2³，阶码 3+127=130=`10000010`。

**5.** **127**（双精度是 1023）。

**6.** `0.95×1 + 0.05×10 = 1.45 ns`。

**7.** `32/8 × 66 = 264 MB/s`。别忘了除以 8。

**8.** 串联 `0.9³ = 0.729`；并联 `1−(1−0.9)³ = 0.999`。

**9.** `2000 / 4 = 500 MIPS`（主频按 MHz 算，已经是 2000MHz）。

**10.** **立即寻址**。

**11.** IR 存**当前正在执行**的指令；PC 存**下一条**指令的地址。

**12.** 指令数量少、指令等长、寻址方式少（另外：多用寄存器、硬布线控制、易流水线）。

**13.** 国标码 `3021H`，机内码 `B0A1H`。

```text
区位码 → 国标码：区号、位号各加 32（20H）
   16 + 32 = 48 = 30H
    1 + 32 = 33 = 21H
   → 国标码 3021H

国标码 → 机内码：各字节再加 80H
   30H + 80H = B0H
   21H + 80H = A1H
   → 机内码 B0A1H
```

> 一步到位的写法：机内码 = 区位码 + A0A0H，即 `10H+A0H=B0H`、`01H+A0H=A1H`。
> 注意区位码要先写成**十六进制**再相加（16 区 = 10H，不是 16H）。

**14.** 中断是**每传一个字节/字就打断 CPU 一次**；DMA 是**整块数据传完才打断一次**，
传输过程由 DMA 控制器直接控制内存与外设，不经过 CPU。

**15.** 寄存器 → Cache → 主存 → 辅存。

## 五、易错清单

1. 补码范围是 **−2^(n−1)**，原码是 **−(2^(n−1)−1)**，差的就是那个 −128。
2. 移码 = 补码**只改符号位**，不是「取反加一」。
3. IEEE 754 的尾数**省略了整数位的 1**，别把它算进 23 位。
4. 阶码偏移量：单精度 127，双精度 1023，**不是 128**。
5. Cache 公式里 `(1−h)` 乘的是**主存时间**，不是 Cache 时间。
6. 总线带宽单位换算：**位 ÷ 8**，这是最高频的失分点。
7. PC 存下一条指令地址，IR 存当前指令，别对调。
8. 并联可靠性是 `1−(1−R)^n`，不是 `1−R^n`。
9. MIPS 公式里主频要换算成 MHz（或除以 10⁶），单位别混。
10. 汉字编码的三级偏移：国标码 = 区位码 + 2020H，机内码 = 国标码 + 8080H，
    合并起来机内码 = 区位码 + A0A0H。换算前先把区号位号转成十六进制。
