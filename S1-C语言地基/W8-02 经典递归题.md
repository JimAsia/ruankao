## 一、汉诺塔（递归思维的标杆）

**规则**：三根柱子，把 n 个盘子从 A 移到 C，每次移一个，大盘不能压小盘。

**递归拆解**：

```text
① 把上面 n-1 个盘子从 A 移到 B（借助 C）
② 把最大的那个从 A 移到 C
③ 把 n-1 个盘子从 B 移到 C（借助 A）
```

```c
void hanoi(int n, char from, char to, char via)
{
    if (n == 1) {                        /* 出口：一个盘子直接搬 */
        printf("盘子 1 从 %c 移到 %c\n", from, to);
        return;
    }
    hanoi(n - 1, from, via, to);         /* ① */
    printf("盘子 %d 从 %c 移到 %c\n", n, from, to);
    hanoi(n - 1, via, to, from);         /* ③ */
}
```

**3 个盘子的实测过程**：

```text
  第  1 步：把盘子 1 从 A 移到 C
  第  2 步：把盘子 2 从 A 移到 B
  第  3 步：把盘子 1 从 C 移到 B
  第  4 步：把盘子 3 从 A 移到 C
  第  5 步：把盘子 1 从 B 移到 A
  第  6 步：把盘子 2 从 B 移到 C
  第  7 步：把盘子 1 从 A 移到 C
  共 7 步
```

### 1.1 ⭐ 移动次数公式

实测对照（递归计数 vs 公式）：

```text
  n    递归计数    公式 2^n-1
  1    1           1
  2    3           3
  3    7           7
  5    31          31
  10   1023        1023
```

**推导**：

```text
f(n) = 2 × f(n-1) + 1，且 f(1) = 1
展开：f(n) = 2^n - 1
```

> 📌 **`2ⁿ - 1` 是软考的高频结论，必须背下来。**
> 64 个盘子需要 `2^64 - 1 ≈ 1.8 × 10^19` 步 —— 一秒一步要 5849 亿年。

## 二、斐波那契：递归的"教训"

```c
long long fibRec(int n)
{
    if (n <= 2) return 1;
    return fibRec(n - 1) + fibRec(n - 2);     /* 调用自己两次！ */
}
```

**实测的调用次数**：

```text
  n    递归调用次数
  10   109
  20   13529
  25   150049
  30   1664079
```

**为什么这么多次**：重复计算。

```text
算 fib(5)：
  fib(5) = fib(4) + fib(3)
         = (fib(3) + fib(2)) + (fib(2) + fib(1))
           ↑ fib(3) 算了两次
         = ((fib(2)+fib(1)) + 1) + (1 + 1)
           ↑ fib(2) 算了三次 ...
```

**复杂度**：朴素递归 O(2ⁿ)，迭代 O(n)。

> 📌 软考经常问「斐波那契递归版的时间复杂度」，答案是 **O(2ⁿ)**，不是 O(n)。

## 三、最大公约数：最优雅的递归

```c
int gcd(int a, int b)
{
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

**三行代码，没有循环，完全贴合数学定义。**

实测：

```text
  gcd(12, 18) = 6
  gcd(100, 75) = 25
  gcd(17, 5) = 1
```

**展开过程**：

```text
gcd(12, 18) → gcd(18, 12)  【12 % 18 = 12】
gcd(18, 12) → gcd(12, 6)   【18 % 12 = 6】
gcd(12, 6)  → gcd(6, 0)    【12 % 6 = 0】
gcd(6, 0)   → 出口，返回 6
```

**为什么规模一定缩小**：余数必然小于除数，所以第二个参数严格递减，最终到 0。

## 四、十进制转二进制：输出顺序的教科书

```c
void toBinary(int n)
{
    if (n == 0) return;
    toBinary(n / 2);          /* ① 先递归处理高位 */
    printf("%d", n % 2);      /* ② 再输出这一位 */
}
```

实测：

```text
  10   → 1010
  255  → 11111111
  1024 → 10000000000
```

**为什么先递归才对**：

```text
toBinary(10) 调 toBinary(5) 调 toBinary(2) 调 toBinary(1) 调 toBinary(0)
                                                                  ↓ 出口
返回时依次打印：
  toBinary(1)  → 1 % 2 = 1
  toBinary(2)  → 2 % 2 = 0
  toBinary(5)  → 5 % 2 = 1
  toBinary(10) → 10 % 2 = 0
结果：1 0 1 0  ← 正是 10 的二进制
```

**如果先 printf 再递归**，输出变成 `0101` —— 倒的。

> 💡 **规律：先递归后输出 → 逆序（从深处往外）；先输出后递归 → 正序（从外往里）。**
> 判断软考的输出顺序题，就看 printf 在递归调用的哪一边。

## 五、四个经典题一览

| 题目 | 出口 | 递推 | 考点 |
|---|---|---|---|
| 汉诺塔 | `n == 1` | 两次 `hanoi(n-1)` | 移动次数 `2ⁿ-1` |
| 斐波那契 | `n <= 2` | `fib(n-1) + fib(n-2)` | 复杂度 O(2ⁿ) |
| gcd | `b == 0` | `gcd(b, a%b)` | 规模必然缩小 |
| 转二进制 | `n == 0` | `toBinary(n/2)` | 输出顺序 |
