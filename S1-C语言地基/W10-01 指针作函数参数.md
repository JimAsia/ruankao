## 一、指针传参解决两个问题

| 问题 | 解法 |
|---|---|
| ① 让函数能修改调用者的变量 | 传地址 |
| ② 让函数能「返回」多个结果 | 用指针当输出参数 |

---

## 二、① 修改实参：swap

```c
void swap(int *a, int *b)
{
    int t = *a;
    *a = *b;
    *b = t;
}
swap(&x, &y);
```

实测：

```text
  交换前：x = 1, y = 2
  交换后：x = 2, y = 1
```

> 📌 这就是 W7「swap 为什么失败」的最终答案。
> **C 语言仍然是值传递**，变的是「传什么值」—— 传值只能读，传地址能改。

---

## 三、② 返回多个结果：输出参数

C 函数只能 `return` 一个值。想同时给出多个结果，用指针写出去：

```c
void minMax(int a[], int n, int *outMin, int *outMax)
{
    int mn = a[0], mx = a[0];
    for (int i = 1; i < n; i++) {
        if (a[i] < mn) mn = a[i];
        if (a[i] > mx) mx = a[i];
    }
    *outMin = mn;
    *outMax = mx;
}
```

调用：

```c
int mn, mx;
minMax(a, 6, &mn, &mx);      /* 传地址，函数才能写进去 */
```

实测：`最小值 = 38，最大值 = 91`

> 💡 这和 `scanf("%d", &n)` 是**完全同一个原理** —— `scanf` 也是用指针"返回"读到的值。
> 现在你应该明白为什么 `scanf` 必须加 `&` 了。

### 3.1 更常见的模式：返回值 + 输出参数

```c
int divide(int a, int b, int *remainder)
{
    if (b == 0) {
        *remainder = 0;
        return -1;                  /* 返回值表示出错 */
    }
    *remainder = a % b;
    return a / b;                   /* 返回值是主结果 */
}
```

实测：

```text
  17 / 5 = 3 余 2
  10 / 0 → 返回值 = -1（-1 表示出错）
```

**这是 C 库的经典风格**：返回值给主结果或错误码，其余结果通过指针带出。

## 四、⭐ 二级指针：改「指针的指向」

```c
void retarget(int **pp, int *target)
{
    *pp = target;
}
retarget(&p, &b);
```

实测：

```text
  初始：*p = 10（指向 m）
  redirect 之后：*p = 20（改指向 n 了）
```

**为什么必须二级**：

```c
/* 如果写成一级指针 */
void bad(int *pp, int *target) { pp = target; }   /* ❌ 只改了副本 */
```

`pp` 是 `p` 的副本，改它不影响 `p` —— 又回到 swap 的老问题。

**类型链**：

```text
p      int*     指向 int
&p     int**    指向「int*」
*pp    int*     就是 p 本身
**pp   int      就是 p 指向的值
```

所以 `*pp = target` 等价于 `p = target`。

---

## 五、⭐ 传什么取决于想改什么

| 想做的事 | 参数类型 |
|---|---|
| 只读一个 `int` | `int` |
| 要改一个 `int` | `int *` |
| 只读一个数组 | `const int a[]` |
| 要改一个数组 | `int a[]` |
| 要改一个指针的指向 | `int **` |

---

## 六、`int a[]` 与 `int *a` 完全等价

实测：

```text
  sum1(a, 6) = 30      ← int a[]
  sum2(a, 6) = 30      ← int *a
  sum3(a, 6) = 30      ← int a[10]
```

**编译器把三者当成同一个类型 `int *a`。**

⚠️ `int a[10]` 里的那个 **10 被完全忽略** —— 传一个只有 3 个元素的数组也不会报错。

> 📌 这就是「数组参数必须传长度」的根本原因，现在你知道它为什么绕不过去了。

**二维数组例外**：列数不能省。

```c
int sumMatrix(int m[][4], int rows)     /* ✅ */
int sumMatrix(int m[][], int rows)      /* ❌ 编译错误 */
```

因为 `m` 的类型是 `int (*)[4]`（数组指针），列数是类型的一部分。
