## 一、条件运算符 `?:`

C 语言**唯一的三元运算符**：

```c
条件 ? 成立时的值 : 不成立时的值
```

```c
int max = (a > b) ? a : b;
```

### 1.1 它和 if-else 的本质区别

| | `if-else` | `?:` |
|---|---|---|
| 是什么 | **语句** | **表达式** |
| 有值吗 | 没有 | 有（两个分支之一的值） |
| 能嵌在表达式里吗 | ❌ | ✅ |

所以 `?:` 能直接参与运算，`if-else` 不行：

```text
10 + ((a > b) ? a : b) = 15
```

真实输出（a=5, b=3）：

```text
10 + ((a > b) ? a : b) = 15
  如果换成 if-else，你得先算出来存进变量再用
```

### 1.2 嵌套

```c
const char *level = (score >= 90) ? "优秀"
                  : (score >= 80) ? "良好"
                  : (score >= 60) ? "及格"
                  :                 "不及格";
```

真实输出（score = 72）：`score = 72 → 及格`

> ⚠️ 嵌套超过两层可读性就崩了。这种时候改写 `if-else if` 链更好——代码是给人看的。

### 1.3 等价改写对照

```c
/* 三元 */
const char *sign1 = (x > 0) ? "正数" : (x < 0) ? "负数" : "零";

/* if-else 链 */
const char *sign2;
if (x > 0)      sign2 = "正数";
else if (x < 0) sign2 = "负数";
else            sign2 = "零";
```

两者结果完全相同。**三元适合「短、单层」，if-else 适合「长、多层」。**

### 1.4 常见误用

| 误用 | 问题 |
|---|---|
| `(a > b) ? a` | 少了冒号分支，编译错误 |
| `(a > b) ? a : 3.5` | 两边类型不同，结果被隐式转成 double |
| `a > b ? printf("x") : ;` | 用表达式做副作用，难读 |

## 二、四个经典分支题

这四个题型的共同点：**不用循环就能写完**，是应用技术分支题的原型。

### 2.1 闰年判断

**规则**：能被 4 整除且不能被 100 整除，**或者**能被 400 整除。

```c
if ((year % 4 == 0 && year % 100 != 0) || (year % 400 == 0))
    printf("%d 是闰年\n", year);
else
    printf("%d 是平年\n", year);
```

真实运行结果：

```text
  2024 → 闰年
  2023 → 平年
  1900 → 平年   （能被 100 整除但不能被 400 整除，所以是平年）
  2000 → 闰年   （能被 400 整除，所以是闰年）
```

> 📌 **1900 和 2000 是检验你写对没写对的关键**。只写 `year % 4 == 0` 的话，1900 会被判成闰年 —— 错。
> 这是软考和所有编程入门考试的经典题，务必记准。

### 2.2 成绩分级：两种写法

```c
/* 写法一：if - else if 链（范围判断，从大到小） */
if (score >= 90)      printf("优秀\n");
else if (score >= 80) printf("良好\n");
else if (score >= 70) printf("中等\n");
else if (score >= 60) printf("及格\n");
else                  printf("不及格\n");

/* 写法二：switch（先除 10 把范围变离散值） */
switch (score / 10) {
    case 10:
    case 9:  printf("优秀\n"); break;
    case 8:  printf("良好\n"); break;
    case 7:  printf("中等\n"); break;
    case 6:  printf("及格\n"); break;
    default: printf("不及格\n");
}
```

真实输出（score = 85）：

```text
  if-else 链：良好
  switch  ：良好
```

### 2.3 三数排序（不用循环）

```c
int a = 3, b = 1, c = 2, t;

if (a > b) { t = a; a = b; b = t; }   /* 保证 a <= b */
if (a > c) { t = a; a = c; c = t; }   /* 保证 a <= c，此时 a 已是最小 */
if (b > c) { t = b; b = c; c = t; }   /* 保证 b <= c */
```

真实输出：

```text
  排序前：a=3 b=1 c=2
  排序后：a=1 b=2 c=3
```

**这三行的顺序能打乱吗？不能。** 每一行都依赖前一行建立的顺序：

- 第 1 行保证 a 最小（在 a、b 之间）
- 第 2 行保证 a 是三者最小
- 第 3 行保证 b ≤ c，此时 a 最小、c 最大

> 📌 「交换两个变量」这个动作在 W1 的 ex05 练过。这里连续用三次，是分支题的经典套路。

### 2.4 三角形判断（两层逻辑）

```c
if (x + y > z && x + z > y && y + z > x) {
    /* 外层：能不能构成三角形 */
    if (x == y && y == z)
        printf("等边三角形\n");
    else if (x == y || y == z || x == z)
        printf("等腰三角形\n");
    else if (x*x + y*y == z*z || ...)
        printf("直角三角形\n");
    else
        printf("普通三角形\n");
} else {
    printf("不能构成三角形\n");
}
```

真实输出（3 4 5）：`→ 直角三角形`

**关键**：外层先判「能不能构成」，内层再判「是什么类型」。两层逻辑不能合并 —— 否则 `1 1 5` 会被判成等腰三角形。

## 三、分支 ↔ 流程图

应用技术的流程图题就是分支的图形表达，两种基本结构：

```text
顺序结构              选择结构
┌─────┐              ┌─────┐
│  A  │              │判断 │
└──┬──┘              └─┬─┬─┘
   │                 是│ │否
┌──▼──┐            ┌──▼┐┌▼──┐
│  B  │            │ A ││ B │
└─────┘            └───┘└───┘
```

**读流程图的三个动作**
1. 找到所有判断框（菱形），每个对应一个 `if`
2. 找到汇合点，判断是 `if-else` 还是连续 `if`
3. 注意循环回边（W4 会讲）

**画流程图的要点**
- 菱形只能有一个入口、两个出口（是/否）
- 每个分支最终都要能走到出口，不能有「死路」
- 汇合点之后是公共代码

## 四、软考怎么考这部分

| 考点 | 位置 | 典型问法 |
|---|---|---|
| 闰年判断条件 | 应用技术 | 补全判断条件 |
| 三数排序的交换次数 | 应用技术 | 给三个数问交换几次 |
| `?:` 的求值 | 应用技术 | 给表达式问结果 |
| 分支覆盖 | 应用技术 | 要覆盖所有分支至少需要几组测试数据 |
| 流程图转代码 | 应用技术 | 给流程图写等价代码 |

**分支覆盖的算法**：数一数代码里有多少个**独立的判断结果**（每个 if 的真和假各算一个），至少需要那么多组数据。
