## 三、自测：全对才进 W10

**1. `int a = 42; int *p = &a;` 之后，`p`、`*p`、`&p` 分别是什么？**

**2. 64 位系统上 `sizeof(int *)` 是多少？那 `sizeof(char *)` 呢？**

**3. `int *p = NULL;` 和 `int *p;` 有什么区别？哪个更危险？**

**4. 下面两个写法结果一样吗？**

```c
int a[3] = {1, 2, 3};
int *p = a;
a[1];
*(a + 1);
```

**5. `int *p` 加 1，地址增加几字节？如果你是 `char *p` 呢？**

**6. 下面代码有什么问题？**

```c
int *f(void) {
    int x = 10;
    return &x;
}
```

---

## 四、标准答案

1. **`p` 是 a 的地址；`*p` 是 42；`&p` 是 p 自己的地址（和 a 的地址不同）。**

2. **都是 8 字节。** 指针本身大小只和平台有关（64 位系统存 8 字节地址），和它指向什么类型无关。但**解引用时读的字节数不同**：`char*` 读 1 字节，`int*` 读 4 字节。

3. **`= NULL` 是空指针（值确定是 0，可以判断）；不初始化是野指针（值随机，判断不了）。野指针更危险** —— 因为它连「检查」都做不到。

4. **完全一样。** `a[i]` 就是 `*(a + i)` 的语法糖，编译器生成相同的代码。这是 C 语言的定义，不是巧合。

5. **`int*` 加 1 增加 4 字节（`sizeof(int)`）；`char*` 加 1 增加 1 字节。** 指针的步长由它指向的类型决定，这正是「指针类型」存在的意义。

6. **返回了局部变量的地址。** `x` 在函数返回时就销毁了，那个地址指向的内存已经不属于你，再访问会读到垃圾数据。编译器会警告 `-Wreturn-local-addr`。
   正确做法：用 `static int x`，或者由调用者传入缓冲区。
