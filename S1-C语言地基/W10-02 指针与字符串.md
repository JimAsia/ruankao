## 一、⭐ 字符数组 vs 字符指针（W6 的完整答案）

```c
char arr[] = "Hello";       /* 数组：栈上 6 字节，内容可改 */
char *ptr  = "Hello";       /* 指针：指向只读区，内容不可改 */
```

实测：

```text
  char arr[] = "Hello";   sizeof(arr) = 6
  char *ptr  = "Hello";   sizeof(ptr) = 8（指针大小）
```

| | `char arr[]` | `char *ptr` |
|---|---|---|
| 存什么 | 6 个字符本身 | 一个地址 |
| 在哪 | 栈 | 指针在栈，字符串在只读区 |
| 能改内容 | ✅ | ❌ 崩溃 |
| 能移动 | ❌ `arr++` 编译错误 | ✅ `ptr++` |

### 1.1 存储位置实测

```text
  arr 的地址 = 000000C427BFFE32（栈）
  ptr 的值   = 00007FF65DF84039（只读数据段）
  ptr 自己的地址 = 000000C427BFFE28（栈，它是变量）
```

> 💡 `ptr` 是个变量（在栈上），它存的值指向只读区。
> 所以 `ptr++` 合法（改 ptr 的值），`ptr[0] = 'x'` 崩溃（改只读区）。

## 二、用指针遍历字符串

三种写法，效果完全一样：

```c
/* 写法一：数组下标 */
for (int i = 0; text[i] != '\0'; i++) putchar(text[i]);

/* 写法二：指针移动 */
for (char *q = text; *q != '\0'; q++) putchar(*q);

/* 写法三：指针 + while（最简洁） */
char *r = text;
while (*r) { putchar(*r); r++; }
```

`while (*r)` 能省掉 `!= '\0'`，因为 `'\0'` 的 ASCII 就是 0，而「非 0 即真」。

---

## 三、指针移动演示

```c
char text[] = "Programming";
char *p = text;
```

实测：

```text
  p = text 之后，*p = 'P'
  p++ 之后，*p = 'r'（指向第二个字符）
  p += 3 之后，*p = 'r'（现在指向第 5 个字符）
```

> 📌 数组名 `text` 不能这样：`text++` 是编译错误。

## 四、⭐ 多个字符串的两种存法

### 4.1 二维字符数组

```c
char names1[3][10] = {"Alice", "Bob", "Cathy"};
```

```text
A l i c e \0 ? ? ? ?
B o b \0 ? ? ? ? ? ?
C a t h y \0 ? ? ? ?
```

- 占 **30 字节**
- 每个字符串最多 9 个字符
- ✅ 内容可改

### 4.2 指针数组

```c
const char *names2[3] = {"Alice", "Bob", "Cathy"};
```

```text
names2[0] ──→ "Alice"（在只读区）
names2[1] ──→ "Bob"
names2[2] ──→ "Cathy"
```

- 占 **24 字节**（3 个指针）
- 字符串长度不受限
- ❌ 内容不可改

### 4.3 怎么选

| 需求 | 选择 |
|---|---|
| 需要修改字符串内容 | `char arr[][N]` |
| 只读，且字符串多/长 | `const char *arr[]` |
| 函数参数（只读） | `const char *` |

> 📌 软考问「`char *a[]` 和 `char a[][10]` 的区别」，就答：**前者是指针数组（存地址），后者是二维数组（存内容）**。

## 五、`const char *` 为什么到处出现

几乎所有字符串函数都长这样：

```c
size_t strlen(const char *s);
int    strcmp(const char *a, const char *b);
char  *strcpy(char *dst, const char *src);
```

| 参数 | 含义 |
|---|---|
| `const char *src` | 我只读你的字符串，不改 |
| `char *dst` | 我要往你这里写 |

**这是一种「接口承诺」**：看函数签名就知道它会不会动你的数据。

> 💡 自己写函数时，只读的字符串参数一律加 `const`。

## 六、常见错误

| 错误 | 后果 |
|---|---|
| `char *p = "abc"; p[0] = 'x';` | ❌ 段错误（只读区） |
| `char *p; strcpy(p, "abc");` | ❌ 野指针，没分配空间 |
| `char buf[5]; strcpy(buf, "Hello");` | ❌ 越界（需要 6 字节） |
| `if (s1 == s2)` | ❌ 比地址，要用 `strcmp` |
| `char s[10]; s = "abc";` | ❌ 数组名不能赋值 |
