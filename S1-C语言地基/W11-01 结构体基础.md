# W11-01 结构体基础

> 前面学的类型都是「装一个值」：`int` 装一个整数，`double` 装一个小数。
> 但现实中的数据是一组的 —— 一个学生有学号、姓名、年龄、成绩。
> 结构体就是把这些打包成一个整体的工具。
> 这是 C 语言唯一的自定义复合类型。

---

## 一、为什么需要结构体

不用结构体，学生会写成四个平行数组：

```c
int    ids[100];
char   names[100][20];
int    ages[100];
double scores[100];
```

能跑，但一旦要排序，四个数组必须**同步**交换。漏一个就数据错乱：

```c
/* 排序时每个都要换，换 4 次 */
int    t1 = ids[j];      ids[j] = ids[j+1];      ids[j+1] = t1;
char   t2[20];           strcpy(t2, names[j]);   strcpy(names[j], names[j+1]); strcpy(names[j+1], t2);
int    t3 = ages[j];     ages[j] = ages[j+1];    ages[j+1] = t3;
double t4 = scores[j];   scores[j] = scores[j+1]; scores[j+1] = t4;
```

用结构体，交换就是一句：

```c
struct Student t = a[j];
a[j] = a[j+1];
a[j+1] = t;
```

> 💡 结构体的价值不是「省代码」，是**保证数据一致**。它让「属于同一个体的字段」在物理上绑在一起，搬动时不会漏。

---

## 二、定义与三种初始化

### 定义

```c
struct Student {
    int    id;
    char   name[20];
    int    age;
    double score;
};                      /* ⚠️ 这个分号不能丢 */
```

定义只是**声明一种类型**，不分配内存。它相当于告诉编译器：「以后有个类型叫 `struct Student`，由这四个成员组成」。

> 📝 少写分号时，gcc 报的错是 `expected ';' at end of declaration`，指向的往往是下一行，容易看错地方。

### 三种初始化

```c
/* ① 按顺序：位置错了编译器未必报错 */
struct Student s1 = {2026001, "张三", 18, 92.5};

/* ② 指定成员名（C99）：最安全，顺序无关 */
struct Student s2 = {
    .score = 88.0,
    .id    = 2026002,
    .name  = "李四",
    .age   = 19
};

/* ③ 先声明再逐个赋值 */
struct Student s3;
s3.id = 2026003;
strcpy(s3.name, "王五");     /* 字符数组不能用 = */
s3.age = 20;
s3.score = 76.5;
```

本机真实输出：

```text
s1: 2026001 张三 18 92.5
s2: 2026002 李四 19 88.0
s3: 2026003 王五 20 76.5
```

> ❌ 方式一的坑：`{2026001, "张三", 92.5, 18}` 这样把成绩和年龄写反，编译器**不报错**（都是数字），只会给你一个错得莫名其妙的结果。字段多的时候一律用方式二。

> ✅ **`s3.name = "王五"` 是错的。** `name` 是数组，数组名是地址常量，不能被赋值。必须 `strcpy`。这条在 W6 讲过，结构体里同样适用。

### 结构体可以整体赋值

```c
struct Student s4 = s1;      /* ✅ 合法：整个结构体逐字节拷贝 */
s4.score = 100.0;            /* 改的是副本，s1 不受影响 */
```

真实输出：

```text
s4 = s1 之后，改 s4.score = 100
s1.score = 92.5（没变）
s4.score = 100.0
```

> 📝 这里有一条重要区别：**数组之间不能 `a = b`，结构体可以 `s1 = s2`。**
> 因为数组名是常量地址，结构体名是变量。软考选择题问过这个。

## 三、内存对齐：`sizeof` 不等于成员之和

```c
struct Student {
    int    id;      /* 4 */
    char   name[20];/* 20 */
    int    age;     /* 4 */
    double score;   /* 8 */
};
```

成员之和 = 36 字节，但 `sizeof(struct Student)` = **40 字节**。真实输出：

```text
s1 占 40 字节
成员之和 = 36 字节
差值 = 4 字节 ← 这叫「内存对齐」，不是浪费
```

多出来的 4 字节是「填充字节」（padding），里面没有数据。

### 对齐的两条规则

1. **每个成员的偏移量，必须是它自身大小的整数倍**，不够就补空字节。
2. **结构体总大小，必须是最大成员大小的整数倍**，不够就补齐。

按这两条算 `Student`：

| 成员 | 大小 | 偏移 | 说明 |
|---|---|---|---|
| `id` | 4 | 0 | 4 的倍数 ✓ |
| `name` | 20 | 4 | 20 的首地址 4 是 1 的倍数 ✓ |
| `age` | 4 | 24 | 24 是 4 的倍数 ✓ |
| `score` | 8 | 28 | **28 不是 8 的倍数** → 补 4 字节，偏移变 32 |
| — | — | 32+8=40 | 最大成员是 8，40 是 8 的倍数 ✓ |

### 成员顺序会改变大小

这是最反直觉的一点，实测三组：

```text
{ char c; int i; }            →  8 字节（1 + 3填充 + 4）
{ char a; double d; char b; } → 24 字节（1 + 7填充 + 8 + 1 + 7填充）
{ double d; char a; char b; } → 16 字节（8 + 1 + 1 + 6填充）
```

同样三个成员，只是顺序不同：**24 字节 vs 16 字节，差 8 字节**。

> ⭐ 结论：**小成员放一起，大成员放前面。** 但日常编程不必刻意优化，只有内存敏感场景（嵌入式、大数组）才值得调整顺序。

### 软考怎么考

| 考法 | 应对 |
|---|---|
| 「`sizeof(struct)` 是多少」 | 按两条规则逐成员推，**不能直接相加** |
| 「结构体和共用体的大小」 | 结构体≈之和+填充；共用体=最大成员 |
| 「为什么要有对齐」 | CPU 按字长访问内存，不对齐需要两次访问 |

## 四、成员访问：`.` 与 `->`

```c
struct Student s = {2026001, "张三", 92.5};
struct Student *p = &s;

s.score      /* 变量用 . */
p->score     /* 指针用 -> */
(*p).score   /* 等价写法，括号不能省 */
```

三者结果一样，实测都是 `92.5`。

> ❌ **`*p.score` 是错的。** `.` 的优先级高于 `*`，编译器理解成 `*(p.score)`。而 `p` 是结构体指针，没有 `score` 成员。gcc 的报错很直白：
>
> ```text
> error: 'p' is a pointer; did you mean to use '->'?
> ```
>
> 看到这条报错，直接把 `.` 换成 `->` 就行。

> 💡 一个记忆法：**看到 `->` 就知道左边是地址**。所以函数参数是 `struct X *p` 时，里面一律用 `p->字段`。

## 五、结构体作函数参数

```c
/* 传值：函数内改的是副本 */
void addByValue(struct Student s, double add) {
    s.score += add;
}

/* 传指针：能改到外面 */
void addByPointer(struct Student *p, double add) {
    p->score += add;
}
```

真实输出（调用前后对比）：

```text
调用前：score = 92.5
函数内（传值）：score = 97.5
传值返回后：score = 92.5  ← 没变
函数内（传指针）：score = 97.5
传指针返回后：score = 97.5  ← 变了
```

这就是 W7 那个 `swap` 问题的**同一个道理**：要让函数改到外面的东西，必须传地址。

### 为什么工程上倾向传指针

| 方式 | 每次调用拷贝 | 能否修改外部 |
|---|---|---|
| 传值 `struct Student s` | 32 字节（整个结构体） | ❌ |
| 传指针 `struct Student *p` | 8 字节（一个地址） | ✅ |

结构体越大差别越大。如果结构体嵌套了 10 门课成绩，可能几百字节，排序时交换函数调用上万次，拷贝开销就很可观。

> ✅ **工程惯例：结构体作参数一律 `const struct X *`，只有需要修改时才去掉 `const`。**

```c
void printStudent(const struct Student *p) {
    printf("%d %s\n", p->id, p->name);
    /* p->score = 0;   ← ❌ 加了 const，编译期就报错，防止手滑 */
}
```

### 结构体可以返回，数组不行

```c
struct Student makeStudent(int id, const char *name, double score) {
    struct Student s;
    s.id = id;
    strcpy(s.name, name);
    s.score = score;
    return s;                  /* ✅ 安全：值拷贝 */
}
```

> ❌ 数组不能这样返回。返回局部数组，得到的是已失效的地址，gcc 会警告：
>
> ```text
> warning: function returns address of local variable [-Wreturn-local-addr]
> ```
>
> 结构体整体返回是「把内容拷一份给调用者」，不是返回地址，所以安全。

## 六、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 定义语法 | 结构体定义末尾要不要分号 | 要，漏了必错 |
| 成员访问 | `p.x` 还是 `p->x` | 指针用 `->`，变量用 `.` |
| `sizeof` | 给结构体算大小 | 按对齐规则算，不能相加 |
| 结构体 vs 数组 | 能不能整体赋值 | 结构体能，数组不能 |
| 结构体作参数 | 传值能否修改实参 | 不能，必须传指针 |
| `typedef` | `typedef struct` 的作用 | 起别名，不产生新类型 |

> 📌 程序填空题常给一个结构体定义，让你补全「读入数据」和「输出数据」。
> 关键是**输入字符串成员时不要加 `&`**：`scanf("%s", a[i].name)` 正确，`scanf("%s", &a[i].name)` 虽然也能跑，但语义上是错的（传的是数组地址的地址）。
