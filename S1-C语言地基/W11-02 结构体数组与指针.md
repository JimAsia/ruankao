# W11-02 结构体数组与指针

> 单个结构体没什么威力，**结构体数组**才是真正的数据结构 —— 成绩表、通讯录、库存列表，本质都是结构体数组。
> 好消息是：W5 学的所有套路（遍历、求最值、排序、查找）**一行都不用改**，只是比较的对象从 `a[i]` 变成 `a[i].score`。

---

## 一、定义与初始化

```c
#define N 6

struct Student {
    int    id;
    char   name[20];
    double score;
};

struct Student stu[N] = {
    {2026001, "张三", 92.5},
    {2026002, "李四", 78.0},
    {2026003, "王五", 96.5},
    {2026004, "赵六", 65.0},
    {2026005, "钱七", 88.0},
    {2026006, "孙八", 78.0}
};
```

真实输出：

```text
学号      姓名       成绩
2026001   张三       92.5
2026002   李四       78.0
2026003   王五       96.5
2026004   赵六       65.0
2026005   钱七       88.0
2026006   孙八       78.0

整个数组占 192 字节 = 6 × 32
```

> 📝 单个元素 32 字节 = 4 + 20 + 8，**正好没有填充**。因为 4+20=24 已经是 `double`（8 字节）的对齐倍数，接上去不用补。
> 把 `name` 改成 `char[10]`，4+10=14 就要补 2 字节，元素变 24 字节 —— 对齐规则在这里体现得很清楚。

## 二、四个套路，一个都不变

W5 讲的四大范式直接搬过来，只改比较目标。

### ① 求最值：存下标，不存值

```c
int maxIdx = 0;
for (int i = 1; i < N; i++) {
    if (stu[i].score > stu[maxIdx].score) maxIdx = i;
}
printf("最高分：%s %.1f\n", stu[maxIdx].name, stu[maxIdx].score);
```

真实输出：`最高分：王五 96.5`

> ⭐ **为什么一定要存下标？** 因为存值只能拿到分数，存下标能拿到这个人的**全部信息**（姓名、学号都还在）。
> 后面要按学号查人、要打印完整名单，只存值就做不到了。

### ② 累加求平均：注意类型

```c
double sum = 0;                          /* ✅ double，不是 int */
for (int i = 0; i < N; i++) sum += stu[i].score;
```

如果把 `sum` 写成 `int`，实测结果：

```text
总分 = 498.0，平均 = 83.00
如果 sum 写成 int：497 分，少了 1.0 分
```

> ❌ 每加一次就截断一次小数，6 个 `.5` 全部被丢掉。
> **这种错不报错、不警告，只是结果不对** —— 比编译错误危险得多。

### ③ 排序：整体交换

```c
for (int i = 0; i < N - 1; i++) {
    for (int j = 0; j < N - 1 - i; j++) {
        if (stu[j].score < stu[j + 1].score) {   /* 降序 */
            struct Student t = stu[j];           /* ✅ 整体交换 */
            stu[j]     = stu[j + 1];
            stu[j + 1] = t;
        }
    }
}
```

排序后：

```text
2026003   王五       96.5
2026001   张三       92.5
2026005   钱七       88.0
2026002   李四       78.0
2026006   孙八       78.0
2026004   赵六       65.0
```

> ✅ **用 `struct Student t` 整体交换，三行搞定。**
> ❌ 不要逐个字段交换（`t_id = a.id; strcpy(t_name, a.name); t_score = a.score;`），字段一多必漏。

### ④ 查找：字符串必须 `strcmp`

```c
const char *target = "赵六";
int found = -1;
for (int i = 0; i < N; i++) {
    if (strcmp(stu[i].name, target) == 0) {   /* ⚠️ 不能写 == */
        found = i;
        break;
    }
}
```

真实输出：`找到 赵六：学号 2026004，成绩 65.0`

> ❌ `stu[i].name == target` 比较的是地址，永远不相等（数组名 vs 指针）。这条在 W6 强调过，结构体数组里同样是最常见的错。

## 三、计数数组替代多变量

统计各分数段人数，新手常写成 5 个独立变量：

```c
int c90 = 0, c80 = 0, c70 = 0, c60 = 0, c0 = 0;
/* 然后写 5 段 if... 加一档就要改 5 处 */
```

标准做法是**计数数组 + 下标映射**：

```c
int cnt[5] = {0};                        /* 90+, 80-89, 70-79, 60-69, <60 */
for (int i = 0; i < N; i++) {
    int s = (int)stu[i].score;
    if      (s >= 90) cnt[0]++;
    else if (s >= 80) cnt[1]++;
    else if (s >= 70) cnt[2]++;
    else if (s >= 60) cnt[3]++;
    else              cnt[4]++;
}

const char *label[5] = {"90 以上", "80-89", "70-79", "60-69", "60 以下"};
for (int i = 0; i < 5; i++) {
    printf("%-8s %d 人  ", label[i], cnt[i]);
    for (int k = 0; k < cnt[i]; k++) printf("★");
    printf("\n");
}
```

真实输出：

```text
90 以上 2 人  ★★
80-89   1 人  ★
70-79   2 人  ★★
60-69   1 人  ★
60 以下 0 人
```

> ⭐ **标签用 `const char *label[5]`（指针数组）而不是 `char label[5][10]`。**
> 前者每个元素 8 字节，后者固定占 50 字节。这也是 W10 讲的「指针数组」的典型用途。

## 四、结构体指针遍历

两种写法完全等价：

```c
/* 写法一：下标 */
for (int i = 0; i < 3; i++)
    printf("%s %.1f\n", arr[i].name, arr[i].score);

/* 写法二：指针 */
for (struct Student *q = arr; q < arr + 3; q++)
    printf("%s %.1f\n", q->name, q->score);
```

真实输出（两种写法结果一致）：

```text
王五 96.5
赵六 65.0
钱七 88.0
```

> ⭐ `q++` 走的是 `sizeof(struct Student)` = 32 字节，**不是 1 字节**。
> 指针类型决定步长 —— 和 W9 讲的完全一致，只是这里「一个元素」正好是整个结构体。

### 结构体数组名的退化

和普通数组一样，结构体数组作参数也会**退化成指针**：

```c
void printAll(const struct Student a[], int n)   /* 等价于 const struct Student *a */
{
    printf("%zu\n", sizeof(a));                  /* 8，不是整个数组的大小！ */
}
```

> ❌ 所以**长度必须单独传**。函数里 `sizeof(a)` 只有 8 字节（一个指针）。

## 五、软考怎么考

| 考点 | 典型问法 | 要点 |
|---|---|---|
| 结构体数组定义 | 初始化列表嵌套大括号 | 每个元素一对 `{}` |
| 求最值 | 为什么保存下标 | 下标能拿到完整记录 |
| 排序 | 交换时怎么换 | 整体赋值，别逐字段 |
| 字符串比较 | 用什么比较姓名 | `strcmp`，不是 `==` |
| 数组参数 | 函数里 `sizeof` 是多少 | 8 字节，长度必须传 |
| 计数数组 | 统计各区间人数 | 数组下标映射，别写 5 个变量 |

> 📌 应用技术大题里，「学生成绩管理」几乎必考结构体数组。
> 模板就是本文四个套路 + 菜单循环（W14 会给完整项目）。
