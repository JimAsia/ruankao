## 三、自测五题（不看答案，先自己算）

**1. 结构体定义末尾的分号能省吗？**

```c
struct A { int x; }
```

**2. `sizeof(struct P)` 是多少？**

```c
struct P { char c; int i; short s; };
```

**3. 下面的 `s2 = s1` 合法吗？如果是数组 `a2 = a1` 呢？**

```c
struct S { int x; };
struct S s1 = {1}, s2;
s2 = s1;
```

**4. 共用体 `union R { char a[10]; int b; double c; };` 的 `sizeof` 是多少？**

**5. 枚举 `enum E { A = 3, B, C = 1, D };` 中 `B` 和 `D` 各是多少？**

---

## 四、答案与解析

**1. 不能省。** 漏了必报错。这个分号是「类型定义语句」的结束符，不是可有可无的装饰。

**2. `12` 字节。** 推一遍：

| 成员 | 大小 | 偏移 | 说明 |
|---|---|---|---|
| `c` | 1 | 0 | ✓ |
| `i` | 4 | **4** | 偏移 1 不是 4 的倍数，补 3 字节 |
| `s` | 2 | 8 | 偏移 8 是 2 的倍数 ✓ |
| — | — | 10 | 最大成员是 4，10 不是 4 的倍数，补 2 → **12** |

注意：**不是 1+4+2=7**。

**3. 结构体能，数组不能。** `s2 = s1` 合法（逐字节拷贝）；`a2 = a1` 编译错误，因为数组名是常量地址，不能作赋值目标。

**4. `16` 字节。** 最大成员是 `a[10]`（10 字节），但最大对齐要求来自 `double`（8 字节）：
10 补到 16 才是 8 的倍数，所以是 **16**。不是 10，也不是 8。

**5. `B = 4`，`D = 2`。** `A = 3` 之后 `B` 自动 +1 得 4；`C = 1` 手动赋值，`D` 接着得 2。

> ⭐ 第 5 题考的就是「手动赋值会打断自动递增」。这种现象在软考里出现过，别想当然认为 `D` 一定是 5。
