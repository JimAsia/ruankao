## 一、三段式结构

```c
for (初始化; 条件; 更新) {
    循环体
}
```

**执行顺序**（这个顺序必须背下来）：

```text
① 初始化（只执行一次）
② 判断条件 → 假就结束
③ 执行循环体
④ 执行更新
⑤ 回到 ②
```

注意：**更新是在循环体之后执行的**。这是读程序题最容易搞错的地方。

---

## 二、六种常见形态

| 形态 | 写法 | 执行次数 |
|---|---|---|
| 从 0 到 n-1 | `for (i = 0; i < n; i++)` | n 次 |
| 从 1 到 n | `for (i = 1; i <= n; i++)` | n 次 |
| 倒序 | `for (i = n; i >= 1; i--)` | n 次 |
| 步长为 2 | `for (i = 0; i <= 10; i += 2)` | 6 次 |
| 翻倍增长 | `for (i = 1; i <= 100; i *= 2)` | 7 次 |
| 字符循环 | `for (c = 'a'; c <= 'e'; c++)` | 5 次 |

**`31_for.c` 的真实输出：**

```text
=== ① 标准 for ===
i = 0  i = 1  i = 2  i = 3  i = 4

=== ③ 倒序 ===
i = 5  i = 4  i = 3  i = 2  i = 1

=== ⑤ 每次乘 2 ===
1 2 4 8 16 32 64
  循环体只执行了 7 次（i = 1,2,4,8,16,32,64），第 8 次判断 i=128 时退出
  这就是 O(log n)：n 翻倍增长时，轮数只按对数增加
```

> ⚠️ 第 ⑤ 种最容易数错：`i <= 100` 时，i 依次是 1、2、4、8、16、32、64，**共 7 次**，不是 8 次。

## 三、省略三段

```c
int i = 0;
for (; i < 3; ) {       /* 省略初始化和更新 */
    printf("%d ", i);
    i++;                /* 更新挪进循环体 */
}
```

| 写法 | 含义 |
|---|---|
| `for (;;)` | 死循环，等价于 `while (1)` |
| `for (; i < n; )` | while 的另一种写法 |
| `for (i = 0; ; i++)` | 没有终止条件，靠 `break` 跳出 |

⚠️ 分号不能省。`for (int i = 0; i < n; i++)` 里是**两个分号**，不是逗号。

## 四、循环变量的作用域

```c
for (int i = 0; i < 3; i++) { }
printf("%d", i);        /* ❌ 编译错误：i 已经不存在了 */
```

C99 起，循环里声明的变量只在循环内有效。要在循环外使用，必须在外层声明：

```c
int i;
for (i = 0; i < 3; i++) { }
printf("%d", i);        /* ✅ i = 3 */
```

> 📌 软考偶尔考「循环结束后 i 的值是多少」。如果 i 是循环内声明的，答「不存在」；循环外声明的，答「最后一次更新后的值」。

## 五、嵌套循环

### 5.1 执行次数

```c
for (int i = 1; i <= 3; i++)        /* 外层 3 次 */
    for (int j = 1; j <= 4; j++)    /* 每轮内层 4 次 */
        x++;                        /* 共 12 次 */
```

**`32_for_trace.c` 的真实输出：**

```text
  外层 i = 1：1 2 3 4
  外层 i = 2：1 2 3 4
  外层 i = 3：1 2 3 4
  外层 3 次 × 内层 4 次 = 共执行 12 次循环体
```

**要点**：外层每动一次，内层都要完整跑一圈。

### 5.2 内层依赖外层

```c
for (int i = 1; i <= 4; i++) {
    for (int j = 1; j <= i; j++)    /* 内层上限是 i */
        printf("*");
    printf("\n");
}
```

输出：

```text
*
**
***
****
```

执行次数 = `1 + 2 + 3 + 4 = 10 = n(n+1)/2`，复杂度 **O(n²)**。

### 5.3 逐轮追踪：读程序题的核心技能

`32_for_trace.c` 把每一轮的值都打印出来了：

```text
  轮次 | i  | sum（累加前）-> sum（累加后）
  -----|----|------------------------------
   1   | 1  | 0 -> 1
   2   | 2  | 1 -> 3
   3   | 3  | 3 -> 6
   4   | 4  | 6 -> 10
   5   | 5  | 10 -> 15
  最终 sum = 15
```

> 💡 **读程序题的唯一正确做法**：在纸上画这样一张表，逐行填。心算跳步必错。

## 六、软考怎么考这部分

| 考点 | 位置 | 典型问法 |
|---|---|---|
| 循环执行次数 | 基础知识 | 「下面循环执行几次」 |
| 嵌套循环的总次数 | 基础知识 | `i=1..n` 套 `j=1..i` 共几次 |
| 循环结束后的变量值 | 应用技术 | 读程序写结果 |
| 步长非 1 的循环 | 应用技术 | `i *= 2` 跑几轮 |
| 循环转流程图 | 应用技术 | 画出等价流程图 |
| 复杂度 | 基础知识 | 双重循环的复杂度 |

**执行次数口诀**：看循环变量的**取值个数**，不是看终值。

- `i = 0; i < n` → 0,1,...,n-1 → n 个
- `i = 1; i <= n` → 1,...,n → n 个
- `i = 1; i < n` → 1,...,n-1 → n-1 个
