## 一、printf：把值按指定格式吐出来

函数原型：

```c
int printf(const char *format, ...);
```

- `format` 里是普通文本 + **转换说明**（以 `%` 开头）
- 后面的参数按顺序填进每个 `%` 的位置
- 返回值是**实际输出了多少个字符**（很少用，但软考选择题问过）

```c
printf("Hello, Programmer!\n");
printf("%d + %d = %d\n", 3, 4, 3 + 4);
```

> ⚠️ **转换符的数量必须和后面参数的数量、类型一一对应。** 不匹配不会报错，但输出全是垃圾，或者程序直接崩。

## 二、常用转换符总表

下面每一行的输出都是 `05_printf.c` 的**真实运行结果**：

| 转换符            | 含义                                | 示例                           | 实际输出           |
| -------------- | --------------------------------- | ---------------------------- | -------------- |
| `%d`           | 十进制整数                             | `printf("%d", 42)`           | `42`           |
| `%o`           | 八进制（无前缀）                          | `printf("%o", 42)`           | `52`           |
| `%x`           | 十六进制小写                            | `printf("%x", 42)`           | `2a`           |
| `%X`           | 十六进制大写                            | `printf("%X", 42)`           | `2A`           |
| `%u`           | 无符号十进制                            | `printf("%u", 42)`           | `42`           |
| `%c`           | 单个字符                              | `printf("%c", 'A')`          | `A`            |
| `%s`           | 字符串                               | `printf("%s", "Programmer")` | `Programmer`   |
| `%f`           | 浮点（默认 6 位小数）                      | `printf("%f", 3.14159265)`   | `3.141593`     |
| `%e`           | 科学计数法                             | `printf("%e", 3.14159265)`   | `3.141593e+00` |
| `%g`           | 自动选 `%f` 或 `%e`                   | `printf("%g", 3.14159265)`   | `3.14159`      |
| `%p`           | 指针地址                              | `printf("%p", &n)`           | `0x7ffd...`    |
| `%%`           | 输出一个百分号                           | `printf("100%%")`            | `100%`         |
| `%zu`          | `sizeof` 的结果                      | `printf("%zu", sizeof(int))` | `4`            |
| `%ld` / `%lld` | long / long long                  | `printf("%lld", x)`          | —              |
| `%lf`          | **只在 scanf 里需要**，printf 里 `%f` 就够 | —                            | —              |

> 📝 软考爱考的对照：**`'A'` 用 `%c` 打出 `A`，用 `%d` 打出 `65`。** 同一个变量换转换符，结果完全不同。

## 三、宽度、精度、对齐

格式：`%[标志][宽度][.精度]转换符`

| 写法 | 效果 | 实际输出（n = 42） |
|---|---|---|
| `[%8d]` | 宽度 8，**右对齐**，左补空格 | `[      42]` |
| `[%-8d]` | 宽度 8，**左对齐**，右补空格 | `[42      ]` |
| `[%08d]` | 宽度 8，**补零** | `[00000042]` |
| `[%8.2f]` | 宽度 8，保留 2 位小数 | `[    3.14]` |
| `%.2f` | 只保留 2 位小数，不管宽度 | `3.14` |

> 💡 应用题要求「保留两位小数」，就是 `%.2f`。要求「输出占 5 列、左对齐」，就是 `%-5d`。这两句会直接写进题干，看到就照抄。

## 四、转义字符

| 转义   | 含义              | ASCII |
| ---- | --------------- | ----- |
| `\n` | 换行              | 10    |
| `\t` | 制表符（跳到下一个制表位）   | 9     |
| `\r` | 回车              | 13    |
| `\\` | 反斜杠本身           | 92    |
| `\"` | 双引号             | 34    |
| `\'` | 单引号             | 39    |
| `\0` | 空字符，**字符串结束标志** | 0     |
| `\a` | 响铃              | 7     |


真实输出：

```text
百分号本身要写两个: 100%
反斜杠本身要写两个: C:\msys64\ucrt64\bin
```

> ❌ 别写 `printf("C:\msys64")` —— `\m` 不是合法转义，行为不确定。路径里的反斜杠必须写成 `\\`。
> 📝 `'\n'` 是**一个字符**（1 字节），`"\n"` 是**一个字符串**（2 字节：`\n` + `\0`）。这个区分软考考过。

## 五、scanf：把键盘输入读进变量

```c
int age;
scanf("%d", &age);
```

`&` 是**取地址符**。为什么必须写？

```text
scanf 的任务：把用户输入的值放到 age 那块内存里
所以它需要知道：age 在哪 —— 需要的是【地址】
如果只给 age：它拿到的是 age 当前的值（比如 18）
              于是它会把输入写到「地址 18」那个地方 —— 内存被写坏
```

> ❌ 忘写 `&` 是新手第一大崩溃原因。有时候程序直接挂，有时候悄悄改坏别的变量，排查起来极其痛苦。
> ✅ 例外：读字符串数组时**不用** `&`，因为数组名本身就是地址。
> ```c
> char name[20];
> scanf("%s", name);      /* 正确，没有 & */
> ```

## 六、scanf 的三个坑

### 坑 1：换行符残留

```c
int age;
char grade;
scanf("%d", &age);      /* 你输入 20 然后回车 */
scanf("%c", &grade);    /* 你会以为在等你输入字母 —— 其实它立刻读到了那个回车 */
```

**原因**：`scanf("%d")` 只吃掉数字，把回车 `\n` 留在输入缓冲区里。下一个 `%c` 一看有东西，直接拿走了。

**解法**：`%c` 前面加一个空格，表示「先跳过所有空白字符」。

```c
scanf(" %c", &grade);   /* ✅ 那个空格是关键 */
```

> 📝 这个坑软考选择题考过不止一次。看到 `scanf("%c")` 紧跟在 `scanf("%d")` 后面，先怀疑换行残留。

### 坑 2：`%s` 不检查长度

```c
char buf[5];
scanf("%s", buf);       /* 输入 "abcdefghij" → 越界写入，栈被踩坏 */
```

**解法**：限制宽度，`scanf("%4s", buf)`，留一个位置给 `\0`。

### 坑 3：`%lf` vs `%f`

| 场景 | float | double |
|---|---|---|
| `printf` | `%f` | `%f`（printf 里 double 也用 `%f`） |
| `scanf` | `%f` | **必须 `%lf`** |

```c
double d;
scanf("%f", &d);        /* ❌ 读到的值是垃圾 */
scanf("%lf", &d);       /* ✅ */
```

## 七、scanf 的返回值

`scanf` 返回**成功读入的项数**。这个特性可以用来做输入校验：

```c
int age;
if (scanf("%d", &age) != 1) {
    printf("输入格式不对\n");
    return 1;
}
```

| 返回值 | 含义 |
|---|---|
| 1 | 成功读了 1 项 |
| 0 | 一项都没读到（比如该输数字你输了字母） |
| `EOF`（-1） | 输入结束或出错 |

> ✅ 从第一天就养成检查返回值的习惯。软考机考的应用技术题，输入格式通常很规整，但真实开发和刷题平台都必须校验。
