## 一、五个必须会的函数

全部来自 `<string.h>`。

| 函数 | 作用 | 注意 |
|---|---|---|
| `strlen(s)` | 长度（不含 `'\0'`） | `sizeof` 是含 `'\0'` 的 |
| `strcpy(d, s)` | 复制 | ⚠️ 不检查 d 的空间 |
| `strcat(d, s)` | 拼接 | ⚠️ 同样有溢出风险 |
| `strcmp(a, b)` | 比较 | 返回值是 `<0 / 0 / >0`，**不是布尔** |
| `strchr / strstr` | 找字符 / 找子串 | 返回指针，找不到返回 `NULL` |

实测：

```text
  s = "Programming"
  strlen(s) = 11
  sizeof(s) = 12（含 '\0'）
```

## 二、⭐ `strcmp` 的返回值（高频）

```c
strcmp("abc", "abc")  =  0     相等
strcmp("abc", "abd")  = -1     小于
strcmp("abd", "abc")  =  1     大于
strcmp("abc", "ab")   =  1     长的大
strcmp("Z", "a")      = -1     'Z'=90 < 'a'=97
```

**比较规则**：逐个字符按 ASCII 码比，**遇到第一个不同的字符就定胜负**。

> ⚠️ 注意最后一行：`"Z" < "a"`。因为大写字母的 ASCII 码（65~90）**小于**小写字母（97~122）。所以按字典序排的话，所有大写字母都排在小写字母前面。

### 2.1 ⚠️ 最常见的错误写法

```c
if (strcmp(a, b))       /* ❌ 这个意思是"不相等"！ */
    printf("相等");      /* 逻辑完全反了 */

if (strcmp(a, b) == 0)  /* ✅ 这才是"相等" */
    printf("相等");
```

因为 `strcmp` 返回 0 表示相等，而 `if (0)` 是假。这个坑几乎每个人都踩过。

### 2.2 正确的三种用法

```c
if (strcmp(a, b) == 0) { /* 相等 */ }
if (strcmp(a, b) != 0) { /* 不相等 */ }
if (strcmp(a, b) < 0)  { /* a 在 b 前面（字典序） */ }
```

## 三、⚠️ 不能用 `==` 比较字符串

```c
char x[] = "abc";
char y[] = "abc";
printf("%d", x == y);       /* 结果是 0（假）！ */
```

实测：

```text
  x 和 y 内容相同，但 x == y 的结果是 0（假）
  因为 == 比的是地址，x 和 y 是两个不同的数组，地址当然不同
```

**`==` 比较的是两个数组的地址**，不是内容。C 语言不会帮你逐字符比。

> 📌 这是软考选择题最爱考的一条。记住：**字符串比内容必须用 `strcmp`，不能用 `==`。**

## 四、⚠️ 这些函数都不检查目标空间

```c
char dst[5];
strcpy(dst, "Hello, World!");       /* 灾难：目标只有 5 字节，源有 14 字节 */
```

`strcpy` 会一直复制到源的 `'\0'` 为止，**根本不看 `dst` 装不装得下**。结果就是越界写入，可能改坏其他变量，也可能直接崩溃。

**更安全的版本**：

```c
strncpy(dst, src, sizeof(dst) - 1);
dst[sizeof(dst) - 1] = '\0';        /* ⚠️ 必须手动补 */
```

实测：

```text
  strncpy 版本 dst2 = "Programming"
  注意：strncpy 在源串太长时不保证补 '\0'，要手动补
```

| 函数 | 安全版本 | 区别 |
|---|---|---|
| `strcpy` | `strncpy` | 限长，但可能不补 `'\0'` |
| `strcat` | `strncat` | 限长 |
| `sprintf` | `snprintf` | 限长 |

## 五、`strchr` 与 `strstr`

```c
const char *p = strchr("hello", 'l');       /* 找字符 */
const char *q = strstr("hello world", "world");  /* 找子串 */
```

实测：

```text
  strchr("hello",'l') 之后，剩余部分是 "llo"
  strstr("hello world","world") 之后是 "world"
```

**返回的是指针**，指向第一次出现的位置。找不到返回 `NULL`。

> 💡 `strchr` 返回 "llo" 而不是 "l"，是因为它返回的是**从那一位开始的整个剩余字符串**的指针。想知道下标可以 `p - 原串首地址`（W9 讲指针时会算）。

## 六、手写这些函数（理解原理）

考试有时要求「不用库函数实现」，这里给出核心逻辑（完整代码见 `55_string_manual.c`）。

### 6.1 手写 strlen

```c
int len = 0;
while (s[len] != '\0') len++;
```

### 6.2 手写 strcpy

```c
int i = 0;
while (src[i] != '\0') { dst[i] = src[i]; i++; }
dst[i] = '\0';              /* ⚠️ 千万别忘了补结束符 */
```

**忘了补 `'\0'`** 是最典型的错误：复制的字符都对，但 `dst` 不是合法字符串，后面用 `%s` 打印会读到乱码。

### 6.3 手写字符串反转

```c
int right = 0;
while (s[right] != '\0') right++;       /* 找到末尾 */
right--;                                 /* ⚠️ 退到最后一个真实字符 */

int left = 0;
while (left < right) {
    char t = s[left]; s[left] = s[right]; s[right] = t;
    left++; right--;
}
```

实测：

```text
  长度 = 5，反转前 right 指向下标 4 的 'o'
  反转后："olleH"
```

### 6.4 手写 strcmp

```c
int k = 0;
while (a[k] != '\0' && b[k] != '\0' && a[k] == b[k]) k++;
int diff = (unsigned char)a[k] - (unsigned char)b[k];
```

实测：

```text
  "abc" vs "abd" → 差值 -1（负数，前者小）
  "abc" vs "abc" → 差值 0（相等）
  "abc" vs "ab"  → 差值 99（正数，前者长所以大）
```

第三个有意思："abc" 比到第 3 位时，`a[2]='c'`(99)，`b[2]='\0'`(0)，差值 99 —— 所以长的大。
