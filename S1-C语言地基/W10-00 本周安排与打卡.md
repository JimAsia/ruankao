## 三、自测：全对才算拿下指针

**1. 下面函数调用后 `x` 是多少？**

```c
void f(int *p) { *p = 100; }
int x = 1;
f(&x);
```

**2. `int a[]` 和 `int *a` 作为函数参数，有什么区别？**

**3. 下面哪个声明的 `b` 是指针？**

```c
A. int *b[10];
B. int (*b)[10];
```

**4. `const int *p` 和 `int * const p` 哪个能改指针的指向？**

**5. 二级指针 `int **pp` 什么时候必须用？举一个例子。**

**6. `char arr[] = "abc"` 和 `char *p = "abc"`，哪个能改内容？**

---

## 四、标准答案

1. **`x = 100`。** 传的是 `&x`（地址），函数内 `*p = 100` 顺着地址改的就是 `x` 本身。

2. **没有任何区别。** 编译器把两者都当成 `int *`（指针）。参数里的 `int a[10]` 那个 10 也被忽略。这就是为什么数组参数必须额外传长度。

3. **B。** `int (*b)[10]` 括号优先，`b` 是指针（数组指针）；`int *b[10]` 里 `b` 先和 `[10]` 结合，是数组（指针数组）。

4. **`const int *p` 能改指向**（const 锁的是值）；`int * const p` 不能改指向（const 锁的是指针本身）。
   口诀：const 在星号左边锁值，右边锁指针。

5. **当需要修改「一个指针本身的指向」时必须用。** 例如：
   ```c
   void retarget(int **pp, int *t) { *pp = t; }
   ```
   链表删除头节点 `void removeHead(Node **head)` 也是同一类。
   原因：如果只传 `int*`，函数拿到的是副本，改不了调用者的指针。

6. **`char arr[]` 能改**（数组在栈上，是自己的内存）；`char *p` 不能改（指向只读区的字面量，`p[0]='x'` 会崩溃）。

> 全对 → 指针这一关算过了。
