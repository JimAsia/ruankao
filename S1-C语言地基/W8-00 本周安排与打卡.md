## 三、自测：全对才进 W9

**1. 递归三要素是什么？缺了出口会怎样？**

**2. 下面函数输出什么？**

```c
void f(int n) {
    if (n == 0) return;
    printf("%d ", n);
    f(n - 1);
}
f(3);
```

**3. 把上一题的 `printf` 移到 `f(n-1)` 之后，输出变成什么？**

**4. n 个盘子的汉诺塔需要多少步？**

**5. `fib(30)` 用朴素递归要调用多少次？时间复杂度是多少？**

**6. `gcd(12, 18)` 的递归展开过程是什么？**

---

## 四、标准答案

1. **出口、递推关系、规模缩小。** 缺出口会无限递归，每层占一个栈帧，最终**栈溢出**（Stack Overflow），程序崩溃。

2. **输出 `3 2 1 `。** `printf` 在递归调用**之前**，属于「先输出后递归」，是从外往里打印。

3. **输出 `1 2 3 `。** `printf` 在递归调用**之后**，是从里往外打印（后序）。这就是 W8-02 讲的「输出顺序由 printf 的位置决定」。

4. **`2ⁿ - 1` 步。** 推导：`f(n) = 2 × f(n-1) + 1`，`f(1) = 1`。

5. **约 166 万次**（实测 1664079 次）。时间复杂度 **O(2ⁿ)**，不是 O(n) —— 因为存在大量重复计算。改成迭代是 O(n)。

6. ```text
   gcd(12, 18) → gcd(18, 12)   【12 % 18 = 12】
   gcd(18, 12) → gcd(12, 6)    【18 % 12 = 6】
   gcd(12, 6)  → gcd(6, 0)     【12 % 6 = 0】
   gcd(6, 0)   → 出口，返回 6
   ```
