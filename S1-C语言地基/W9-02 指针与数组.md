# W9-02 指针与数组

> 📝 S1 地基期 · 第 9 周 · 第 2 节
> 上一篇：[[W9-01 地址与指针变量]] ｜ 下一篇：[[W9-03 指针常见错误]]
> 示例代码：`code/w9/83_pointer_array.c`、`code/w9/84_pointer_arith.c`

> 🎯 一句话：**数组名就是首元素的地址**，由此推出 `a[i] == *(a + i)`。

---

## 一、数组名 = 首地址

实测：

```text
  a       = 000000495AFFF680
  &a[0]   = 000000495AFFF680
  两者完全相同
```

---

## 二、⭐ 三种写法完全等价

```c
a[i]        /* 下标法 */
*(a + i)    /* 指针运算 */
p[i]        /* 指针 + 下标（p = a） */
```

实测三种同时输出：

```text
  a[0]=10   p[0]=10    *(a+0)=10
  a[1]=20   p[1]=20    *(a+1)=20
  ...
```

> 📌 这不是"巧合"，是 C 语言的定义：**下标写法只是指针运算的语法糖**，编译器生成完全一样的代码。

---

## 三、指针运算：+1 走多远

实测：

```text
  sizeof(int) = 4
  &a[0] = 000000495AFFF680
  &a[1] = 000000495AFFF684
  差 4 字节 —— 正好是一个 int 的大小
```

**⭐ 指针 + 1 走的是「一个元素」的距离，不是 1 字节。**

这正是「指针类型」存在的意义：类型决定步长。

| 指针类型 | `p + 1` 前进 |
|---|---|
| `char *` | 1 字节 |
| `int *` | 4 字节 |
| `double *` | 8 字节 |

---

## 四、指针能做的四种运算

| 运算 | 例子 | 结果 |
|---|---|---|
| 加减整数 | `p + 3` / `p - 1` | 移动 n 个元素 |
| **指针相减** | `last - first` | **相隔几个元素**（不是字节） |
| 自增自减 | `p++` / `--p` | 移动一个元素 |
| 比较 | `p < q` | 谁在前 |

实测：

```text
  last - first = 5   （相隔几个元素，不是字节数）
  如果按字节算：20 字节
```

**不能做的**：`p + q`（两个指针相加）、`p * 2`、`p / 2` —— 都没有意义。

---

## 五、⭐ `*p++` 与 `(*p)++`

这是最容易搞混的一对。

| 写法 | 效果 |
|---|---|
| `*p++` | 等价于 `*(p++)`：**先取值，然后指针后移** |
| `(*p)++` | 把**指向的值**加 1，指针不动 |

实测：

```text
  (*r)++ 之后：b[0] = 2，r 指向 b[0]     ← 值变了，指针没动
  *r++   之后：b[0] = 2，r 指向 b[1]     ← 值没变，指针走了
```

**为什么**：`++` 的优先级高于 `*`，所以 `*p++` 是 `*(p++)`。

> 📌 记法：**`*p++` 走指针，`(*p)++` 改值。**

## 六、数组名 vs 指针变量

| | 数组名 `a` | 指针变量 `p` |
|---|---|---|
| 是什么 | 常量地址 | 变量 |
| 能赋值吗 | ❌ `a = p` 编译错误 | ✅ `p = a + 2` |
| 能自增吗 | ❌ `a++` 编译错误 | ✅ `p++` |

实测：

```text
  执行 p = a + 2 之后：*p = 30（就是 a[2]）
  再 p++ 之后：*p = 40（就是 a[3]）
```

## 七、用指针遍历数组

```c
for (int *p = a; p < a + n; p++) {
    sum += *p;
}
```

**⚠️ 条件是 `p < a + n`，不能写 `p <= a + n`。**

| 位置 | 含义 | 能解引用吗 |
|---|---|---|
| `a + n - 1` | 最后一个元素 | ✅ |
| `a + n` | 最后一个元素的**后面** | ❌ 越界 |

> 💡 C 标准允许指针指向「末尾的下一个位置」，但不允许解引用它。
> 所以 `p < a + n` 安全，`p <= a + n` 不安全。

---

## 八、为什么函数里 `sizeof` 拿不到数组大小

```text
  数组作参数时会【退化】成指针
  int arr[] 在参数位置上等价于 int *arr
  所以函数内 sizeof(arr) 是 8（指针大小），不是数组大小
```

这就是 W7 说的「数组参数必须传长度」的根本原因 —— 现在你知道为什么了。
