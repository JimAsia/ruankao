## 一、指针是什么

**指针 = 存地址的变量。**

```text
普通变量：存值          指针变量：存地址
┌────────┐             ┌────────┐        ┌────────┐
│   42   │             │ 0x7ffd │  ───→  │   42   │
└────────┘             └────────┘        └────────┘
   a = 42                 p = &a            *p 能取到 42
```

---

## 二、三件套：`&`、`*`、类型

```c
int a = 42;
int *p = &a;        /* p 存着 a 的地址 */
```

| 写法 | 含义 | 读法 |
|---|---|---|
| `&a` | 取 a 的地址 | "a 在哪" |
| `int *p` | 声明一个指向 int 的指针 | "p 是个指针" |
| `*p` | 解引用，取 p 指向的值 | "顺着 p 走一趟" |
| `&p` | p 自己的地址 | "p 这个变量在哪" |

实测：

```text
  a 的值   = 42
  a 的地址 = 00000017C19FFD64
    p     = 00000017C19FFD64   （和 &a 相同）
    *p    = 42
    &p    = 00000017C19FFD58   （p 自己也有地址）
```

---

## 三、通过指针改值

```c
*p = 100;
```

实测：

```text
  改之前：a = 42
  执行 *p = 100 之后：a = 100
  ⚠️ 我们没写 a = 100，但 a 确实变了 —— 因为 p 指向它
```

> 💡 这是指针最核心的能力：**拿到地址，就能改别人的内存**。
> W7 那个「swap 交换不了」的问题，就是靠这个解决的（W10 会讲）。

## 四、⭐ 指针类型决定「读几个字节」

```text
  sizeof(int *)    = 8
  sizeof(char *)   = 8
  sizeof(double *) = 8
```

**指针本身大小都一样**（都是存一个地址），但**解引用时读的字节数不同**：

| 指针类型 | `*p` 读几个字节 |
|---|---|
| `char *` | 1 |
| `int *` | 4 |
| `double *` | 8 |

实测演示（同一块内存 `0x41424344`）：

```text
    *pi（按 int 读）  = 0x41424344
    *pc（按 char 读） = 0x44  （只读了最低 1 字节）
  ↑ 小端机器上最低字节是 0x44，正好是 'D'
```

> 📌 所以指针类型不能乱写。`int` 的地址给 `double *`，读出来就是错的。

## 五、`r = &n` 和 `*r = n` 的区别

```c
int m = 1, n = 2;
int *r = &m;

r = &n;         /* 改的是指针本身，r 现在指向 n */
*r = 99;        /* 改的是 r 指向的那个值 */
```

| 写法 | 改什么 |
|---|---|
| `r = &n` | 指针的**指向** |
| `*r = 99` | 指针指向的**值** |

实测：

```text
  初始：*r = 1（指向 m）
  执行 r = &n 后：*r = 2（改指向 n 了）
```

## 六、⭐ 指针的三种状态

| 状态 | 声明 | 安全性 |
|---|---|---|
| **有效指针** | `int *p = &a;` | ✅ 安全 |
| **空指针** | `int *p = NULL;` | ⚠️ 可判断，不能解引用 |
| **野指针** | `int *p;`（未初始化） | ❌ **最危险，无法判断** |

实测：

```text
  int *p = NULL;
  p 的值 = 0000000000000000
  NULL 本质就是 (void*)0 —— 一个保证不指向任何有效数据的地址

  int *wild;  未初始化，wild 里的值是随机的
  wild = 00000061F73FF850（这是垃圾值，每次运行可能不同）
```

**为什么野指针比空指针更可怕**：

| | 空指针 | 野指针 |
|---|---|---|
| 值 | 确定是 0 | 随机 |
| 能判断吗 | ✅ `if (p == NULL)` | ❌ 判断不了 |
| 解引用后果 | 立刻崩溃 | 可能崩溃、可能悄悄改坏数据 |

> 📌 软考问「空指针和野指针的区别」，就答这两点：**值是否确定、能否判断**。

### 6.1 三条防野指针的规矩

```c
① 声明时就初始化：  int *p = NULL;
② 用之前判空：      if (p != NULL) { *p = ...; }
③ 释放后置空：      free(p); p = NULL;
```
