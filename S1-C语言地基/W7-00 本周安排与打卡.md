**2. 为什么数组传给函数后，函数能改数组内容？**

**3. 下面函数有什么问题？**

```c
int sum(int arr[]) {
    int n = sizeof(arr) / sizeof(arr[0]);
    int s = 0;
    for (int i = 0; i < n; i++) s += arr[i];
    return s;
}
```

**4. 下面代码输出什么？**

```c
void f(void) { static int x = 0; x++; printf("%d ", x); }
int main(void) { f(); f(); f(); }
```

**5. 把上一题的 `static` 去掉，输出变成什么？**

**6. `int sumMatrix(int m[][], int rows)` 为什么编译不通过？**

---

## 四、标准答案

1. **输出 `1`。** 值传递：`x` 是 `a` 的副本，函数里改 `x` 不影响 `a`。

2. **因为数组作参数时传的是首地址**，不是整个数组的拷贝。函数拿着地址就能直接操作原数组。注意这仍然是值传递——只是"值"变成了地址。

3. **`sizeof(arr)` 拿到的是指针大小（8 字节），不是数组大小。** 所以 `n` 会是 2（`8/4`），循环只跑了前两个元素。**必须额外传长度参数**：`int sum(int arr[], int n)`。

4. **输出 `1 2 3`。** `static int x = 0` 只在第一次调用时初始化，之后一直保留。每次进来是 `x++` 而不是 `x = 0`。

5. **输出 `1 1 1`。** 去掉 `static`，`x = 0` 每次调用都重新执行。

6. **第二维（列数）不能省。** 编译器要靠列数计算 `m[i][j]` 的地址偏移：`(i × 列数 + j) × 元素大小`。列数未知就算不出来，所以必须写 `int m[][4]`。
