## 四、标准答案要点

1. **B**。预处理 → 编译 → 汇编 → 链接，产物依次是 `.i` → `.s` → `.o` → `.exe`。
2. `3 3.50`。第一个是整数除法得 3；第二个把 a 强转成 double 得 3.5，`%.2f` 打两位。
3. **44**。`unsigned char` 范围 0~255，300 超出后按 256 取模：`300 % 256 = 44`。无符号溢出是**明确定义的回绕**。
4. `scanf("%c")` 会读到上一条 `scanf("%d")` 残留在缓冲区里的换行符，导致用户根本没机会输入。改成 `scanf(" %c", &grade)`（前面加空格）。
5. `"%6.2f"`。
