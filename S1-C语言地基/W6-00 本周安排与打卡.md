## 三、自测：全对才进 W7

**1. `char s[] = "abc";` 的 `sizeof(s)` 是多少？`strlen(s)` 是多少？**

**2. `char s2[] = {'a','b','c'};` 能用 `printf("%s", s2)` 打印吗？为什么？**

**3. `strcmp("abc", "abd")` 返回什么？`strcmp("abc", "abc")` 呢？**

**4. 下面代码输出什么？**

```c
char x[] = "abc";
char y[] = "abc";
printf("%d", x == y);
```

**5. `int a[3][4];` 中，`a[1][2]` 前面有几个元素？**

**6. 字符串反转时，找到末尾 `'\0'` 的位置之后，为什么必须先 `right--` 再开始交换？**

---

## 四、标准答案

1. **`sizeof(s)` = 4，`strlen(s)` = 3。** 差的那个就是末尾的 `'\0'` —— `sizeof` 算它，`strlen` 不算。

2. **不能。** `{'a','b','c'}` 是字符数组，没有 `'\0'` 结束标志。`printf("%s")` 会一直往后读内存直到碰巧遇到 0，读到什么打印什么，属于未定义行为（可能乱码、可能崩溃）。

3. **`strcmp("abc","abd")` 返回负数**（实际是 -1，表示前者小，因为 `'c' < 'd'`）；**`strcmp("abc","abc")` 返回 0**（相等）。

4. **输出 `0`（假）。** `==` 比较的是两个数组的**地址**，`x` 和 `y` 是两个不同的数组，地址必然不同。要比内容必须用 `strcmp(x, y) == 0`。

5. **6 个。** 公式：`i × 列数 + j` = `1 × 4 + 2` = 6。即 `a[0][0..3]`（4 个）加上 `a[1][0]`、`a[1][1]`（2 个）。

6. **因为 `right` 停在 `'\0'` 上（不是最后一个字符）。** 不 `--` 直接交换的话，会把 `'\0'` 换到开头，字符串立刻被截断成空串。
