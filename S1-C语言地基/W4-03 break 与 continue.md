# W4-03 break 与 continue

## 一、一句话区分

| 关键字 | 作用 | 影响范围 |
|---|---|---|
| `break` | **结束整个循环** | 本次循环不再有任何后续轮次 |
| `continue` | **结束本轮** | 下一轮照常进行 |

`34_break_continue.c` 的真实输出：

```text
=== ① break：i 到 4 就跳出 ===
1 2 3
  → 只打印了 1 2 3，4 及以后都没执行

=== ② continue：跳过 4 ===
1 2 3 5 6 7 8 9 10
  → 打印 1 2 3 5 6 7 8 9 10，只是没有 4
```

同样的循环（1 到 10），`break` 在 4 处停下就再也不动了，`continue` 只是跳过了 4。

## 二、continue 的典型用法：过滤

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;      /* 偶数跳过 */
    printf("%d ", i);
}
/* 输出 1 3 5 7 9 */
```

**写成 if 包起来也能达到同样效果：**

```c
for (int i = 1; i <= 10; i++) {
    if (i % 2 != 0) {
        printf("%d ", i);
    }
}
```

| 写法 | 优点 | 缺点 |
|---|---|---|
| `continue` | 减少嵌套层级，前置条件写在开头 | 逻辑被"跳转"打断，不如连续读顺畅 |
| `if` 包住 | 结构清晰 | 层数多了会形成"箭头形"缩进 |

> 💡 两种都对。判断标准是**可读性**：条件少用 continue，条件多用 if 包。别为了炫技硬用。

## 三、嵌套循环里的 break 只跳出本层

```c
for (int i = 1; i <= 3; i++) {
    for (int j = 1; j <= 3; j++) {
        if (j == 2) break;          /* 只跳出内层 */
        printf("(%d,%d) ", i, j);
    }
}
```

真实输出：

```text
(1,1) (2,1) (3,1)
  → 外层照常跑 3 轮，每轮内层只打了 j=1
```

**这是最容易误解的地方。** `break` 不会帮你跳出所有循环，只跳出**它所在的那一层**。

### 3.1 想跳出多层：标志变量法

```c
int found = 0;
for (int i = 1; i <= 3 && !found; i++) {     /* 条件里检查标志 */
    for (int j = 1; j <= 3; j++) {
        if (i * j == 6) {
            printf("找到 i=%d, j=%d\n", i, j);
            found = 1;
            break;                            /* 先跳出内层 */
        }
    }
}
```

真实输出：

```text
  找到 i=2, j=3，两层一起停
  原理：内层 break 后，外层的条件 !found 也变假，于是外层也停
```

**原理**：内层 `break` 只能跳到内层之外；但因为外层循环的条件里加了 `&& !found`，`found` 变成 1 之后，外层在下一次判断时也会失败，于是也停了。

> 📌 这是软考应用技术里常见的手法，也常出现在答案里。记住「标志变量 + 拆成两个条件」这个模式。

### 3.2 还有两种写法（了解）

```c
/* 法二：goto（C 语言支持，但工程上慎用） */
for (...) for (...) if (cond) goto done;
done:

/* 法三：把循环抽成函数，用 return 直接返回 */
```

软考应用技术里偶尔会出现 `goto` 的题，知道它「无条件跳转到标号处」即可。

## 四、⚠️ continue 在 while 里的死循环陷阱

这个坑非常经典：

```c
int i = 0;
while (i < 10) {
    if (i == 5) continue;     /* ❌ i 永远停在 5 */
    printf("%d ", i);
    i++;                      /* ← continue 跳过了这一句 */
}
```

**为什么会死循环**：`i` 到 5 时，`continue` 直接跳回条件判断，`i++` 永远不会执行，于是 `i` 卡在 5，条件 `i < 10` 永远成立。

**正确做法**：把更新提前，或者改用 `for`。

```c
/* 改法一：更新提到 continue 之前 */
int i = 0;
while (i < 10) {
    i++;
    if (i == 5) continue;
    printf("%d ", i);
}

/* 改法二：直接用 for（更新在头部，continue 不会跳过它） */
for (int i = 0; i < 10; i++) {
    if (i == 5) continue;
    printf("%d ", i);
}
```

真实输出（改法一）：

```text
  正确的 while 写法：1 2 3 4 6 7 8 9 10
  → 同样跳过 5，但不会死循环
```

> 💡 **`for` 比 `while` 更安全**的原因就在这里：更新的位置固定在头部，`continue` 跳不过去。所以「次数已知」的循环优先用 `for`。

## 五、break 的其他用途

`break` 不只用于循环，在 `switch` 里也用：

```c
switch (x) {
    case 1: ...; break;      /* 跳出 switch */
    case 2: ...; break;
}
```

⚠️ **`break` 只跳出它所在的那一层**：如果 `switch` 在循环里，`switch` 内的 `break` 只跳出 `switch`，不影响循环。

## 六、软考怎么考这部分

| 考点 | 位置 | 典型问法 |
|---|---|---|
| break 与 continue 的输出差异 | 应用技术 | 给一段循环问最终输出 |
| 嵌套循环的 break 范围 | 基础知识 | 「内层 break 后，外层还继续吗」 |
| continue 跳过更新的死循环 | 基础知识 | 「这段代码为什么停不下来」 |
| break 在 switch 与循环中的区别 | 基础知识 | 「switch 里的 break 会跳出循环吗」 |
| 标志变量跳出多层 | 应用技术 | 补全代码 |

**读程序题的判断方法**：

1. 先标出所有 `break` 和 `continue`
2. 遇到 `continue` → 本轮剩余代码全部跳过，直接进入**更新**步骤
3. 遇到 `break` → 跳出**最近的**一层循环（或 switch）
