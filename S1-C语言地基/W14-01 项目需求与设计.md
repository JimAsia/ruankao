## 二、数据结构怎么选

### 方案 A：三个平行数组（❌ 不推荐）

```c
int    ids[MAXN];
char   names[MAXN][20];
double scores[MAXN];
```

删除一个学生要同步移三个数组，漏一个就数据错乱。

### 方案 B：结构体数组（✅ 本项目采用）

```c
typedef struct {
    int    id;
    char   name[NAMELEN];
    double score;
} Student;

static Student g_stu[MAXN];
static int     g_count = 0;
```

删除时一句 `g_stu[i] = g_stu[i+1]` 就整体搬走，不会漏字段。

### 为什么用固定数组而不是动态分配

| 方式 | 优点 | 缺点 |
|---|---|---|
| 固定数组 `Student a[100]` | 简单、无内存泄漏 | 上限死板 |
| `malloc` 动态 | 想存多少存多少 | 要管理释放、代码复杂 |

> 📌 **软考应用题的答案几乎都是固定数组**。
> 因为题目一般会写「学生人数不超过 100」。看到这种话，直接开 `#define MAXN 100`。

### 人数用一个变量单独存

```c
Student g_stu[100];    /* 容量 100 */
int     g_count;       /* 实际有几个 */
```

> ⚠️ **不要用「数组长度」当人数。** 数组长度永远是 100（容量），实际人数是 `g_count`。
> 遍历一律 `for (i = 0; i < g_count; i++)`，不是 `i < MAXN`。

## 三、模块划分

整个程序 10 个函数，各管一件事：

| 函数 | 职责 | 返回 |
|---|---|---|
| `findById(id)` | 按学号找下标 | 下标或 -1 |
| `addStudent()` | 添加 | 无 |
| `showAll()` | 显示 | 无 |
| `searchById()` | 查找并显示 | 无 |
| `sortByScore()` | 排序 | 无 |
| `modifyScore()` | 改成绩 | 无 |
| `deleteStudent()` | 删除 | 无 |
| `showStats()` | 统计 | 无 |
| `loadFromFile(path)` | 加载 | 条数或 -1 |
| `saveToFile(path)` | 保存 | 0 或 -1 |

> ⭐ **`findById` 是核心。** 查找、修改、删除三个功能都要用它，写一次用三次。
> 这就是函数的价值 —— 不是「代码短」，是**逻辑只有一份**。

```c
static int findById(int id)
{
    for (int i = 0; i < g_count; i++) {
        if (g_stu[i].id == id) return i;
    }
    return -1;              /* 找不到统一返回 -1 */
}
```

调用方：

```c
int idx = findById(id);
if (idx < 0) { printf("未找到\n"); return; }
/* 后面直接用 g_stu[idx] */
```

## 四、主循环的骨架

```c
int running = 1;
while (running) {
    printMenu();
    int choice;
    if (scanf("%d", &choice) != 1) {
        clearInput();          /* ⚠️ 必须清，否则死循环 */
        printf("无效输入\n");
        continue;
    }
    switch (choice) {
        case 1: addStudent();  break;
        /* ... */
        case 0: running = 0;   break;
        default: printf("无效选项\n"); break;
    }
}
```

### 三个必须注意的点

**① `scanf` 失败必须清缓冲区**

如果用户输入 `abc`，`scanf("%d")` 返回 0，`abc` 留在缓冲区里。下一轮 `scanf` 又读到 `abc`，又失败……**无限循环打印菜单**。

```c
static void clearInput(void)
{
    int c;
    while ((c = getchar()) != '\n' && c != EOF) { }
}
```

实测：输入 `abc` 后程序输出 `无效输入，请输入 0-9`，然后正常继续，不会卡死。

**② 用 `running` 标志而不是 `while (1) + break`**

两种都对，但 `running` 的好处是**退出前还能做事**（本项目里是「问是否保存」）。

**③ 每个 case 都要 `break`**

漏了就会穿透到下一个功能。这是 W3 讲过的坑，在真实项目里后果更严重。

## 五、输入校验放在哪

三处必须校验：

| 位置 | 校验什么 | 不校验的后果 |
|---|---|---|
| 学号 | 是否重复 | 出现两个学号相同的人，查找删除全乱 |
| 成绩 | `0 <= s <= 100` | 出现 -5 分、120 分，统计结果荒谬 |
| 姓名 | 用 `%19s` 限宽 | 超长姓名写爆 `char[20]` |
| 人数 | `g_count < MAXN` | 数组越界，程序崩溃 |

```c
if (g_count >= MAXN) {
    printf("人数已满（上限 %d）\n", MAXN);
    return;
}
if (findById(id) >= 0) {
    printf("学号 %d 已存在\n", id);
    return;
}
```

> ⭐ **输入校验是「工程」和「作业」的分界线。**
> 作业里不校验也能跑通老师给的测试数据；工程里不校验，用户第一次乱输就崩。

## 六、文件格式怎么定

```
1001 张三 85.0
1002 李四 92.0
1003 王五 78.0
```

一行一条，空格分隔。写和读的格式串必须配对：

| 操作 | 格式串 |
|---|---|
| 写 `fprintf` | `"%d %s %.1f\n"` |
| 读 `fscanf` | `"%d %19s %lf"` |

> ⚠️ **两个不对称点：**
> - 写用 `%.1f`，读用 `%lf`（`scanf` 读 `double` 必须加 `l`）
> - 读要加宽度 `%19s`，防止别人的文件里姓名超长
