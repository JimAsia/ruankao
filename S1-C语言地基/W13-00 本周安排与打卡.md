## 三、自测六题

**1. `5 & 3`、`5 | 3`、`5 ^ 3`、`~5` 各是多少？**

**2. 把整数 `x` 的第 3 位清零，代码怎么写？**

**3. `1 << 31` 和 `1u << 31` 有区别吗？**

**4. `#define SQ(x) x * x`，那么 `SQ(2 + 1)` 等于多少？**

**5. 多语句宏为什么必须用 `do { ... } while (0)` 包起来？**

**6. `struct { unsigned int a : 3; };` 中 `a` 能存的最大值是多少？`sizeof` 是多少？**

## 四、答案与解析

**1.**

| 表达式 | 计算 | 结果 |
|---|---|---|
| `5 & 3` | `0101 & 0011` | **1** |
| `5 \| 3` | `0101 \| 0011` | **7** |
| `5 ^ 3` | `0101 ^ 0011` | **6** |
| `~5` | `~...00000101` | **-6** |

> `~5 = -6` 是最容易错的。按补码：`~x = -x - 1`，所以 `~5 = -6`。

**2.**

```c
x &= ~(1u << 3);
```

拆解：`1u << 3` 是 `0000 1000`，取反是 `1111 0111`，`&` 上去只清第 3 位。

**3. 有区别，而且是致命的。**

- `1 << 31`：`1` 是 `int`，左移 31 位让符号位变 1，属于**有符号溢出**（未定义行为）。gcc 通常给出 `-2147483648`，但不保证。
- `1u << 31`：`1u` 是 `unsigned`，得到 `2147483648`，正确。

> ✅ **位运算一律用 `1u` / `1ULL`。**

**4. `5`。**

展开成 `2 + 1 * 2 + 1` = `2 + 2 + 1` = **5**（不是 9）。

要得到 9 必须写：

```c
#define SQ(x) ((x) * (x))
```

**5. 因为要保证宏展开后是「一条完整语句」。**

```c
#define SWAP(a,b) { int t=(a); (a)=(b); (b)=t; }

if (m < n) SWAP(m,n);
else printf("x");
```

展开成 `if (m<n) { ... } ; else ...` —— 那个分号是一条空语句，`if` 到此结束，`else` 找不到配对，编译报错。

`do { ... } while (0)` 让整体成为一条语句，正好吸收调用处的分号。

**6. 最大值 7，`sizeof` 是 4。**

- 3 位无符号：`0 ~ 2³-1` = `0 ~ 7`
- `sizeof` 是 **4**，因为声明类型是 `unsigned int`，编译器按 `int` 分配单元，不是按位精确计算
- 想压到 1 字节要写 `unsigned char a : 3;`
