## 一、统计各类字符

```c
int upper = 0, lower = 0, digit = 0, space = 0, other = 0;

for (int i = 0; text[i] != '\0'; i++) {
    char c = text[i];
    if      (c >= 'A' && c <= 'Z') upper++;
    else if (c >= 'a' && c <= 'z') lower++;
    else if (c >= '0' && c <= '9') digit++;
    else if (c == ' ')             space++;
    else                           other++;
}
```

实测（`"Hello, World! 2026"`）：

```text
  大写字母 2 个      （H、W）
  小写字母 8 个      （ello、orld）
  数字     4 个      （2026）
  空格     2 个
  其他     2 个      （逗号、感叹号）
  总长度   18
```

**两个要点**：

1. **用字符区间判断，不要用 magic number**。写 `c >= 'A' && c <= 'Z'` 而不是 `c >= 65 && c <= 90`。
2. **能这样写的前提是 ASCII 连续**：`A~Z` 是 65~90，`a~z` 是 97~122，`0~9` 是 48~57。

## 二、大小写转换

```c
/* 小写 → 大写：减 32 */
if (s[i] >= 'a' && s[i] <= 'z') s[i] = s[i] - 32;

/* 大写 → 小写：加 32 */
if (s[i] >= 'A' && s[i] <= 'Z') s[i] = s[i] + 32;
```

实测：

```text
  原串：  "MiXeD CaSe"
  全大写："MIXED CASE"
  全小写："mixed case"
  原理：'a' - 'A' = 32，所以小写减 32 变大写
```

### 2.1 ⚠️ 转换后必须补 `'\0'`

如果你是把转换结果写到**另一个数组**：

```c
char toUpper[50];
for (int i = 0; s1[i] != '\0'; i++) {
    toUpper[i] = (s1[i] >= 'a' && s1[i] <= 'z') ? s1[i] - 32 : s1[i];
}
toUpper[strlen(s1)] = '\0';         /* ⚠️ 补上，否则不是合法字符串 */
```

**原地转换**（直接改自己）就不需要补，因为原来的 `'\0'` 还在。

## 三、回文判断

```c
int i = 0;
int j = strlen(s) - 1;
int isPal = 1;

while (i < j) {
    if (s[i] != s[j]) {
        isPal = 0;
        break;                  /* 一发现不同就收工 */
    }
    i++;
    j--;
}
```

实测：

```text
  "level " → 是回文
  "hello " → 不是回文
  "abcba " → 是回文
  "abcd  " → 不是回文
```

**边界情况**（现在不用管，写出来自动是对的）：

| 输入 | 结果 | 为什么 |
|---|---|---|
| `""` 空串 | 是回文 | `j` 变成 -1，`i < j` 为假，循环不执行 |
| `"a"` | 是回文 | `i == j`，循环不执行 |
| `"ab"` | 不是回文 | 比较一次就发现不同 |

### 3.1 进阶：忽略大小写和标点

经典题 `"A man, a plan, a canal: Panama"` 是回文，但要先「清洗」：

```c
/* ① 过滤：只保留字母和数字，同时转小写 */
char clean[100];
int k = 0;
for (int i = 0; s[i] != '\0'; i++) {
    if (s[i] >= 'A' && s[i] <= 'Z') clean[k++] = s[i] + 32;
    else if ((s[i] >= 'a' && s[i] <= 'z') || (s[i] >= '0' && s[i] <= '9'))
        clean[k++] = s[i];
}
clean[k] = '\0';

/* ② 再对 clean 做普通回文判断 */
```

> 📌 这个「先清洗，再判断」的两段式结构，是软考应用题里的常见套路。

## 四、⭐ 统计单词个数

```c
int wordCount = 0;
int inWord = 0;                     /* 是否正处在一个单词内部 */

for (int i = 0; sentence[i] != '\0'; i++) {
    if (sentence[i] != ' ') {
        if (!inWord) {              /* 从空格进入非空格 = 新单词开始 */
            wordCount++;
            inWord = 1;
        }
    } else {
        inWord = 0;                 /* 遇到空格，离开单词 */
    }
}
```

实测：

```text
  句子："I am learning C language"
  单词数 = 5
```

**核心思路**：数「从空格跳到非空格」的次数。

| 状态 | 动作 |
|---|---|
| 空格 → 非空格 | **单词数 +1**，标记进入单词 |
| 非空格 → 非空格 | 什么都不做（还在同一个单词里） |
| 非空格 → 空格 | 标记离开单词 |
| 空格 → 空格 | 什么都不做 |

> 💡 `inWord` 这个「标志变量」是 W4 讲过的模式：用一个变量记住上一轮的状态。

## 五、通用套路总结

字符串题几乎都能拆成这三步：

```text
① 遍历（for + s[i] != '\0'）
② 判断（字符区间 / 是否等于某字符）
③ 处理（计数 / 转换 / 交换 / 拼接）
```

| 题型 | ① 遍历 | ② 判断 | ③ 处理 |
|---|---|---|---|
| 统计字符 | 逐个 | 属于哪类 | 对应计数器 +1 |
| 大小写转换 | 逐个 | 是大写还是小写 | ±32 |
| 回文判断 | 首尾向中间 | `s[i] != s[j]` | 标记不是回文，break |
| 单词计数 | 逐个 | 是否空格 | 状态切换时 +1 |
| 字符串反转 | 首尾向中间 | 无 | 交换 |
| 查找子串 | 逐个起点 | 逐字符比较 | 记录位置 |

3. 再填判断和处理
4. 最后检查边界（空串、单字符、末尾 `'\0'`）
