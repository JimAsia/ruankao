# W6-02 字符数组与 \0

## 一、C 语言没有字符串类型

**字符串 = 以 `'\0'` 结尾的字符数组。**

这是本节唯一需要真正理解的事。没有 `string` 这个类型，只有一个约定：**从头往后读，读到 0 就停**。

```text
"abc" 在内存里：
┌───┬───┬───┬────┐
│ a │ b │ c │ \0 │
└───┴───┴───┴────┘
 97  98  99   0
```

---

## 二、⭐ 三种写法，差别很大

```c
char s1[] = "abc";                  /* 字符串：4 字节 */
char s2[] = {'a', 'b', 'c'};        /* 字符数组：3 字节，没有 '\0' */
char s3[] = {'a', 'b', 'c', '\0'};  /* 手动加 '\0'，才是字符串 */
```

实测：

```text
  char s1[] = "abc"             → sizeof = 4
  char s2[] = {'a','b','c'}      → sizeof = 3
  char s3[] = {'a','b','c','\0'} → sizeof = 4
```

| 写法 | 是字符串吗 | 能直接用 `%s` 打印吗 |
|---|---|---|
| `"abc"` | ✅ 是 | ✅ 能 |
| `{'a','b','c'}` | ❌ 不是 | ❌ **不能** |
| `{'a','b','c','\0'}` | ✅ 是 | ✅ 能 |

**为什么 `s2` 不能用 `%s` 打印**：`printf` 会一直往后读内存，直到碰巧遇到一个 0 才停。读到什么打印什么 —— 这是未定义行为，可能打印一堆乱码，也可能直接崩溃。

## 三、`'\0'` 的位置

实测 `s1` 的每个字节：

```text
  s1 的每个字节（用 %d 看 ASCII 码）：97 98 99 0
  97='a', 98='b', 99='c', 0='\0' —— 最后一个 0 就是结束标志
```

用 `%d` 打印字符，看到的是 ASCII 码。这个技巧在调试字符串时非常有用。

---

## 四、⭐ `sizeof` 与 `strlen` 的区别

| | sizeof | strlen |
|---|---|---|
| 是什么 | **运算符**（编译期求值） | **函数**（运行期数） |
| 数什么 | 分配了多少字节 | 有几个字符 |
| 算不算 `\0` | **算** | **不算** |
| 需要 `<string.h>` | 不需要 | 需要 |

实测：

```text
  sizeof(s1)  = 4   整个数组占几字节（含 '\0'）
  strlen(s1)  = 3   字符个数（不含 '\0'）
```

> 📌 这是软考选择题的高频对比。记住一句话：**sizeof 问「占多大」，strlen 问「有多长」。**

## 五、能不能修改

```c
char s[] = "abc";
s[0] = 'X';             /* ✅ 可以改，数组在栈上，是自己的内存 */

char *p = "abc";
p[0] = 'X';             /* ❌ 崩溃（段错误），字面量在只读区 */
```

| 写法 | 存储位置 | 能否修改 |
|---|---|---|
| `char s[] = "abc"` | 栈（自己的数组） | ✅ 能 |
| `char *p = "abc"` | 只读数据段 | ❌ 不能 |

实测：

```text
  s1[0] = 'X' 之后：Xbc   ← 数组在栈上，可以改
  char *p = "abc" 这种写法，p 指向只读区，内容是：abc
  写 p[0] = 'X' 会崩溃（段错误），本程序不演示
```

> 💡 想改内容就用数组；只想读就用指针，最好加 `const`：
> `const char *p = "abc";`

## 六、遍历字符串的三种写法

```c
char text[] = "Hello";

/* 写法一：下标 + strlen */
for (size_t i = 0; i < strlen(text); i++) printf("%c", text[i]);

/* 写法二：遇到 '\0' 停 */
for (int i = 0; text[i] != '\0'; i++) printf("%c", text[i]);

/* 写法三：指针边走边取（W9 会细讲） */
for (const char *q = text; *q != '\0'; q++) printf("%c", *q);
```

**推荐写法二**：

| 写法 | 问题 |
|---|---|
| 一 | `strlen` 每次判断都调用一遍，O(n²) |
| 二 | ✅ 只走一遍，不用库函数 |
| 三 | 需要理解指针，W9 再说 |

## 七、倒序打印

```c
int len = strlen(text);
for (int i = len - 1; i >= 0; i--) {
    printf("%c", text[i]);          /* 从最后一个字符打回第一个 */
}
```

实测：

```text
  正序：Hello
  倒序：olleH
```

⚠️ 起点是 `len - 1`，不是 `len`（`s[len]` 是 `'\0'`）。

## 八、二维字符数组 = 多个字符串

```c
char words[4][20] = {"level", "hello", "abcba", "abcd"};
```

```text
words[0] → "level"
words[1] → "hello"
words[2] → "abcba"
words[3] → "abcd"
```

这就是「字符串数组」在 C 里的写法：**每行一个字符串，第二维是每行能放的最大长度（含 `'\0'`）**。
