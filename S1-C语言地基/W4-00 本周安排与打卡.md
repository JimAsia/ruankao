## 三、自测：全对才进 W5

**1. 下面循环里 i 依次取哪些值？共执行几次？**

```c
for (int i = 0; i < 10; i += 3)
```

**2. `i = 100` 时，下面两段各执行几次循环体？**

```c
while (i <= 5) { printf("A"); i++; }
```
```c
do { printf("B"); i++; } while (i <= 5);
```

**3. 下面两段输出分别是什么？**

```c
for (int i = 0; i < 5; i++) { if (i == 2) continue; printf("%d ", i); }
```
```c
for (int i = 0; i < 5; i++) { if (i == 2) break;    printf("%d ", i); }
```

**4. 下面代码输出什么？**

```c
for (int i = 1; i <= 2; i++)
    for (int j = 1; j <= 3; j++) {
        if (j == 2) break;
        printf("(%d,%d) ", i, j);
    }
```

**5. 下面代码想找出 -5 和 -3 中的最大值，输出会是什么？错在哪？**

```c
int max = 0;
for (int i = -5; i <= -3; i += 2) {
    if (i > max) max = i;
}
printf("%d", max);
```

**6. `n = 3725` 时，下面代码输出什么？**

```c
int rev = 0;
while (n > 0) { rev = rev * 10 + n % 10; n /= 10; }
printf("%d", rev);
```

## 四、标准答案

1. **i 依次是 0、3、6、9，共 4 次。** `i += 3` 后 i = 12 时 `12 < 10` 不成立，退出。

2. **while 执行 0 次**（条件一开始就是假）；**do-while 执行 1 次**（先执行后判断）。这是两者唯一的本质差别。

3. continue 版输出 **`0 1 3 4`**（跳过 2，其余照打）；break 版输出 **`0 1 `**（到 2 就整个停）。

4. 输出 **`(1,1) (2,1) `**。内层 `break` 只跳出内层，外层照常跑完 2 轮，每轮内层只打了 j=1。

5. **输出 `0`，错了。** 三个数全是负数，`max` 初值 0 比它们都大，所以永远不更新。**初值应取一个足够小的数**（如 `-2147483647`），这样正确答案才是 -3。

6. **输出 `5273`**。四轮变化：`rev = 5 → 52 → 527 → 5273`。

> 全对 → 进 W5（一维数组）。
> 错 1～2 题 → 回看对应小节。第 5 题错了要特别警惕，那个坑在 W5 的数组最值里会再出现一次。
> 错 3 题以上 → 重做本周练习。**循环没打牢，S2 的数据结构会完全跟不上。**
