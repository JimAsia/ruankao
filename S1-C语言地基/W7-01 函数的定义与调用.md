## 一、函数的三个部分

```c
int add(int a, int b)       /* ← 函数头：返回类型 函数名(参数列表) */
{                           /* ← 函数体开始 */
    return a + b;           /* ← return 交回结果 */
}
```

| 部分 | 说明 |
|---|---|
| 返回类型 | 交出什么类型的值；不返回就写 `void` |
| 函数名 | 调用时用的名字，遵循标识符规则 |
| 参数列表 | 接收什么输入；不接收就写 `void` |
| `return` | 交回结果并结束函数 |

## 二、声明与定义

```c
int add(int a, int b);      /* 声明（原型）：只说"有这么个函数" */

int main(void) {
    add(1, 2);              /* 有了声明才能在这里调用 */
}

int add(int a, int b) {     /* 定义：给出具体实现 */
    return a + b;
}
```

**为什么需要声明**：编译器从上往下读代码，遇到 `add(1,2)` 时必须先知道 `add` 长什么样，才能检查参数类型对不对。

实测输出里写了：

```text
  如果删掉声明，编译器会报 'implicit declaration of function'
  C99 之后这是错误，不是警告
```

> 💡 实际项目里，声明放在 `.h` 头文件，定义放在 `.c` 源文件。`#include <stdio.h>` 拿到的就是一堆函数的声明。

## 三、四种返回形态

| 形态 | 例子 | 什么时候用 |
|---|---|---|
| 无参无返回 | `void sayHello(void)` | 只做一件事，不需要输入输出 |
| 有参无返回 | `void printLine(int n)` | 有输入，但结果是"做出来"的（打印） |
| 有参有返回 | `int add(int a, int b)` | 最常用 |
| 无参有返回 | `int getInt(void)` | 从某处取值 |

**判断标准**：

```text
需要把结果交回去 → 有返回值
只是做事/输出   → void
```

## 四、返回值能直接参与运算

```c
int s = add(3, 4);                      /* 存进变量 */
printf("%d", add(10, 20) + 5);          /* 直接参与运算 */
int total = add(add(1, 2), add(3, 4));  /* 嵌套调用 */
```

实测：

```text
add(3, 4) = 7
add(10, 20) + 5 = 35
add(add(1,2), add(3,4)) = 10
```

> ⚠️ **函数可以嵌套调用，但不能嵌套定义**。C 语言不允许在函数内部再定义函数。

## 五、提前 return

```c
double average(int sum, int count)
{
    if (count == 0) return 0.0;     /* 提前拦掉异常情况 */
    return (double)sum / count;
}
```

实测：

```text
  average(10, 4) = 2.50
  average(10, 0) = 0.00  ← 被 count==0 的提前 return 拦住了
```

**好处**：把异常情况在开头处理掉，后面就是"正常路径"，不用层层嵌套 `if`。

这就是所谓的「卫语句」（guard clause），是写好函数的基本功。

## 六、函数设计的三条建议

| 建议 | 理由 |
|---|---|
| **一个函数只做一件事** | 名字能说清楚，测试和复用都容易 |
| **参数不超过 4 个** | 超过就该考虑用结构体打包（W11） |
| **返回值要能表达失败** | 比如返回 -1 表示出错，或者用 `bool` + 输出参数 |
