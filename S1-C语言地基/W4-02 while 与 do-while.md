# W4-02 while 与 do-while

## 一、while：先判断，再执行

```c
while (条件) {
    循环体
}
```

**执行顺序**：判断 → 体 → 判断 → 体 → ……直到条件为假。

⚠️ **循环体里必须有让条件趋假的动作**，否则死循环：

```c
int i = 1;
while (i <= 5) {
    printf("%d ", i);
    i++;              /* ← 没有这句就是死循环 */
}
```

---

## 二、do-while：先执行，再判断

```c
do {
    循环体
} while (条件);       /* ← 末尾这个分号不能丢 */
```

**执行顺序**：体 → 判断 → 体 → 判断 → ……

**关键区别：至少执行一次。**

---

## 三、两者的本质差别

`33_while_dowhile.c` 用同一个条件（`i = 100; i <= 5`）跑了两种循环，真实输出：

```text
=== ② 条件一开始为假 ===
while：  （循环体执行了 0 次）

do-while：执行了一次 （循环体执行了 1 次）

  这就是两者的本质区别：
    while    先判断，条件假 → 0 次
    do-while 先执行，条件假 → 1 次
```

| | while | do-while |
|---|---|---|
| 判断时机 | 体之前 | 体之后 |
| 最少执行次数 | **0** | **1** |
| 末尾分号 | 无 | **必须有** |
| 适用 | 次数未知，可能不执行 | 至少要执行一次 |

---

## 四、什么时候必须用 do-while

典型场景：**先做一次，再看要不要继续**。

**菜单**：

```c
do {
    显示菜单();
    读取选择();
} while (choice != 2);
```

菜单必须显示一次，用户才能选「退出」。用 while 写反而不自然。

**输入校验**（要求至少输入一次）：

```c
do {
    printf("请输入 1~100 的数: ");
    scanf("%d", &n);
} while (n < 1 || n > 100);
```

`33_while_dowhile.c` 里的菜单演示：

```text
  [第 1 次显示菜单]  1.开始  2.退出  → 用户选了 1
  [第 2 次显示菜单]  1.开始  2.退出  → 用户选了 2
  退出菜单。do-while 保证菜单至少出现一次，即使一进来就想退出
```

> 📌 软考问「哪种循环至少执行一次」，答案就是 **do-while**。这是选择题。

## 五、for 与 while 可以互换

```c
/* for */
for (int k = 0; k < 3; k++) printf("%d ", k);

/* while 等价写法 */
int k = 0;                      /* 初始化提到外面 */
while (k < 3) {                 /* 条件 */
    printf("%d ", k);
    k++;                        /* 更新放末尾 */
}
```

**对应关系**：

| for 的三段 | while 里的位置 |
|---|---|
| 初始化 | 循环之前 |
| 条件 | while 括号里 |
| 更新 | 循环体末尾 |

**选择建议**：

| 情况 | 用哪个 |
|---|---|
| 次数已知 | **for**（三段集中写，不易漏更新） |
| 次数未知，靠条件退出 | **while** |
| 至少执行一次 | **do-while** |

## 六、死循环

```c
for (;;) { ... }
while (1) { ... }
do { ... } while (1);
```

死循环本身不是错，常用在「服务端主循环」「菜单」这类需要一直跑的程序里，靠 `break` 或 `return` 退出。

⚠️ **无意造成的死循环**才是 bug，常见原因：

| 原因 | 例子 |
|---|---|
| 忘了更新循环变量 | `while (i < n) { ... }` 没有 `i++` |
| 更新方向错了 | `while (i < n) i--;` |
| `continue` 跳过了更新（见下一篇） | `while (...) { if (x) continue; i++; }` |
| 条件恒真 | `while (i = 1)` 用了赋值 |
