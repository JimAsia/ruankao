## 三、自测六题

**1. 对一个已有 1KB 内容的 `a.txt` 执行 `fopen("a.txt", "w")`，文件变成多少字节？**

**2. `fopen("不存在.txt", "r")` 返回什么？该怎么处理？**

**3. `fgets` 读入 `"abc\n"` 这一行，`strlen` 是多少？为什么？**

**4. `fgetc` 的返回值为什么要用 `int` 接，不能用 `char`？**

**5. `fwrite(a, sizeof(Student), 3, fp)` 返回什么？返回 2 说明什么？**

**6. 为什么不能用 `while (!feof(fp))` 做读循环的条件？**

---

## 四、答案与解析

**1. 0 字节。** `"w"` 模式打开即清空，哪怕一个字都不写。这是新手丢数据的头号原因。
想读就用 `"r"`，想追加就用 `"a"`。

**2. 返回 `NULL`。** 必须判：

```c
FILE *fp = fopen("不存在.txt", "r");
if (fp == NULL) {
    perror("fopen");        /* 打印具体原因 */
    return 1;
}
```

> `perror` 会输出 `fopen: No such file or directory`，比「打开失败」有用得多。

**3. 4。** 内容 `abc` 三个字符 + `'\n'` 一个，共 4 字节。
**`fgets` 会把换行符一起读进来**，这是它和 `gets` 一样「按行读」的代价。
所以比较字符串前常要去掉：

```c
size_t len = strlen(line);
if (len > 0 && line[len - 1] == '\n') line[len - 1] = '\0';
```

**4. 因为要能表示 `EOF`。** `EOF` 通常是 `-1`。
如果用 `char`（尤其 `unsigned char`）接，`-1` 会变成 `255`，`255 != EOF` 永远成立 → **死循环**。

**5. 返回成功写入的「元素个数」，即 3。** 返回 2 说明只写了 2 条，第 3 条失败 —— 通常是磁盘满、权限问题或路径失效。
**注意不是字节数**（字节数是 96）。

**6. 因为 `feof` 只有在「读操作已经失败」之后才返回真。**
所以循环会多跑一次，处理一条不存在的数据。如果里面是 `sum += x`，就会多加一次上一次的旧值。

> ✅ 正确做法：用读函数的返回值判断
> ```c
> while (fscanf(fp, "%d", &x) == 1) { ... }
> while (fgets(line, sizeof(line), fp) != NULL) { ... }
> while ((ch = fgetc(fp)) != EOF) { ... }
> ```
