## 三、自测：全对才进 W4

**1. 下面代码输出什么？**

```c
int a = 1, b = -5;
if (a > 0)
    if (b > 0)
        printf("both\n");
else
    printf("a <= 0\n");
```

**2. `score = 85` 时，下面代码输出什么？错在哪？**

```c
if (score >= 60)      printf("及格\n");
else if (score >= 90) printf("优秀\n");
```

**3. `n = 3` 时，下面代码输出几行？分别是哪几行？**

```c
switch (n) {
    case 1: printf("A\n");
    case 2: printf("B\n");
    case 3: printf("C\n");
    default: printf("D\n");
}
```

**4. `a = 5, b = 8` 时，`(a > b) ? a : b` 的值是多少？**

**5. 补全闰年判断条件：**

```c
if (______)
    printf("闰年\n");
```

**6. 下面这段嵌套分支有 3 条执行路径，要全部覆盖至少需要几组测试数据？**

```c
if (x > 0)
    if (y > 0)  printf("Q1\n");
    else        printf("Q2\n");
else
    printf("Q3\n");
```

## 四、标准答案

1. **输出 `a <= 0`**。`else` 就近匹配内层 `if`。虽然 a = 1（正数），但内层 `b > 0` 为假，于是执行属于内层的 `else`。这正是悬空 else 的坑。

2. **输出 `及格`**，`else if (score >= 90)` 永远轮不到。因为 85 已经在第一个条件 `score >= 60` 命中并执行完了。**else if 链必须从大到小判断。**

3. **输出 2 行：`C`、`D`**。`n = 3` 从 `case 3` 进入，打印 `C`，没有 `break` 所以继续穿透到 `default`，再打印 `D`。前面 case 1、case 2 不匹配，不执行。

4. **`8`**。条件 `5 > 8` 为假，取冒号后面的值。

5. **`(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)`**。外层括号建议写上，虽然 `&&` 优先级更高，省掉结果也对。

6. **3 组**。三个判断结果（`x > 0`、`y > 0`、无 else 的第 3 条路径）各需要覆盖：取 `(1,1)`、`(1,-1)`、`(-1,0)` 三组即可。
