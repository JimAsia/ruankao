## 一、⭐ 指针数组 vs 数组指针（一字之差）

```c
int *a[10];        /* 指针数组：10 个元素的数组，每个元素是 int* */
int (*b)[10];      /* 数组指针：1 个指针，指向「含 10 个 int 的数组」 */
```

| | `int *a[10]` | `int (*b)[10]` |
|---|---|---|
| 是什么 | **数组** | **指针** |
| `sizeof` | 80（10 × 8） | 8（一个指针） |
| 元素/指向 | 元素是 `int*` | 指向 `int[10]` |
| 常见用途 | 存多个字符串 | 处理二维数组 |

实测：

```text
  指针数组：sizeof(a) = 24（3 个指针）
  数组指针：sizeof(b) = 8，sizeof(*b) = 16（4 个 int）
```

### 1.1 ⭐ 读声明的口诀

**从变量名开始，先看右边，再看左边；括号优先。**

```text
int *a[10];
    a 先和 [10] 结合 → a 是数组
    再和 * 结合      → 元素是指针
    结论：10 个 int* 的数组

int (*b)[10];
    括号先        → b 是指针
    指向 int[10]  → 指向「10 个 int 的数组」
```

**为什么括号不能省**：`[]` 的优先级高于 `*`，不加括号 `b` 会先被 `[]` 拿走。

## 二、指针数组的实际用途

```c
const char *names[3] = {"Alice", "Bob", "Cathy"};
```

这就是「字符串数组」最省空间的写法 —— 只存 3 个地址，字符串本体在只读区。

**对比二维数组**：

| 写法 | 占用 | 长度限制 | 能否修改 |
|---|---|---|---|
| `char a[3][10]` | 30 字节 | 每个 ≤9 字符 | ✅ |
| `const char *a[3]` | 24 字节 | 不限 | ❌ |

## 三、⭐ const 与指针的四种组合

这是最容易搞混的一组。**诀窍：看 const 在 `*` 的哪一边。**

```c
const int *p;           /* const 在 * 左边 → 锁【值】 */
int * const p;          /* const 在 * 右边 → 锁【指针】 */
const int * const p;    /* 两边都有 → 全锁 */
int *p;                 /* 无 const → 都不锁 */
```

| 写法 | 能否改 `*p` | 能否改 `p` |
|---|---|---|
| `int *p` | ✅ | ✅ |
| `const int *p` | ❌ | ✅ |
| `int * const p` | ✅ | ❌ |
| `const int * const p` | ❌ | ❌ |

实测验证：

```text
  ① const int *p1 = &a;
     p1 = &b  ✅ 可以改指向
     *p1 = 99 ❌ 编译错误

  ② int *const p2 = &a;
     *p2 = 99 ✅ 可以改值（a 变成 99）
     p2 = &b  ❌ 编译错误

  ③ const int *const p3 = &a;
     两个都不能改
```

### 3.1 一句口诀

```text
const 在星号左边 → 锁值
const 在星号右边 → 锁指针
两边都有         → 全锁
```

**另一种读法（从右往左读，英文习惯）**：

```text
const int *p     →  p is a pointer to const int
int * const p    →  p is a const pointer to int
```

> 📌 软考选择题经常给一个声明问「哪个操作非法」。用上面的口诀现场判断即可。

## 四、二级指针回顾

```c
int **pp;       /* 指向「int*」的指针 */
```

**什么时候用**：

| 场景 | 例子 |
|---|---|
| 改一个指针的指向 | `void retarget(int **pp, int *t)` |
| 链表删除头节点 | `void removeHead(Node **head)` |
| 函数返回指针 + 错误码 | `int create(Node **out)` |
| 动态二维数组（S2） | `int **matrix` |

类型链：

```text
p      int*     指向 int
&p     int**    指向「int*」
*pp    int*     就是 p
**pp   int      就是 p 指向的值
```

## 五、函数指针（了解即可）

```c
int add(int a, int b) { return a + b; }

int (*fp)(int, int) = add;      /* fp 是指向函数的指针 */
int r = fp(3, 4);               /* 通过指针调用 */
```

**读法**：`(*fp)` 表示 fp 是指针，`(int,int)` 是参数，`int` 是返回类型。

**用途**：把函数当参数传（回调）、实现策略模式。

> 初级程序员很少考，知道「有这么个东西、能读得懂声明」就够了。

## 六、声明速查表

| 声明 | 含义 |
|---|---|
| `int *p` | 指向 int 的指针 |
| `int **p` | 指向「int*」的指针（二级指针） |
| `int *a[10]` | 10 个 int* 的数组（指针数组） |
| `int (*a)[10]` | 指向「int[10]」的指针（数组指针） |
| `int (*f)(int)` | 指向「接收 int 返回 int 的函数」的指针 |
| `const int *p` | 指向 const int 的指针（值不可改） |
| `int * const p` | const 指针，指向 int（指向不可改） |

> 💡 见到复杂声明就套口诀：**从变量名开始，先右后左，括号优先**。
