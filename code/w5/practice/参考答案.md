## ex41 输入输出求和（输入 `5` / `3 7 1 9 4`）

```text
数组：3 7 1 9 4
总和 = 24
平均 = 4.80
```

**注意两点：**

1. 读入数组要用循环：
```c
for (int i = 0; i < n; i++) scanf("%d", &a[i]);
```
不是 `scanf("%d", a)` —— 那样只能读第一个元素。

2. 平均必须转浮点：
```c
(double)sum / n        /* ✅ 4.80 */
sum / n                /* ❌ 4，整数除法 */
```

## ex42 最值及下标（输入 `6` / `72 45 91 38 66 88`）

```text
最大值 = 91，下标 = 2
最小值 = 38，下标 = 3
```

**关键：`max = a[0]`，循环从 `i = 1` 开始。**

```c
int max = a[0], maxIdx = 0;
for (int i = 1; i < n; i++) {
    if (a[i] > max) { max = a[i]; maxIdx = i; }
}
```

如果写成 `max = 0`，遇到全负数数组就会输出 0 —— 这是 W4 就强调过的坑，这里再犯一次。

> 💡 补充：用 `>` 得到**第一个**最大值的位置，用 `>=` 得到**最后一个**。软考读程序题会考这个细节。

## ex43 数组逆序（输入 `6` / `1 2 3 4 5 6`）

```text
逆序后：6 5 4 3 2 1
```

```c
for (int i = 0, j = n - 1; i < j; i++, j--) {
    int t = a[i]; a[i] = a[j]; a[j] = t;
}
```

**条件必须是 `i < j`：**

| 条件 | 后果 |
|---|---|
| `i < j` | ✅ 正确，每轮换首尾两个 |
| `i < n` | ❌ 每个元素被换两次，等于没换 |
| `i <= j` | 结果对，但奇数个元素时中间那个会和自己交换（多做一次无用功） |

## ex44 顺序查找（输入 `6` / `15 28 37 42 58 63` / `42`）

```text
下标 = 3
```

查找不存在的值（`100`）输出 `-1`。

**为什么用 -1 表示没找到**：0 是合法下标，用它表示「没找到」会和「在下标 0 找到」混淆。-1 永远不可能是合法下标，所以安全。

**找到就 `break`**，不用继续扫。

## ex45 删除所有等于 x 的元素（输入 `7` / `3 5 3 7 3 9 1` / `3`）

```text
删除后：5 7 9 1
剩余个数 = 4
```

**覆盖法（双指针）：**

```c
int k = 0;
for (int i = 0; i < n; i++) {
    if (a[i] != x) {
        a[k] = a[i];
        k++;
    }
}
n = k;
```

**为什么这个算法是对的**：`k` 永远 ≤ `i`，所以 `a[k] = a[i]` 只会写到已经读过的位置，不会覆盖还没读的数据。

**为什么比「找到一个就整体前移」好**：

| 方法 | 复杂度 | 说明 |
|---|---|---|
| 每找到就前移 | O(n²) | 每删一个都要搬一遍 |
| **覆盖法** | **O(n)** | 一趟走完 |

这题是本周最难的一道，也是软考应用题里出现过的模型。**想不出来就先跑答案，理解后合上文件默写一遍。**

## ex46 冒泡排序（输入 `6` / `72 45 91 38 66 88`）

```text
排序后：38 45 66 72 88 91
```

```c
for (int i = 0; i < n - 1; i++) {
    for (int j = 0; j < n - 1 - i; j++) {
        if (a[j] > a[j + 1]) {
            int t = a[j]; a[j] = a[j+1]; a[j+1] = t;
        }
    }
}
```

**三个常见错误：**

| 错误 | 后果 |
|---|---|
| 内层 `j < n - 1`（漏了 `- i`） | 结果对，但多做无用功 |
| 内层 `j <= n - 1 - i` | 越界 |
| 条件写 `a[j] < a[j+1]` | 变成降序 |

改成降序只需把 `>` 改成 `<`。
