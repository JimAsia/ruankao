## ex71 递归求和

```text
sumTo(10) = 55
sumTo(100) = 5050
```

```c
int sumTo(int n) {
    if (n == 1) return 1;
    return n + sumTo(n - 1);
}
```

**展开过程**：

```text
sumTo(10) = 10 + sumTo(9)
          = 10 + 9 + sumTo(8)
          = ...
          = 10 + 9 + ... + 2 + sumTo(1)
          = 10 + 9 + ... + 2 + 1
```

> 💡 这题用循环其实更好。递归版的价值在于练「递推思维」，不是为了性能。

## ex72 递归阶乘

```text
fact(10) = 3628800
fact(20) = 2432902008176640000
```

```c
long long fact(int n) {
    if (n <= 1) return 1;
    return (long long)n * fact(n - 1);
}
```

**⚠️ 出口写 `n <= 1` 而不是 `n == 1`：**

| 出口 | `fact(0)` 的结果 |
|---|---|
| `n == 1` | 一直递归到 -1、-2… → **栈溢出** |
| `n <= 1` | 正确返回 1（数学上 `0! = 1`） |

这是「出口没覆盖边界」的典型后果。

## ex73 递归斐波那契

```text
fib(10) = 55
fib(20) = 6765
fib(30) = 832040
```

```c
long long fib(int n) {
    if (n <= 2) return 1;
    return fib(n - 1) + fib(n - 2);
}
```

**这题写对了，但它很慢 —— 必须知道为什么：**

```text
fib(5) = fib(4) + fib(3)
       = (fib(3) + fib(2)) + (fib(2) + fib(1))
         ↑ fib(3) 被算了两次
       = ((fib(2)+fib(1)) + 1) + (1 + 1)
         ↑ fib(2) 被算了三次 ...
```

**调用次数实测**：

| n | 调用次数 |
|---|---|
| 10 | 109 |
| 20 | 13,529 |
| 30 | 1,664,079 |
| 40 | 约 3 亿 |

复杂度 **O(2ⁿ)**。S2 会讲两种优化：改迭代，或者加「记忆化」。

## ex74 递归 gcd

```text
gcd(12, 18) = 6
gcd(100, 75) = 25
gcd(17, 5) = 1
```

```c
int gcd(int a, int b) {
    if (b == 0) return a;
    return gcd(b, a % b);
}
```

**这是递归最漂亮的例子** —— 三行，无循环，完全贴合数学定义。

**为什么规模一定缩小**：余数必然小于除数，所以第二个参数严格递减，最终到 0。

**为什么 `b == 0` 时答案是 a**：`x` 能同时整除 `x` 和 `0`，所以最大公约数就是 `x`。

## ex75 递归输出二进制

```text
10   → 1010
255  → 11111111
1024 → 10000000000
```

```c
void toBinary(int n) {
    if (n == 0) return;
    toBinary(n / 2);        /* 先递归 */
    printf("%d", n % 2);    /* 再输出 */
}
```

**为什么顺序不能反**

```text
toBinary(10) → toBinary(5) → toBinary(2) → toBinary(1) → toBinary(0)
                                                            ↓ 出口
打印顺序（返回时）：1 → 0 → 1 → 0，即 1010 ✓

如果先 printf 再递归：0 → 1 → 0 → 1，即 0101 ✗
```

**规律**：

| 写法 | 输出顺序 |
|---|---|
| 先递归，后 printf | 逆序（从深处往外） |
| 先 printf，后递归 | 正序（从外往里） |

## ex76 递归求数组最大值

```text
输入 6 / 72 45 91 38 66 88
输出：最大值 = 91
```

```c
int maxRec(int a[], int n) {
    if (n == 1) return a[0];                /* 出口：只剩一个 */

    int maxOfRest = maxRec(a, n - 1);       /* 前面 n-1 个的最大值 */
    return (a[n - 1] > maxOfRest) ? a[n - 1] : maxOfRest;
}
```

**递推式**：

```text
maxRec(a, n) = max( a[n-1], maxRec(a, n-1) )
```

**展开**（`{3, 7, 1}`）：

```text
maxRec(a,3) = max(1, maxRec(a,2))
maxRec(a,2) = max(7, maxRec(a,1))
maxRec(a,1) = 3                        ← 出口
回代：max(7,3)=7 → max(1,7)=7
```

> 💡 实际工程里求最大值用循环更好。这题是练「拆成 1 个元素 + 剩下所有」。
