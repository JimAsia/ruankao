## ex221 Prim

**实测输出**：

```text
从顶点 0 开始
  第 1 步：加入顶点 1，边权 2
  第 2 步：加入顶点 2，边权 3
  第 3 步：加入顶点 4，边权 5
  第 4 步：加入顶点 3，边权 6

最小生成树总权值 = 16 ✓
```

**三步逻辑**

```text
① 找 lowcost 最小的未访问点
② 加入集合，累加权值
③ 用新点更新所有未访问点的 lowcost
```

> ⭐ Prim 天然不会成环（每次只连一个新点）。
> 复杂度 O(n²)，只和顶点数有关 → 适合稠密图。

## ex222 Kruskal

**实测输出**：

```text
排序后：0-1(2) 1-2(3) 1-4(5) 0-3(6) 2-4(7) 1-3(8) 3-4(9)

选 0-1(2)
选 1-2(3)
选 1-4(5)
选 0-3(6)

总权值 = 16 ✓
```

**为什么跳过 2-4(7)**

前面已选 0-1、1-2、1-4，此时 2 和 4 已连通，再加 2-4 就形成环 `1-2-4-1`。
并查集 `find(2) == find(4)` → 跳过。

**三步**

```text
① 边排序 O(e log e)
② 依次取边，并查集判环
③ 选够 n-1 条就停
```

> ⭐ 复杂度 O(e log e)，e 越小越快 → 适合稀疏图。

## ex223 Dijkstra

**实测输出**：

```text
  确定 1（dist=10）  →  更新：2=60
  确定 3（dist=30）  →  更新：4=90
  确定 2（dist=60）  →  更新：4=70
  确定 4（dist=70）

到 0 = 0，到 1 = 10，到 2 = 60，到 3 = 30，到 4 = 70
```

**手算验证 0→4**

```text
直达 0→4         = 100
0→1→2→4        = 10+50+10 = 70
0→3→4          = 30+60 = 90
最短是 70 ✓
```

**核心一行**

```c
if (dist[u] + cost[u][v] < dist[v]) dist[v] = dist[u] + cost[u][v];
```

**三种算法对比**

| 算法 | 复杂度 | 解决 | 负权 |
|---|---|---|---|
| Dijkstra | O(n²) | 单源 | 不支持 |
| Bellman-Ford | O(ne) | 单源 + 判负环 | 支持 |
| Floyd | O(n³) | 所有点对 | 支持 |

## ex224 拓扑排序

**实测输出**：

```text
图 1：初始入度 0:0 1:1 2:1 3:1 4:2 5:2
      拓扑序列：0 → 1 → 2 → 3 → 4 → 5
      结果：成功（无环）✓

图 2：0→1 1→2 2→0
      初始入度 0:1 1:1 2:1（没有入度为 0 的点）
      结果：失败 → 有环 ✓
```

**关键点**

1. 入度为 0 的入队 → 出队输出 → 后继入度减 1 → 减到 0 再入队。
2. **输出数 < n 说明有环**（环上点入度永远 ≥ 1）。
3. 拓扑序列**不唯一**。

**判断序列是否合法**：每个点出现时，它的所有前驱必须已经出现过。

## ex225 判环

**实测输出**：

```text
有向图 0→1→2→0：有环 ✓
有向图 0→1→2→3：无环 ✓
无向图 0-1-2-0：有环 ✓
无向图 0-1-2（树）：无环 ✓
```

**有向图：三色标记**

```text
白（0）= 未访问
灰（1）= 正在递归栈上
黑（2）= 已完成

遇到灰色节点 → 有回边 → 有环
```

> ⚠️ **不能用「访问过就说明有环」**：`0→1、0→2、1→2` 里 2 被访问两次但没环。

**无向图：并查集**

加边时如果两端已连通，这条边就成环。

| # | 坑 | 后果 |
