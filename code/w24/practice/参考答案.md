## ex241 分区（快排核心）

**实测输出**：

```text
原始：[49 38 65 97 76 13 27 49]
基准 = 49
  a[6]=27 填到 i=0（左边）
  a[2]=65 填到 j=6（右边）
  a[5]=13 填到 i=2（左边）
  a[3]=97 填到 j=5（右边）
基准 49 归位到下标 3

分区后：[27 38 13 49 76 97 65 49]
```

**挖坑法三步**

```text
① pivot = a[lo]，a[lo] 变成「坑」
② j 从右往左找 < pivot 的，填左边的坑；i 从左往右找 > pivot 的，填右边的坑
③ i、j 相遇时，把 pivot 填进去
```

> ⭐ **全程只有赋值，没有交换**，比交换法效率高一点。

**两个重要结论**

1. 一趟分区后，**基准到了最终位置**
2. 软考问「快排一趟能确定几个元素」→ 至少 1 个（基准）

## ex242 完整快排 + 第 k 小

**实测输出**：

```text
① 完整快排：13 27 38 49 49 65 76 97，比较 22 次

② 第 3 小 = 38（比较 15 次）
   第 5 小 = 49（比较 18 次）

③ 随机 13 次 vs 已有序 28 次
```

**第 k 小的 O(n) 原理**

```text
完整快排：递归两边，每层总共 n → O(n log n)
第 k 小  ：只递归一边
          工作量 n + n/2 + n/4 + ... = 2n → O(n)
```

> ⭐ 这个技巧叫 **quickselect**，C++ 的 `nth_element` 就是它。

**最坏情况**

已有序时比较 28 次 = `n(n-1)/2`，退化成 O(n²)。

## ex243 归并 + 逆序对

**实测输出**：

```text
① 归并排序：13 27 38 49 49 65 76 97，比较 16 次

② 逆序对：
   暴力法（O(n^2)）：15 个
   归并法（O(nlogn)）：15 个
   两者一致 ✓
```

**归并统计逆序对的原理**

```c
if (a[i] <= a[j]) {
    tmp[k++] = a[i++];
} else {
    g_inv += (mid - i + 1);     // ⭐ 左边 i..mid 全都 > a[j]
    tmp[k++] = a[j++];
}
```

一次就能统计出 `mid - i + 1` 个逆序对 —— 这就是把 O(n²) 降到 O(n log n) 的关键。

> 📌 软考/面试常考「怎么快速统计逆序对」→ 归并排序。

## ex244 基数排序

**实测输出**：

```text
原始：329 457 657 839 436 720 355 123 90 5

exp=1   桶个数：2 0 0 1 0 2 1 2 0 2
        本趟：720 90 123 355 5 436 457 657 329 839
exp=10  本趟：5 720 123 329 436 839 355 457 657 90
exp=100 本趟：5 90 123 329 355 436 457 657 720 839 ✓
```

**为什么从低位到高位**

高位排在后面，优先级更高，会把低位已排好的顺序「覆盖」掉 —— 所以最终正确。

**为什么必须从后往前放**

为了保证稳定。相同位的相对顺序不能反转。
**基数排序的稳定性不是可选项，是正确性的前提。**

**复杂度**：O(d(n+r))，d=3（本例），r=10

## ex245 场景选算法

| 场景 | 答案 | 理由 |
|---|---|---|
| n=20 小数组 | 直接插入 | 代码简单、常数小 |
| 基本有序 | 直接插入 | 退化成 O(n) |
| 要求稳定 n=100000 | 归并 | 唯一 O(nlogn) 且稳定 |
| 内存紧张 | 堆排序 | 唯一 O(1) 空间的 O(nlogn) |
| 一般最快 | 快速 | 常数小、缓存友好 |
| 链表排序 | 归并 | 空间还能是 O(1) |
| 0~999 整数 | 基数 | 线性时间 |
| 第 k 小 | 快速选择 | 平均 O(n) |

**选择的四个维度**

```text
1. n 的大小          小 → 插入；大 → O(nlogn)
2. 数据初始状态       基本有序 → 插入
3. 是否要求稳定       要求 → 归并
4. 空间限制          紧张 → 堆排
+  数据类型          小范围整数 → 基数
```

## ex246 综合小测

**八题答案**

| 题 | 答案 |
|---|---|
| 快排最坏比较次数（n=1000） | 499500 = n(n-1)/2 |
| 归并 8 个元素几层递归 | log₂8 = 3 层 |
| 一趟能定位的排序 | 快排、选择、冒泡、堆排 |
| 稳定的排序 | 插入、冒泡、归并、基数 |
| 空间 O(1) 的 O(nlogn) | 堆排序 |
| 比较次数与数据无关 | 选择排序 |
| 基数排序是不是比较排序 | 不是，O(d(n+r)) |
| 一趟结果怎么判断 | 看确定了什么 |

**判断一趟结果的表**

| 现象 | 排序 |
|---|---|
| 最大值到末尾 | 冒泡 |
| 最小值到最前 | 选择 |
| 某元素左小右大 | 快速 |
| 前 i 个局部有序 | 插入 |
| 更接近有序但没定位 | 希尔 |

## 汇总：本周六个坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | 快排分区忘了 `i < j` 保护 | 越界 |

## 记忆卡：总表（考前必看）

| 排序 | 最好 | 最坏 | 空间 | 稳定 | 一趟后 |
|---|---|---|---|---|---|
| 直接插入 | O(n) | O(n²) | O(1) | 稳定 | 前 i 个有序 |
| 冒泡 | O(n) | O(n²) | O(1) | 稳定 | 最大到末尾 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 | 最小到最前 |
| 希尔 | O(n^1.3) | O(n^1.3) | O(1) | 不稳定 | 更接近有序 |
| 快速 | O(nlogn) | **O(n²)** | O(logn) | 不稳定 | 基准归位 |
| 归并 | O(nlogn) | O(nlogn) | **O(n)** | 稳定 | 局部有序 |
| 堆 | O(nlogn) | O(nlogn) | **O(1)** | 不稳定 | 堆顶归位 |
| 基数 | O(d(n+r)) | O(d(n+r)) | O(n+r) | 稳定 | 按位有序 |

**稳定性口诀**：插冒归基稳，选希快堆晃。
