## ex21 奇偶与正负（输入 `7`）

```text
7 是奇数
7 是正数
```

| 输入 | 输出 |
|---|---|
| `-4` | `-4 是偶数` / `-4 是负数` |
| `0` | `0 是偶数` / `0 是零` |

**两个要点：**

1. **判断奇数用 `n % 2 != 0`，不要用 `n % 2 == 1`。** 因为负数取余的符号跟被除数走：`-3 % 2` 得 `-1`，不是 `1`。用 `== 1` 的话 -3 会被判成偶数。
2. 三选一用 `if - else if - else`。写成三个独立 `if` 结果也对（三个条件互斥），但每次都要把三个条件全判一遍；而且一旦以后条件改得不互斥，就会输出多行。**互斥的判断一律用 else if 链。**

## ex22 最值与最小值（输入 `3 9 5`）

```text
最大值 = 9，最小值 = 3
```

**「打擂台」写法：**

```c
int max = a;            /* 先让 a 当擂主 */
if (b > max) max = b;   /* b 来挑战 */
if (c > max) max = c;   /* c 来挑战 */
```

这个模式比三目嵌套清楚得多：

```c
/* 反面例子，能算对但难读 */
int max = (a > b) ? ((a > c) ? a : c) : ((b > c) ? b : c);
```

> 💡 这个「打擂台」是 W5 求数组最大值的前身，先把模式记住。

## ex23 成绩分级（输入 `85`）

```text
if-else：良好
switch ：良好
```

**if-else 链的关键：从大到小判断。**

```c
if (score >= 90) ...
else if (score >= 80) ...    /* 85 在这里命中 */
```

如果反过来从小到大写，85 会在 `score >= 60` 就命中并跳过后面所有分支。

**switch 的关键：把范围压成离散值。**

```c
switch (score / 10) {        /* 85 / 10 = 8 */
    case 10:
    case 9:  printf("优秀\n"); break;   /* 故意不写 break，让 100 和 90~99 共享 */
```

## ex24 闰年判断

| 年份 | 结果 | 为什么 |
|---|---|---|
| 2024 | 闰年 | 能被 4 整除，不能被 100 整除 |
| 2023 | 平年 | 不能被 4 整除 |
| 1900 | **平年** | 能被 4 整除，**但也能被 100 整除**，且不能被 400 整除 |
| 2000 | **闰年** | 能被 400 整除 |

**完整条件：**

```c
(year % 4 == 0 && year % 100 != 0) || (year % 400 == 0)
```

只写 `year % 4 == 0` 的话，1900 会判错 —— 这是这道题唯一的坑。

## ex25 字符类型判断

| 输入 | 输出 |
|---|---|
| `A` | `'A' 是大写字母` |
| `z` | `'z' 是小写字母` |
| `7` | `'7' 是数字` |
| 空格 | `这个字符是空格` |
| `@` | `'@' 是其他字符` |

**核心：字符比较本质是 ASCII 码比较。**

```c
if (ch >= 'A' && ch <= 'Z')
```

能这样写的前提是 ASCII 表里大写字母是**连续**的（65~90），小写字母（97~122）、数字（48~57）也都连续。

⚠️ `scanf(" %c", &ch)` 前面那个空格不能省，否则会读到残留的换行（W1 学过的坑）。

## ex26 简易计算器

| 输入 | 输出 |
|---|---|
| `3 + 4` | `3.00 + 4.00 = 7.00` |
| `10 / 0` | `除数不能为 0` |
| `6 * 7` | `6.00 * 7.00 = 42.00` |

**三个要点：**

1. `scanf("%lf %c %lf", &a, &op, &b)` —— `%c` 前必须有空格。
2. **除法必须单独判 `b == 0`**，不能直接算。浮点除零会得到 `inf`，看起来不崩溃但结果是垃圾；整数除零直接崩溃。
3. `switch` 里每个 `case` 别忘了 `break`，尤其是 `case '/'` 里面那个 `if-else` 结束后要 `break`，否则会穿透到 `default` 报「无效运算符」。
