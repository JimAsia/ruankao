## ex191 树的递归统计

**实测输出**：

```text
节点总数 = 6（A B C D E F 共 6 个）
叶子数   = 3（D F C）
深度     = 4（A-B-E-F 共 4 层）

边界空树：节点 0，叶子 0，深度 0
```

**递归模板（核心）**

```c
节点数 = 左 + 右 + 1
叶子   = (左右都空 ? 1 : 0) + 左叶子 + 右叶子
深度   = max(左深, 右深) + 1
```

> ⭐ 三者共同点：先递归问左右子树，再汇总自己。
> 这是「树的递归」最核心的套路，后面所有树题都是这个骨架。

## ex192 三种遍历

**实测输出**：

```text
先序：1 2 4 5 3 （访问 5 次）
中序：4 2 5 1 3 （访问 5 次）
后序：4 5 2 3 1 （访问 5 次）
```

**一句话区分**

```text
先序：根 → 左 → 右    （根最先）
中序：左 → 根 → 右    （根居中）
后序：左 → 右 → 根    （根最后）
```

> ⭐ 左孩子永远在右孩子之前，区别只在根的位置。
> 英文名 Pre/In/Post 就是指根的位置。

## ex193 前序 + 中序重建

**实测输出**：

```text
前序：ABDECFG
中序：DBEAFCG
重建后，后序：DEBFGCA ✓
```

**分治切分**

```c
root = pre[0]                       // 根
rootIdx = 中序里根的下标
左子树：pre+1, in, rootIdx
右子树：pre+1+rootIdx, in+rootIdx+1, n-1-rootIdx
```

> ⚠️ 两个数组的左右子树必须用**同一套下标**切，不能各切各的。

**结论**：中序 + 前序（或中序 + 后序）能唯一确定树；只有前序 + 后序不能。

## ex194 层序遍历

**实测输出**：

```text
层序遍历：1 2 3 4 5 6 ✓
```

**为什么必须用队列**

```text
层序要求「先遇到先访问」= 先进先出 = 队列
递归（栈）做的是「先遇到后访问」，做不了层序
```

| 遍历 | 本质 | 结构 |
|---|---|---|
| 前/中/后序 | DFS | 栈/递归 |
| 层序 | BFS | 队列 |

## ex195 判断完全二叉树

**实测输出**：

```text
完全二叉树（1 2 3 4 5 6）→ 是 ✓
缺左孩子但右孩子有 → 否 ✗
```

**判断标准**

```text
把树按层序排开（空位也占位置），
完全二叉树 = 空位只能出现在最后，且中间不能断。
```

**实现**：层序遍历，用一个 `seenNull` 标记。一旦遇到 NULL 之后又遇到非 NULL，就不是完全二叉树。

> ⭐ 判断完全二叉树的目的是确认「能否用数组高效存储」（堆就要求完全二叉树）。

## ex196 镜像树

**实测输出**：

```text
翻转前中序：1 2 3 4 6 7 9
翻转后中序：9 7 6 4 3 2 1
```

**三步**

```c
t = left;  left = right;  right = t;   // 交换
mirror(left);  mirror(right);          // 递归
```

> ⭐ 镜像后中序正好是原中序的倒序（左中右 → 右中左）。
> 复杂度：时间 O(n)，空间 O(h)。

## 记忆卡

**三条性质**

```text
第 i 层最多 2^(i-1) 个
深度 k 最多 2^k - 1 个
n0 = n2 + 1
```

**三种遍历**（根的位置）

```text
先序：根左右    中序：左根右    后序：左右根
```

**重建结论**

```text
中序 + 前序 ✓    中序 + 后序 ✓    前序 + 后序 ✗
```
