# W11 练习参考答案与要点

> 答案源码在 `answers/` 目录。所有输出都是本机实际运行结果。
> 编译命令（ex101 需要 `-lm`）：
> ```bash
> gcc -std=c17 -Wall -Wextra -o ex101 ex101_struct_point.c -lm && ./ex101
> ```

## ex101 两点距离

**输入** `0 0` / `3 4`，**输出**：

```text
点 A(0.0, 0.0)
点 B(3.0, 4.0)
距离 = 5.00

struct Point 占 16 字节（2 个 double，没填充）
```

**关键点**

1. `scanf("%lf %lf", &a.x, &a.y)` —— `double` 用 `%lf`，且**必须加 `&`**（成员也是变量）。
2. 编译要加 `-lm`，否则报 `undefined reference to 'sqrt'`。这个错误代码没错，只是没链接数学库。
3. `sqrt` 返回 `double`，用 `%.2f` 输出两位小数。

**常见错误**

```c
int dist = sqrt(...);            /* ❌ 截断成整数 */
printf("%d", dist);
```

## ex102 统计成绩

**输入** 4 个学生，**输出**：

```text
平均分 = 87.00
最高分 = 李四（92.0）
```

**关键点**

1. `double sum = 0;` —— 用 `int` 会每加一次截断一次。
2. 最高分**存下标**，不存值：

```c
int maxIdx = 0;
for (int i = 1; i < n; i++)
    if (a[i].score > a[maxIdx].score) maxIdx = i;
```

3. 比较用 `>` 而不是 `>=`，保证并列时取先出现的（李四在赵六前面）。
4. `scanf("%d %19s %lf", &a[i].id, a[i].name, &a[i].score)` —— **`name` 不加 `&`**，`id` 和 `score` 要加。

> ⭐ `%19s` 里的 19 是宽度限制，防止输入超长把内存写坏。数组是 `char name[20]`，留 1 位给 `'\0'`。

## ex103 按姓名排序

**输入** Zhang / Li / Wang，**输出**：

```text
2 Li 92.0
3 Wang 78.0
1 Zhang 85.0
```

**关键点**

1. 比较用 `strcmp(a[j].name, a[j+1].name) > 0`（升序）。
2. 交换时**整体交换**：

```c
struct Student t = a[j];
a[j] = a[j+1];
a[j+1] = t;
```

3. 加了 `swapped` 标记做提前退出优化：某趟一次都没交换，说明已有序，直接 `break`。
4. 注意 `strcmp` 是按 ASCII 比较，**大写字母在小写字母前面**（`"Z" < "a"`）。

**常见错误**

```c
if (a[j].name > a[j+1].name)      /* ❌ 比较的是地址 */
if (!strcmp(a[j].name, a[j+1].name))  /* ⚠️ 这是「相等」不是「大于」 */
```

## ex104 批量加分

**输入** `3 5` + 三个学生，**输出**：

```text
1 张三 90.0
2 李四 100.0
3 王五 65.0
```

**关键点**

1. 函数签名必须是 `void addBonus(struct Student *p, double bonus)`，调用时传 `&a[i]`。
2. 函数内用 `p->score`。
3. 加分后要封顶：

```c
p->score += bonus;
if (p->score > 100.0) p->score = 100.0;
```

李四 98 + 5 = 103，不封顶就输出 103.0 —— 这是本题唯一的坑。

**对照实验**：把形参改成 `struct Student p`（不传指针），输出会完全没有变化。这就是 W7 讲的值传递。

## ex105 生日与年龄

**输入** `李四 2008 3 15`，**输出**：

```text
李四 2008-03-15 年龄 18
```

**三组边界实测**

| 输入生日 | 输出年龄 | 说明 |
|---|---|---|
| 2008-03-15 | 18 | 生日已过，直接算 |
| 2008-12-25 | **17** | 生日未到，减 1 |
| 2008-10-24 | 18 | 生日当天，算已到 |

**关键点**

1. 年龄 = 年份差，再判断今年生日是否已过。
2. 判断条件必须拆成两种情况：

```c
if (birth.m > NOW_M || (birth.m == NOW_M && birth.d > NOW_D))
    age--;
```

3. 输出用 `%02d` 补零：`3` → `03`。

**常见错误**

```c
if (birth.m > NOW_M && birth.d > NOW_D)   /* ❌ 用 && */
```

`3 月 15 日` 相对 `10 月 24 日`：月份 3 > 10 为假，整个条件直接假，看起来对。
但 `12 月 25 日`：12 > 10 真、25 > 24 真 → 判定「已过」，错算成 18 岁。
**正确结果是 17 岁** —— 这就是 `&&` 与 `||` 的分水岭。

## ex106 枚举与星期

**输入** `6`，**输出**：

```text
SAT  休息日

数字对应：MON=1 TUE=2 WED=3 THU=4 FRI=5 SAT=6 SUN=7
枚举值就是 7 个整数，所以能直接和 n 比较
```

**输入** `3` → `WED  工作日`
**输入** `9` → `输入错误（应为 1-7）`

**关键点**

1. 枚举定义 `MON = 1`，让 1 对应周一（默认从 0 开始就会错一位）。
2. 先做范围检查，再强制转换 `(enum Weekday)n`。
3. 五个工作日共用一段，**故意不写 `break`** —— 这是 case 穿透的正确用法。
4. `default` 分支不能省，虽然前面已经检查过范围。

> ⭐ C 的枚举**不做范围检查**。`(enum Weekday)99` 完全合法，编译器不拦你。所以范围检查必须自己写。

## 汇总：本周六个坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | `struct` 定义末尾漏分号 | 编译报错，位置指错行 |
| 2 | `sizeof` 直接相加成员大小 | 少算填充字节，答案错 |
| 3 | `s.name = "x"` | 编译错误，必须 `strcpy` |
| 4 | 结构体数组按字符串比较用 `==` | 永远找不到，悄悄错 |
| 5 | 传结构体值想改实参 | 改了副本，实参没变 |
| 6 | 年龄判断用 `&&` 而不是 `\|\|` | 跨年生日错算 1 岁 |
