## ex171 建表与遍历

**实测输出**：

```text
=== 尾插法 ===
  10 -> 20 -> 30 -> 40 -> 50 -> NULL
  输入 10 20 30 40 50 → 顺序一致

=== 头插法 ===
  50 -> 40 -> 30 -> 20 -> 10 -> NULL
  输入 10 20 30 40 50 → 顺序相反

=== 遍历求长度 ===
  尾插链表长度：5
  头插链表长度：5
```

**关键点**

1. 节点的 `next` 必须写 `struct Node *`（typedef 未生效）。
2. 头插两句顺序：`n->next = head->next;` 然后在 `head->next = n;`。
   **反了会成自环，遍历死循环。**
3. 销毁时先存 `next` 再 `free`。

## ex172 按位置插入与删除

**实测输出**：

```text
初始：10 -> 20 -> 30 -> 40 -> 50

在下标 2 插入 99 → 10 -> 20 -> 99 -> 30 -> 40 -> 50
表头插入 5       → 5 -> 10 -> 20 -> 99 -> 30 -> 40 -> 50
末尾插入 60      → ... -> 50 -> 60
删除下标 3       → 被删的是 99，结果 5 -> 10 -> 20 -> 30 -> 40 -> 50 -> 60
```

**关键点**

1. 插入 `pos` 合法范围 `0..length`；删除 `0..length-1`。
2. 插入两句顺序不能反（先接后断）。
3. 删除必须 `free(victim)`。
4. **表头插入 O(1)（前驱是头结点），表尾插入 O(n)（要找尾）** —— 和顺序表正好相反。

## ex173 逆置

**实测输出**：

```text
三指针法：1 -> 2 -> 3 -> 4 -> 5  →  5 -> 4 -> 3 -> 2 -> 1
再跑头插法：5 -> 4 -> 3 -> 2 -> 1  →  1 -> 2 -> 3 -> 4 -> 5（复原）

空表：逆置后还是空表 ✓
单节点：逆置后还是自己 ✓
```

**三指针四步（背下来）**

```c
next = cur->next;      ① 先存后继
cur->next = prev;      ② 反转指向
prev = cur;            ③ prev 前进
cur  = next;           ④ cur 前进
```

> ⚠️ 第 ① 步绝不能颠倒。先改 `cur->next` 就丢了后继，链表只剩前半截。

**两个优雅之处**

- 不需要特判空表和单节点，while 条件天然处理对了
- O(n) 时间、O(1) 空间

## ex174 合并两个有序链表

**实测输出**：

```text
A        1 -> 4 -> 7 -> 10
B        2 -> 3 -> 8 -> 11 -> 15
合并后   1 -> 2 -> 3 -> 4 -> 7 -> 8 -> 10 -> 11 -> 15

边界：A 为 NULL → 直接返回 B ✓
      两个都 NULL → 返回 NULL，不崩 ✓
```

**关键点**

1. **空间 O(1)**：不 malloc，只重排 `next` 指针（复用原节点）。
2. 剩余部分一句接上：`tail->next = (a != NULL) ? a : b;`
   不用写两个 while 逐个搬。
3. `dummy` 在栈上，不需要 `free`。
4. 合并后原链表 a、b 已被拆散，不能再单独使用。

> ⭐ 对比数组归并：数组必须开新数组 O(n+m) 空间，链表可以 O(1)。

## ex175 按奇偶拆分

**实测输出**：

```text
源        1 -> 2 -> 3 -> 4 -> 5 -> 6 -> 7 -> 8
奇数链    1 -> 3 -> 5 -> 7
偶数链    2 -> 4 -> 6 -> 8
源（已空） -> NULL

边界：全奇数 → 偶数链为空 ✓
      空表   → 两条都空 ✓
```

**两个致命细节**

**① 摘节点前必须存 next**

```c
Node *next = cur->next;     /* ⚠️ 少了这句，cur->next 一改就丢了后面 */
cur->next = NULL;           /* 接到新链 */
cur = next;
```

**② 必须维护 tail 指针**

没有 tail 时，每次尾插都要从头找尾 → O(n²)。
有 tail 时每次插入 O(1) → 整体 O(n)。

> 📌 n=8 时看不出差别，n=100000 时差几个小时。

## ex176 快慢指针三连

**实测输出**：

```text
奇数个(7)：中间是 4
偶数个(6)：中间是 4（偏后）

正常链表 → 有环？否
造环后   → 有环？是

[1 2 3 4 5] 删倒数第 1 → [1 2 3 4]
[1 2 3 4]   删倒数第 4 → [2 3 4]（删掉头节点）
k = 99       → 不变，不崩
```

**三个算法**

```c
/* 找中间 */
while (fast && fast->next) { slow = slow->next; fast = fast->next->next; }
return slow;

/* 判环 */
while (fast && fast->next) {
    slow = slow->next; fast = fast->next->next;
    if (slow == fast) return 1;
}

/* 删倒数第 k：fast 先走 k+1 步 */
for (int i = 0; i <= k; i++) fast = fast->next;
while (fast) { fast = fast->next; slow = slow->next; }
slow->next = slow->next->next;
```

**三个易错点**

1. **`while` 条件必须 `fast != NULL && fast->next != NULL`**
   顺序也不能反（先判 fast 非空，才能访问 `fast->next`）。
2. **删倒数第 k 时 fast 走 k+1 步**，不是 k 步 —— 要停在被删节点的前驱。
3. **必须用 dummy**，否则删头节点时没有前驱。

> ⭐ 判环时快指针走 2 步能保证相遇；走 3 步可能跳过慢指针，不一定相遇。

## 汇总：本周六个坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | `next` 写成 `Node *` | 编译报 `unknown type name` |
| 2 | 头插两句顺序反了 | 自环，遍历死循环 |
| 3 | 插入时先改 `prev->next` | 后半段丢失 + 内存泄漏 |
| 4 | 删除忘了 `free` | 内存泄漏 |
| 5 | 销毁时先 `free` 再取 `next` | 访问已释放内存，偶发崩溃 |
| 6 | 循环链表用 `p != NULL` 遍历 | 死循环 |

## 记忆卡：两张必须背的表

### 顺序表 vs 链表

| | 顺序表 | 链表 |
|---|---|---|
| 按位置访问 | **O(1)** | O(n) |
| 按值查找 | O(n) | O(n) |
| 表头插入 | O(n) | **O(1)** |
| 表尾插入 | **O(1)** | O(n) |
| 插入（已知位置指针） | O(n) | **O(1)** |
| 存储密度 | 高（≈1） | 低（有指针开销） |

### 四种链表的判空

| 类型 | 判空条件 |
|---|---|
| 带头结点单链表 | `head->next == NULL` |
| 不带头结点单链表 | `head == NULL` |
| 带头结点循环单链表 | `head->next == head` |
