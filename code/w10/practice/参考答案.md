## ex91 用指针返回多个值（`6` / `72 45 91 38 66 88`）

```text
最小值 = 38，最大值 = 91
```

```c
void minMax(int *a, int n, int *outMin, int *outMax) {
    int mn = *a, mx = *a;
    for (int *p = a + 1; p < a + n; p++) {
        if (*p < mn) mn = *p;
        if (*p > mx) mx = *p;
    }
    *outMin = mn;
    *outMax = mx;
}
```

**为什么需要这种写法**：C 函数只能 `return` 一个值。想同时给出两个结果，有两条路 —— 用结构体打包（W11），或者用指针当输出参数（本答案）。

**这和 `scanf("%d", &n)` 是同一个原理** —— `scanf` 也是通过指针"返回"读到的值。

## ex92 手写 strcpy

```text
复制结果：Programming
```

```c
void myStrcpy(char *dst, const char *src) {
    while ((*dst++ = *src++) != '\0')
        ;
}
```

**那一行在干什么**：

```text
① *dst = *src     复制一个字符
② 判断这个字符是不是 '\0'
③ dst++、src++    两个指针都后移
```

**⭐ 为什么 `'\0'` 也被复制了**：赋值发生在判断**之前**，`'\0'` 已经写进 dst 了，只是判断后退出循环。所以 dst 天然以 `'\0'` 结尾，不用手动补。

怕写错就用易读版：

```c
while (*src != '\0') { *dst = *src; dst++; src++; }
*dst = '\0';        /* ← 这种写法必须手动补 */
```

## ex93 手写 strcat

```text
Hello World
```

```c
void myStrcat(char *dst, const char *src) {
    while (*dst != '\0') dst++;         /* ① 走到 dst 末尾 */
    while ((*dst++ = *src++) != '\0')   /* ② 从那里开始抄 */
        ;
}
```

**两步缺一不可**：不先走到末尾，就会从头覆盖 dst 的内容。

## ex94 指针反转字符串（`hello`）

```text
olleh
```

```c
void reverseStr(char *s) {
    char *right = s;
    while (*right) right++;
    right--;                            /* ⚠️ 退回最后一个真实字符 */

    while (s < right) {
        char t = *s; *s = *right; *right = t;
        s++; right--;
    }
}
```

**`right--` 是最容易漏的一步**：不 `--` 就把 `'\0'` 和首字符交换了，字符串立刻变空。

## ex95 二级指针

```text
初始：*p = 10（指向 a）
retarget 之后：*p = 20（应该指向 b）
```

```c
void retarget(int **pp, int *target) {
    *pp = target;
}
```

**为什么必须二级**：如果参数写 `int *pp`，`pp` 是 `p` 的副本，`pp = target` 只改副本 —— 又回到 W7 的 swap 问题。

**类型链**：

```text
p      int*     指向 int
&p     int**    指向「int*」
*pp    int*     就是 p
**pp   int      就是 p 指向的值
```

**现实用途**：链表删除头节点 `void removeHead(Node **head)`。

## ex96 指针判断回文

```text
level    → 是回文
hello    → 不是回文
abcba    → 是回文
a        → 是回文
ab       → 不是回文
```

```c
int isPalindrome(const char *s) {
    const char *left = s, *right = s;
    while (*right) right++;
    right--;
    while (left < right) {
        if (*left != *right) return 0;
        left++; right--;
    }
    return 1;
}
```

**边界自动正确**：空串和单字符时 `left >= right`，循环不执行，返回 1。
