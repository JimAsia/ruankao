## ex31 求和（输入 `10`）

```text
1~10 的和 = 55
1~10 的偶数和 = 30
```

**两个初值都是 0。** 累加写错初值（比如写 1）是新手常犯的错，结果会多 1。

偶数和有两种写法：

```c
/* 写法一：判断 + 累加 */
for (int i = 1; i <= n; i++) if (i % 2 == 0) evenSum += i;

/* 写法二：直接以 2 为步长，循环少一半 */
for (int i = 2; i <= n; i += 2) evenSum += i;
```

## ex32 阶乘表

```text
1! = 1
2! = 2
3! = 6
...
10! = 3628800
```

**关键：用累乘，不要每轮从头乘。**

```c
long long fac = 1;
for (int i = 1; i <= 10; i++) {
    fac *= i;              /* 上一层的结果直接乘，O(n) */
    printf("%d! = %lld\n", i, fac);
}
```

如果写成「每轮从头乘到 i」，复杂度会变成 O(n²)，而且代码更啰嗦。

**为什么用 `long long`**：`13! = 6227020800`，超过 int 的 21 亿上限。虽然这题只算到 10!（3628800），但养成习惯能少踩坑。

## ex33 素数判断

| 输入 | 输出 |
|---|---|
| 97 | 是素数 |
| 91 | 不是素数（7 × 13） |
| 1 | 不是素数 |
| 2 | 是素数 |

**三个必须处理的点：**

```c
if (n < 2) { /* 0 和 1 不是素数，直接返回 */ }

for (int i = 2; i * i <= n; i++) {     /* 只试到 √n */
    if (n % i == 0) { isPrime = 0; break; }
}
```

1. **`n < 2` 要单独判**。不判的话，1 会被误判成素数（因为 2 到 0 的循环一次都不跑，`isPrime` 保持 1）。
2. **`i * i <= n` 而不是 `i < n`**。后者虽然也对，但慢得多；前者利用「因子成对出现」的性质。
3. **找到因子就 `break`**，没必要继续试。

> 💡 不用 `sqrt(n)` 是为了避免引入 `<math.h>` 和浮点误差。`i * i` 全程整数运算，更干净。

## ex34 数字拆位（输入 `3725`）

```text
位数 = 4
各位和 = 17
反转 = 5273
```

**核心：一个循环干三件事。**

```c
int tmp = n;            /* ⚠️ 必须复制，拆位会破坏原数 */
while (tmp > 0) {
    int digit = tmp % 10;
    sum += digit;                 /* 各位和 */
    rev  = rev * 10 + digit;      /* 反转 */
    cnt++;                        /* 位数 */
    tmp /= 10;
}
```

**反转的四轮变化：**

```text
digit=5 → rev = 0*10+5   = 5
digit=2 → rev = 5*10+2   = 52
digit=7 → rev = 52*10+7  = 527
digit=3 → rev = 527*10+3 = 5273
```

`rev * 10` 是「腾出个位」，`+ digit` 是「填进去」—— 记住这个动作就够了。

## ex35 打印图案（输入 `4`）

正三角：

```text
*
**
***
****
```

**外层控制行数，内层控制每行的字符数。**

```c
for (int i = 1; i <= n; i++) {      /* 第 i 行 */
    for (int j = 1; j <= i; j++)    /* 打 i 个星 */
        printf("*");
    printf("\n");                   /* ⚠️ 每行结束必须换行 */
}
```

**最常见的两个错：**
- 忘了 `printf("\n")`，所有星号挤在一行
- 内层写成 `j <= n`，结果变成实心矩形

进阶的等腰三角形，规律是「第 i 行先打 n-i 个空格，再打 2i-1 个星」：

```text
   *        i=1: 3空格 + 1星
  ***       i=2: 2空格 + 3星
 *****      i=3: 1空格 + 5星
*******     i=4: 0空格 + 7星
```

## ex36 最大公约数（输入 `12 18`）

```text
最大公约数 = 6
最小公倍数 = 36
```

**辗转相除法：**

```c
int origA = a, origB = b;      /* ⚠️ 先存原始值 */

while (b != 0) {
    int t = a % b;
    a = b;
    b = t;
}
int gcd = a;                   /* 循环结束时 a 就是 gcd */

int lcm = origA / gcd * origB; /* 先除后乘，减少溢出风险 */
```

**验算过程：**

```text
12 % 18 = 12   →  a=18, b=12
18 % 12 = 6    →  a=12, b=6
12 % 6  = 0    →  a=6,  b=0   ← 结束，gcd = 6
```

**两个坑：**
1. **不保存原值** —— 辗转相除会把 a、b 改成 0 和 gcd，算 lcm 时就没原始数据了。
2. **`a * b / gcd` 可能溢出** —— 写成 `a / gcd * b`，先除后乘，中间值更小。
