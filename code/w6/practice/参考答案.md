## ex51 矩阵行和与列和（输入 `2 3` / `1 2 3` / `4 5 6`）

```text
第 1 行之和 = 6
第 2 行之和 = 15
第 1 列之和 = 5
第 2 列之和 = 7
第 3 列之和 = 9
```

**行和与列和的唯一区别：双层循环的顺序。**

```c
/* 行和：外层行，内层列 */
for (int i = 0; i < r; i++) {
    int sum = 0;
    for (int j = 0; j < c; j++) sum += a[i][j];
}

/* 列和：外层列，内层行 */
for (int j = 0; j < c; j++) {
    int sum = 0;
    for (int i = 0; i < r; i++) sum += a[i][j];
}
```

外层循环决定了「一趟跑完什么」。想按列累加，外层就必须是列。

## ex52 矩阵转置（输入 `2 3` / `1 2 3` / `4 5 6`）

```text
1 4
2 5
3 6
```

```c
for (int i = 0; i < r; i++)
    for (int j = 0; j < c; j++)
        t[j][i] = a[i][j];       /* 下标对调 */
```

**注意转置后是 `c` 行 `r` 列**，输出时外层循环要用 `c`。

方阵可以原地转置（不开新数组），但内层必须从 `j = i + 1` 开始：

```c
for (int i = 0; i < n; i++)
    for (int j = i + 1; j < n; j++)     /* ⚠️ 从 i+1 开始 */
        交换 a[i][j] 和 a[j][i];
```

从 0 开始的话，每个位置会被换两次，等于没转。

## ex53 统计字符（输入 `Abc123!@#`）

```text
大写 = 1，小写 = 2，数字 = 3，其他 = 3
```

```c
for (int i = 0; s[i] != '\0'; i++) {
    char c = s[i];
    if      (c >= 'A' && c <= 'Z') upper++;
    else if (c >= 'a' && c <= 'z') lower++;
    else if (c >= '0' && c <= '9') digit++;
    else                           other++;
}
```

**能这样写的前提是 ASCII 连续**：`A~Z` 是 65~90，`a~z` 是 97~122，`0~9` 是 48~57。

## ex54 字符串反转（输入 `hello`）

```text
olleh
```

```c
int right = 0;
while (s[right] != '\0') right++;    /* 找末尾，停在 '\0' 上 */
right--;                              /* ⚠️ 退到最后一个真实字符 */

int left = 0;
while (left < right) {
    交换 s[left] 和 s[right];
    left++; right--;
}
```

**`right--` 是最容易漏的一步。** 不 `--` 的话会把 `'\0'` 换到开头，字符串立刻变空。

## ex55 回文判断

| 输入 | 输出 |
|---|---|
| `level` | 是回文 |
| `hello` | 不是回文 |
| `abcba` | 是回文 |
| `a` | 是回文 |
| `ab` | 不是回文 |

```c
int left = 0, right = strlen(s) - 1, isPal = 1;
while (left < right) {
    if (s[left] != s[right]) { isPal = 0; break; }
    left++; right--;
}
```

**边界情况自动正确**：空串时 `right = -1`，循环不执行；单字符时 `left == right`，也不执行。所以不用特判。

## ex56 大小写互换（输入 `Hello World 2026`）

```text
hELLO wORLD 2026
```

```c
if      (s[i] >= 'a' && s[i] <= 'z') s[i] = s[i] - 32;
else if (s[i] >= 'A' && s[i] <= 'Z') s[i] = s[i] + 32;
```

**这题的关键不在转换，在输入方式：**

| 输入方式 | 问题 |
|---|---|
| `scanf("%s", s)` | ❌ 遇到空格就停，只能读到 `Hello` |
| `fgets(s, sizeof(s), stdin)` | ✅ 读整行，但**末尾会带上 `'\n'`** |

`fgets` 带进来的 `'\n'` 必须手动去掉：

```c
int len = strlen(s);
if (len > 0 && s[len - 1] == '\n') s[len - 1] = '\0';
```

不去掉的话，输出末尾会多一个空行，而且后续处理长度会多算 1。
