## 逐题关键点

### ex01 自我介绍
无难点。练的是「`printf` 要加分号、`\n` 要写在字符串里面」。

### ex02 四则运算 — 输入 `17 5`

```text
17 + 5 = 22
17 - 5 = 12
17 * 5 = 85
17 / 5 = 3      ← 整数除法，只要商
17 % 5 = 2      ← 取余数
```

| 容易错的地方 | 说明 |
|---|---|
| 输出 `17 %% 5` | 打出来就是两个百分号。要写 `%%` 才对 |
| 期望 `17 / 5 = 3.4` | `int / int` 永远是整数，想要 3.4 得写 `(double)a / b` |
| `scanf` 忘了 `&` | 立刻崩，或者读到垃圾值 |

### ex03 摄氏转华氏 — 输入 `37`，输出 `98.60`

**本题唯一考点：`9 / 5` 是 1，不是 1.8。**

```c
f = c * 9 / 5 + 32;      /* ❌ 整数除法，9/5 = 1，结果 69.00 */
f = c * 9.0 / 5.0 + 32;  /* ✅ 浮点除法，结果 98.60 */
```

### ex04 圆的周长和面积 — 输入 `2`

```text
周长 = 12.566，面积 = 12.566
```

半径 2 时两者相等，不是巧合：2πr = πr² 当且仅当 r = 2。
用 `#define PI 3.1415926` 定义常量比自己到处写数字好。

### ex05 交换变量 — 输入 `3 8`

第一问用 `temp`：

```c
int temp = a;
a = b;
b = temp;
```

第二问只靠加减法，推导过程：

```text
初始     a = a0,  b = b0
a = a+b  a = a0+b0,  b = b0
b = a-b  a = a0+b0,  b = a0+b0-b0 = a0
a = a-b  a = a0+b0-a0 = b0,  b = a0
```

> 💡 这个「不借助第三变量交换」是软考应用技术出现频率极高的小模型，也会出现在读程序写结果题里。必须能徒手推。

### ex06 成绩统计 — 输入 `85 90 78`

```text
总分 = 253，平均分 = 84.33
```

```c
double avg = sum / 3;            /* ❌ 84.00，先整数除法截断了 */
double avg = (double)sum / 3;    /* ✅ 84.33 */
```

**记住这个规律：只要除号两边都是整数，结果就是整数。** 想得到小数，必须在做除法**之前**把某个操作数变成浮点。

### ex07 秒数转换 — 输入 `3725`

```text
1 时 2 分 5 秒
```

```c
hour = total / 3600;   /* 3725 / 3600 = 1 */
rest = total % 3600;   /* 3725 % 3600 = 125 */
min  = rest / 60;      /* 125 / 60 = 2 */
sec  = rest % 60;      /* 125 % 60 = 5 */
```

> 💡 **`/` 取高位，`%` 取低位** —— 这是进制转换、数字拆分、时间换算的统一套路。软考应用题里的「取出一个整数的各位数字」（`n % 10` 得个位，`n / 10` 去掉个位）就是同一个模型。这个模型在 W4 的循环里会升级成「while 循环拆数字」，是必考题型。

### ex08 字符与 ASCII — 输入 `A`

```text
A 的 ASCII 码是 65
对应小写字母是 a
```

```c
printf("%c", upper);        /* 打字符  → A */
printf("%d", upper);        /* 打编码  → 65 */
printf("%c", upper + 32);   /* 大写转小写 */
```

要背的几个 ASCII 值：

| 字符 | 十进制 |
|---|---|
| `'0'` | 48 |
| `'A'` | 65 |
| `'a'` | 97 |
| 空格 | 32 |
