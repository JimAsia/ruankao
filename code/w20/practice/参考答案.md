## ex201 BST 查找与插入

**实测输出**：

```text
中序遍历：20 30 40 50 60 70 80（升序 ✓）
找 40：找到 ✓
找 99：没找到 ✓
```

**BST 三大性质**

1. 左子树所有值 < 根 < 右子树所有值
2. 中序遍历 = 升序序列（验证正确性的标志）
3. 查找每步比大小往下走，复杂度 O(高度)

**插入为什么不用调整**：新节点永远插在叶子位置，那里本来就满足大小关系。

## ex202 BST 删除

**实测输出**：

```text
初始：20 30 40 50 60 70 80

情况1 删叶子 20 → 30 40 50 60 70 80
情况2 删一个孩子（40 有右孩子 45）→ 30 45 50 60 70 80
情况3 删两孩子 70 → 30 45 50 60 80（用 80 替代）
删根 50 → 仍升序
```

**三种情况**

| 情况 | 处理 |
|---|---|
| 叶子 | 直接删，返回 NULL |
| 一个孩子 | 孩子顶上来 |
| 两个孩子 | 右子树最小值替代，递归删它 |

> ⭐ 情况 3 选「右子树最小值」（中序后继），保证中序仍升序。

## ex203 哈夫曼树 WPL

**实测输出**：

```text
{2, 4, 5, 7}    → WPL = 35 ✓
{5, 32, 18, 7, 25} → WPL = 184 ✓
```

**构造**：每次取两个最小的合并，直到剩一个。

**WPL 手算**：每个叶子的 权值 × 深度 之和。

> ⭐ WPL 越小，平均编码越短，压缩效果越好。
> 这是「贪心算法」的经典例子。

## ex204 建堆 + 堆排序

**实测输出**：

```text
原始数组 [49 38 65 97 76 13 27 49]
建堆后   [97 76 65 49 49 13 27 38]   堆顶 = 97
排序后   [13 27 38 49 49 65 76 97]   升序
```

**三个关键点**

1. 建堆从 `n/2` 开始（`> n/2` 的都是叶子）
2. 向下调整：找较大的孩子，比自己大就交换下沉
3. 堆排序：堆顶换末尾 → 向下调整 → 重复

**复杂度**：建堆 O(n)，排序 O(n log n)，空间 O(1)。

## ex205 判断平衡

**实测输出**：

```text
平衡树：是 ✓
斜树：否 ✗
```

**定义**：任意节点左右子树高度差 ≤ 1。

**优化**：朴素版每次重算高度 O(n²)；自底向上返回高度 O(n)。

> ⭐ AVL 靠旋转维持平衡，保证查找稳定 O(log n)。
> 四种失衡：LL/右旋、RR/左旋、LR/先左后右、RL/先右后左。

## ex206 综合小测

**五题答案**：

| 题 | 答案 |
|---|---|
| 深度 5 满二叉树节点数 | 2^5 - 1 = 31 |
| 100 节点完全二叉树深度 | ⌊log2(100)⌋+1 = 7 |
| n 节点二叉树空指针 | n+1 |
| n0 和 n2 关系 | n0 = n2 + 1 |
| n 叶子哈夫曼树总节点 | 2n-1 |

**六条核心性质**（背诵）

```text
1. 第 i 层最多 2^(i-1) 个
2. 深度 k 最多 2^k - 1 个
3. 完全二叉树深度 = ⌊log2(n)⌋ + 1
4. n0 = n2 + 1
5. 空指针 = n + 1
6. 哈夫曼树总节点 = 2n - 1
```

## 记忆卡：W20 必背

**BST**

```text
中序 = 升序
删除两孩子 = 右子树最小值替代
复杂度 = O(高度)，退化斜树 = O(n)
```

**哈夫曼**

```text
WPL = Σ(权值 × 深度)
无度为 1 的节点；n 叶子 → 2n-1 节点
编码是前缀码
```

**堆**

```text
大顶堆：根最大；孩子下标 2i / 2i+1
建堆 O(n)，排序 O(n log n)，空间 O(1)，不稳定
```
