# W12 练习参考答案与要点

> 答案源码在 `answers/` 目录。所有输出为本机实际运行结果。
> 每个程序都会在当前目录生成 `.txt` 文件，属正常现象。

## ex111 写 1~n 的平方表

**输入** `5`，**输出**：

```text
已写入 5 行
1 1
2 4
3 9
4 16
5 25
```

**关键点**

1. `fopen(path, "w")` 后**必须判 NULL**，否则后面 `fprintf(NULL, ...)` 直接崩溃。
2. 写完 `fclose` 再 `fopen(path, "r")`，不要试图「写完立刻读」—— 缓冲区可能还没落盘。
3. 读回用 `while (fscanf(fp, "%d %d", &a, &b) == 2)`，两个都是整数就写 `== 2`。

## ex112 读文件求和

**输出**：

```text
共读 10 个数
总和 = 381
平均 = 38.10
最大 = 100
```

**关键点**

1. `while (fscanf(fp, "%d", &x) == 1)` —— 返回「读到的项数」，只读一个数就是 `== 1`。
2. **`max` 的初值用第一个读到的数**，不要写 `0`：

```c
int first = 1;
while (fscanf(fp, "%d", &x) == 1) {
    if (first) { max = x; first = 0; }
    if (x > max) max = x;
    ...
}
```

> ⚠️ 本组数据全是正数，写 `max = 0` 也能得到 100，**看不出错**。
> 如果数据是 `-5 -3 -9`，`max = 0` 会输出 0 —— 这个坑在 W4 已经踩过一次。

3. 平均分要 `(double)sum / count`，否则整数除法只保留整数部分。

## ex113 统计行/字符/单词

**输出**：

```text
行 3  字符 47  单词 9
```

核对：三行分别是 12 + 19 + 16 = **47** 字节（含换行），单词 hello/world/C/programming/2026/file/io/is/easy = **9** 个。

**关键点**

1. **`int ch`，不是 `char ch`。** `fgetc` 读不到返回 `EOF`（-1），`unsigned char` 装不下 `-1`，会变成 255，死循环。
2. 单词统计的核心是 `inWord` 标记：

```c
if (ch == ' ' || ch == '\n' || ch == '\t') {
    inWord = 0;
} else if (!inWord) {          /* 从空白进入非空白 */
    inWord = 1;
    words++;
}
```

> ⭐ 数的是「从空白跳到非空白的次数」，不是空格数。连续 5 个空格也只算一次。

3. 行数用 `'\n'` 的个数。如果最后一行没有换行，会少算 1 行 —— 用 `fgets` 数更稳。

## ex114 复制文件并比较

**输出**：

```text
复制完成，共 53 字节
两个文件内容一致
```

**关键点**

1. `int ch;` 逐字符读写，同样不能用 `char`。
2. **第二个 `fopen` 失败时必须关第一个**：

```c
FILE *out = fopen(dst, "w");
if (out == NULL) {
    perror("open dst");
    fclose(in);           /* ⚠️ 少了这句就是句柄泄漏 */
    return 1;
}
```

3. 比较两个文件时，除了逐字符比，还要确认**长度一致**：

```c
while ((c1 = fgetc(f1)) != EOF) {
    if (c1 != fgetc(f2)) { same = 0; break; }
}
if (same && fgetc(f2) != EOF) same = 0;   /* f2 更长 */
```

> ⚠️ 只比「共同长度」的话，`abc` 和 `abcdef` 会被判成相同。

## ex115 成绩表存取

**输出**：

```text
读入：1 张三 85.5
读入：2 李四 92.0
读入：3 王五 78.0
读入：4 赵六 90.5

共 4 人，总分 346.00，平均 86.50
```

**关键点**

1. 写入格式串 `"%d %s %.1f\n"` 和读取格式串 `"%d %19s %lf"` **必须能对上**。
2. 读 `double` 用 `%lf`，写 `double` 用 `%.1f`（或 `%f`）—— 这是 `scanf` 和 `printf` 唯一不对称的格式符。
3. `%19s` 限制宽度，防止超长姓名写爆 `char[20]`。
4. 写完 `fclose` 再读，保证内容已落盘。

> ⭐ 记住这个对应：**一个结构体 = 文件里的一行 = 一条记录**。

## ex116 关键字查找

**输入** `is`，**输出**：

```text
第 3 行：C programming is fun
第 4 行：file io is easy
命中 2 行
```

**关键点**

1. `fgets` 逐行读，`strstr(line, key)` 判断包含。返回 `NULL` 表示不含。
2. `fgets` 保留了 `\n`，用 `printf("第 %d 行：%s", n, line)` **不加 `\n`**，正好换行。
3. 最后一行如果没有 `\n`，要手动补，否则下一次输出会粘在同一行。

**`strstr` 与 `strchr` 的区别**

| 函数 | 查找对象 | 返回 |
|---|---|---|
| `strstr(line, key)` | 子串 | 首次出现的地址，找不到 NULL |
| `strchr(line, 'x')` | 单个字符 | 首次出现的地址，找不到 NULL |

想要**位置（下标）**：

```c
char *p = strstr(line, key);
if (p != NULL) {
    int pos = (int)(p - line);     /* 指针相减得元素个数 */
}
```

## 汇总：本周六个坑

| # | 坑 | 后果 |
|---|---|---|
| 1 | `"w"` 打开想读 | 文件当场被清空 |
| 2 | 不判 `fopen` 返回 NULL | 后续操作直接崩 |
| 3 | `fgets` 后没去掉 `\n` | `strcmp` 永远不等 |
| 4 | `char ch = fgetc(fp)` | 可能死循环 |
| 5 | `while (!feof(fp))` | 最后一条数据被处理两次 |
| 6 | 第二个 fopen 失败没关第一个 | 句柄泄漏 |
