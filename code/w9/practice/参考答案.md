## ex81 用指针交换（`3 8`）

```text
交换前 a = 3, b = 8
交换后 a = 8, b = 3
```

```c
void swap(int *a, int *b) {
    int t = *a;
    *a = *b;
    *b = t;
}
swap(&a, &b);        /* ⚠️ 传地址 */
```

**⭐ 这就是 W7「swap 为什么失败」的答案：**

| 版本 | 传什么 | 结果 |
|---|---|---|
| W7 | `swap(int x, int y)` 传值 | ❌ 交换的是副本 |
| W9 | `swap(int *a, int *b)` 传地址 | ✅ 顺着地址改原件 |

**关键洞察**：C 语言**仍然是值传递**，变的是「传什么值」—— 传值只能读，传地址能改。

## ex82 指针遍历求和（`5` / `3 7 1 9 4`）

```text
和 = 24
```

```c
int sumByPtr(int *a, int n) {
    int sum = 0;
    for (int *p = a; p < a + n; p++) sum += *p;
    return sum;
}
```

**⚠️ 条件是 `p < a + n`，不是 `p <= a + n`。**

`a + n` 指向「最后一个元素之后」，可以用于比较，但**解引用就是越界**。

## ex83 指针找最大值（`6` / `72 45 91 38 66 88`）

```text
最大值 = 91
```

```c
int maxByPtr(int *a, int n) {
    if (n <= 0) return 0;
    int max = *a;                        /* *a 就是 a[0] */
    for (int *p = a + 1; p < a + n; p++)
        if (*p > max) max = *p;
    return max;
}
```

初值陷阱在指针版同样存在：`max = 0` 遇到全负数就错了。

## ex84 指针反转（`6` / `1 2 3 4 5 6`）

```text
反转后：6 5 4 3 2 1
```

```c
void reverseByPtr(int *a, int n) {
    int *left = a, *right = a + n - 1;   /* ⚠️ 是 a+n-1 */
    while (left < right) {
        int t = *left; *left = *right; *right = t;
        left++; right--;
    }
}
```

**和 W5 的下标版完全对应**：

| 下标版 | 指针版 |
|---|---|
| `i = 0` | `left = a` |
| `j = n - 1` | `right = a + n - 1` |
| `while (i < j)` | `while (left < right)` |

## ex85 手写 strlen（`Programming`）

```text
长度 = 11
```

```c
int myStrlen(const char *s) {
    const char *p = s;
    while (*p != '\0') p++;
    return (int)(p - s);        /* 指针相减 = 元素个数 */
}
```

**为什么 `p - s` 是长度**：`p` 最后停在 `'\0'` 上，`s` 在开头，两者相隔的字符数正好等于长度。

⚠️ 别写成 `p - s + 1`，那会把 `'\0'` 也算进去。

## ex86 指针与数组等价性

| 小题 | 写法 A | 写法 B | 结果 |
|---|---|---|---|
| ① 取 a[3] 值 | `a[3]` = 40 | `*(a+3)` = 40 | 相同 |
| ② 取 a[3] 地址 | `&a[3]` | `a+3` | 相同 |
| ③ 改 a[0] | `a[0] = 99` | `*p = 99` | 相同 |
| ④ 求间隔 | `4 - 2` = 2 | `&a[4] - &a[2]` = 2 | 相同 |
| ⑤ 遍历 | `a[i]` | `*(p+i)` | 相同 |

**结论**：

```text
a[i]   ==  *(a + i)
&a[i]  ==  a + i
```

这不是巧合，是 C 语言的定义 —— **下标写法只是指针运算的语法糖**。

> 📌 软考经常考「`*(a+3)` 和 `a[3]` 是否等价」，答案是等价。也可能考更绕的：
> `*(a+3)` 等价于 `a[3]`，也等价于 `*(&a[0]+3)`，也等价于 `p[3]`（p = a）。
