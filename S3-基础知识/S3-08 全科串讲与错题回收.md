# S3-08 全科串讲与错题回收

> 这份文档有两个用途：
> ① 考前 30 分钟快速过一遍八模块的**必背公式与结论**；
> ② 用两套模拟卷（各 25 题）检测漏洞，错的回去翻对应手册。

## 一、八模块速查总表

| 模块 | 三件必背 |
|---|---|
| **计算机组成** | 补码范围 `−2^(n−1) ~ 2^(n−1)−1`；Cache `t=h·tc+(1−h)·tm`；带宽 `位宽/8 × 频率` |
| **操作系统** | 进程=资源分配、线程=调度；`S<0` 时 `|S|`=等待数；可用主机 `2^n−2` 的同理，页面置换 FIFO 有 Belady |
| **数据库** | 视图=外模式；`m:n` 必建表；2NF 消部分、3NF 消传递、BCNF 全超键 |
| **网络** | 集线器/交换机/路由器 = 物理/链路/网络；`/26→62`；三次握手 SYN→SYN+ACK→ACK |
| **软件工程** | 螺旋=风险分析；自顶向下=桩、自底向上=驱动；改善性维护占比最大 |
| **知识产权** | 著作权自动产生；发明 20/实用新型 10/外观 15；商标 10 可续展 |
| **C++** | 构造基类→成员→派生，析构相反；虚函数看对象、非虚看指针；`map` 是红黑树 |
| **数据结构** | `n0=n2+1`；排序总表；哈希失败 ASL=α |

### 卷 A 答案

| 题 | 答 | 解析 |
|---|---|---|
| 1 | **A** | 补码比原码多表示一个 −128，编码就是 `1000 0000` |
| 2 | **A** | 单精度偏移 127，双精度 1023 |
| 3 | **B** | `0.9×1 + 0.1×10 = 1.9ns` |
| 4 | **B** | `32/8 × 66 = 264 MB/s`，别忘除以 8 |
| 5 | **B** | SJF 可证明平均周转时间最短，但长作业可能饿死 |
| 6 | **B** | S<0 时，`|S|` 就是等待队列里的进程数 |
| 7 | **D** | 四个必要条件是互斥、请求并保持、不可剥夺、环路等待 |
| 8 | **C** | 只有 FIFO 会出现「页框变多反而缺页更多」 |
| 9 | **A** | 视图是给用户看的，属于外模式 |
| 10 | **C** | m:n 必须独立建表，主键是两端主键的组合 |
| 11 | **C** | 基本运算只有并、差、笛卡尔积、选择、投影 |
| 12 | **B** | 2NF 消部分依赖，3NF 消传递依赖 |
| 13 | **C** | 集线器物理层、交换机链路层、路由器网络层 |
| 14 | **B** | SYN → SYN+ACK → ACK |
| 15 | **A** | 私有地址只有 10/8、172.16/12、192.168/16；172.32 不在范围内 |
| 16 | **B** | `2^6 − 2 = 62` |
| 17 | **B** | 原型模型就是为了解决需求不明确 |
| 18 | **C** | 螺旋模型的标志就是风险分析 |
| 19 | **B** | 自顶向下缺下层 → 用桩；自底向上缺上层 → 用驱动 |
| 20 | **C** | 改善性（完善性）维护约占一半 |
| 21 | **C** | `13 − 10 + 2 = 5` |
| 22 | **B** | 著作权自动产生，保护表达不保护思想 |
| 23 | **C** | 发明 20 年（实用新型 10、外观设计 15） |
| 24 | **C** | `n0 = n2 + 1 = 11` |
| 25 | **B** | 已有序且取首元素为基准，每次分区都退化成 n−1 和 0 |

### 卷 B 答案

| 题 | 答 | 解析 |
|---|---|---|
| 1 | **C** | −1 的补码是全 1，最好记的一个 |
| 2 | **A** | 12.5 = 1.1001×2³，阶码 130=`10000010` |
| 3 | **C** | `64/8 × 100 = 800 MB/s` |
| 4 | **D** | `1 − 0.1³ = 0.999` |
| 5 | **B** | 进程管资源，线程管调度 |
| 6 | **C** | 栈是线程私有的，其余共享 |
| 7 | **B** | 银行家算法在分配前判断安全性，属于「避免」 |
| 8 | **A** | 2NF 消除部分依赖，3NF 消除传递依赖 |
| 9 | **C** | 除法对应「全部」这类查询 |
| 10 | **C** | GRANT/REVOKE 是数据控制语言 |
| 11 | **A** | 原子性 |
| 12 | **B** | 交换机看 MAC 地址，工作在数据链路层 |
| 13 | **B** | DNS 查询用 UDP/53（区域传送用 TCP） |
| 14 | **C** | /26 每段 64 个，130 落在 128~191 |
| 15 | **B** | 4 = 2²，24 − 2 = 22 |
| 16 | **C** | 功能内聚最高，偶然内聚最低 |
| 17 | **D** | 路径覆盖 > 条件组合 > 判定/条件 > 条件 > 判定 > 语句 |
| 18 | **B** | 关键路径是最长路径，关键活动浮动为 0 |
| 19 | **B** | 合同没约定时归开发者，不是出钱方 |
| 20 | **B** | 10 年，每次续展 10 年，可无限续 |
| 21 | **B** | 栈：中缀转后缀、表达式求值、括号匹配 |
| 22 | **B** | ASL 只与装填因子 α 有关，与表长无关 |
| 23 | **B** | 逆序保证每件物品只用一次；正序会变成完全背包 |
| 24 | **C** | 堆排序空间 O(1)；快排 O(log n)，归并 O(n) |
| 25 | **A** | 先序根 A，中序分左右：左 `DBE`、右 `C`；后序 `DEB` + `C` + `A` |

> 25 题解析：先序 `A B D E C`，根是 A；中序 `D B E A C`，
> A 左边 `D B E` 是左子树，右边 `C` 是右子树。
> 左子树先序 `B D E`、中序 `D B E` → 根 B，左 D、右 E。
> 后序 = 左 `D E B` + 右 `C` + 根 `A` = `DEBCA`。

## 五、应试策略

### 5.1 时间分配（上午题 75 分 / 150 分钟）

```text
第一遍（60 分钟）：做完全部会做的，不会的标记跳过
第二遍（50 分钟）：攻标记题，能推的推，能排除的排除
第三遍（25 分钟）：检查 + 涂卡
预留（15 分钟）：机动
```

> ⭐ 不要在一道题上卡超过 3 分钟。选择题 1 分，卡住就是亏。

### 5.2 答题顺序

```text
先做「会的」→ 再做「能算的」→ 最后「纯记忆但忘了的」
```

计算题（补码、Cache、子网、McCabe）**一定要拿到**，因为它们有确定答案，
不像概念题容易记混。

### 5.3 蒙题原则（实在不会时）

```text
① 排除明显错误的两个，在剩下两个里选
② 选「最全面、最中庸」的那个（绝对化表述往往是错的）
③ 计算题如果算出答案在选项里，基本就是它
④ 完全不会就选 B 或 C，不要空着
```

### 5.4 常见「绝对化」陷阱词

```text
"一定" "必须" "所有" "完全" "只能" "绝不"
—— 出现这些词的选项，八成是错的
```
